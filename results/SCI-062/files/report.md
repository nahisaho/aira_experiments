## 1. 実験目的と背景

無細胞タンパク質合成（Cell-Free Protein Synthesis; CFPS）は、生細胞を必要とせずに転写・翻訳機構を試験管内で再構成するタンパク質生産技術である。本フレームワークでは、CFPS システムの生産性を系統的に最適化するため、以下の 6 モジュールからなる計算フレームワークを設計・実装した：

1. **転写–翻訳連成モデル**: リソース競合（リボソーム、RNAP）を考慮した ODE モデル
2. **エネルギー再生系の比較**: クレアチンリン酸（CP）、ホスホエノールピルビン酸（PEP）、マルトースの 3 系統
3. **イオン濃度最適化**: Mg²⁺/K⁺/ポリアミン（スペルミジン）の応答曲面マッピング
4. **mRNA 安定性・リボソーム負荷予測**: 配列特徴量に基づく半減期・翻訳効率モデル
5. **スケールアップ設計**: バッチ → 半連続 → 連続系の動態比較
6. **膜タンパク質発現**: ナノディスク共翻訳挿入のケーススタディ

本研究の目的は、これらのモジュールを統合し、CFPS の反応条件を多角的に最適化するための定量的ガイドラインを提供することである。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 ODE ベースのキネティクスモデリング

全モジュールにおいて、`scipy.integrate.solve_ivp`（RK45 法）を用いた常微分方程式系の数値解法を採用した。各モデルの主要特徴：

- **転写–翻訳連成**: Michaelis-Menten 型速度式、リボソーム・RNAP の競合的結合モデル
- **エネルギー再生**: 基質枯渇 + 副産物蓄積 + 毒性フィードバックを含む反応速度論
- **膜タンパク質**: 8 変数の連立 ODE（mRNA、新生 MP、挿入 MP、ミスフォールド MP、遊離ナノディスク、NTP、アミノ酸、エネルギー基質）

### 2.2 ベイズ最適化

Module 3 において、Expected Improvement（EI）獲得関数を用いたベイズ最適化を実装。逆距離加重補間によるサロゲートモデルと組み合わせ、Mg²⁺ 濃度の最適値を 20 回の反復で同定した。

### 2.3 応答曲面法（RSM）

Mg²⁺/K⁺/スペルミジンの 3 因子空間における二次応答曲面モデルを構築。交互作用項を含むガウス型応答関数により、全パラメータ空間のコンター図を生成した。

### 2.4 mRNA 安定性予測

GC 含量、5'UTR 構造、polyA 尾部長、レアコドン頻度、RBS 強度をパラメータとする経験的予測モデルを構築。リボソーム密度と翻訳速度の関係をフットプリントモデルで記述した。

## 3. 主要な結果と数値

### 3.1 Module 1: 転写–翻訳連成モデル

| パラメータ | 値 |
|---|---|
| 最大タンパク質収量 | **36.1 nM** |
| 翻訳速度飽和 DNA 濃度 | 32.3 nM |
| リボソーム総濃度 | 500 nM |

- DNA テンプレート濃度の増加はリボソーム枯渇を引き起こし、翻訳速度が飽和する
- mRNA は約 60 分で定常状態に達し、NTP 枯渇により 180 分以降に系全体が停止

**関連図表**: `figures/fig1_txn_tln_dynamics.png`, `figures/fig2_resource_competition.png`

### 3.2 Module 2: エネルギー再生系の比較

| エネルギー系 | ATP 持続時間 (min) | ピーク ATP (mM) | コスト効率 |
|---|---|---|---|
| クレアチンリン酸 (CP) | 55 | 26.74 | 37.5 |
| PEP | 37 | 12.43 | 8.7 |
| マルトース | **102** | **27.34** | **124.3** |

- **マルトース系**が ATP 持続時間・コスト効率の両面で最も優れる
- PEP 系はピルビン酸蓄積による産物阻害が顕著で、早期に ATP 供給が停止
- CP 系は初期応答が速いが、中長期のコスト効率ではマルトースに劣る

**関連図表**: `figures/fig3_energy_systems.png`, `figures/fig4_energy_radar.png`

### 3.3 Module 3: イオン濃度最適化

| イオン | 最適濃度 | 許容範囲 |
|---|---|---|
| Mg²⁺ | **11.0 mM** | 8–15 mM |
| K⁺ | **170 mM** | 130–210 mM |
| スペルミジン | **1.5 mM** | 1.0–2.0 mM |

- ベイズ最適化は 15 回の反復で真の最適値の 99% 以内に収束
- Mg²⁺ は最も感度が高く、±3 mM の偏差で収量が 50% 以上低下
- K⁺–Mg²⁺ 間には負の交互作用が存在

**関連図表**: `figures/fig5_ion_optimization.png`, `figures/fig6_bayesian_opt.png`

### 3.4 Module 4: mRNA 安定性とリボソーム負荷

| mRNA | 半減期 (min) | リボソーム/mRNA | 翻訳速度 (prot/min/mRNA) |
|---|---|---|---|
| GFP (720 nt) | **37.3** | 6.6 | 16.1 |
| Luciferase (1653 nt) | 21.3 | **15.4** | 15.8 |
| GPCR (1050 nt) | 23.0 | 7.5 | 11.7 |
| scFv (750 nt) | 35.9 | 6.2 | 14.3 |

- 短鎖・高 GC・5'UTR ステムループ構造を持つ mRNA（GFP）が最も安定
- 長鎖 mRNA（Luciferase）はリボソーム密度は高いが、半減期が短く全体的な翻訳出力は制限される
- レアコドン頻度が 20% を超えると翻訳速度が 50% 以上低下

**関連図表**: `figures/fig7_mrna_stability.png`, `figures/fig8_codon_sensitivity.png`

### 3.5 Module 5: スケールアップ設計

| 反応モード | ピーク収量 (nM) | 生産性 (nM/hr) | 特徴 |
|---|---|---|---|
| バッチ | 62.2 | 5.2 | 基質枯渇で早期停止 |
| 半連続 | **234.6** | **19.5** | 周期的給餌により持続発現 |
| 連続（CECF） | 62.2 | 5.2 | 希釈によるタンパク質損失 |

- **半連続系**がバッチの 3.8 倍のピーク収量を達成
- 連続系は定常状態に達するが、希釈率の最適化が不十分な場合はバッチと同等
- 体積スケールアップでは 1 mL 以上で混合効率・酸素移動が急速に低下

**関連図表**: `figures/fig9_scaleup_comparison.png`, `figures/fig10_volume_scaling.png`

### 3.6 Module 6: 膜タンパク質 / ナノディスク ケーススタディ

| ナノディスク濃度 (µM) | 挿入 MP (µM) | 挿入効率 (%) |
|---|---|---|
| 0 | 0.00 | 0.0 |
| 10 | 10.00 | >99 |
| 25 | 25.00 | >99 |
| 50 | 44.23 | >99 |
| 100 | 48.23 | >99 |
| 200 | 49.24 | >99 |

- ナノディスクが存在しない場合、膜タンパク質は 100% ミスフォールド/凝集
- ナノディスク濃度 50 µM 以上で挿入収量が飽和（∼44–49 µM）
- ナノディスクの利用効率は低濃度（10–25 µM）で最も高い
- 実用上は **50 µM** のナノディスク添加が最適（収量/コストの均衡点）

**関連図表**: `figures/fig11_nanodisc_mp.png`

## 4. 考察と今後の展望

### 4.1 主要な知見

1. **リソース競合のボトルネック**: DNA テンプレート濃度はリボソーム・RNAP の有限性により飽和挙動を示す。多遺伝子発現系ではリソース配分の最適化が不可欠である。

2. **エネルギー再生の選択**: マルトース系は低コストかつ長時間の ATP 供給が可能であり、工業スケールの CFPS に最適である。ただし、再生速度は CP 系に劣るため、短時間の高生産性が求められる場合は CP 系を推奨する。

3. **イオン環境の重要性**: Mg²⁺ は最も感度の高い因子であり、精密な制御（±1 mM 以内）が必要である。ベイズ最適化により、従来のグリッドサーチの 1/10 未満の実験数で最適値を同定可能であることを示した。

4. **コドン最適化の効果**: レアコドンの除去は翻訳効率に直接的に寄与する。特に膜タンパク質のような翻訳が遅い対象では、コドン最適化の効果が大きい。

5. **スケールアップ戦略**: 半連続系（dialysis-based CECF）が最も生産性が高いが、実装の複雑さを考慮すると、初期スクリーニングではバッチ系、量産にはフロースルー連続系の段階的導入が現実的である。

### 4.2 モデルの限界

- 本モデルは主要な動態パラメータに焦点を当てた簡略化モデルであり、以下の要素は未考慮：
  - 分子シャペロン（DnaK/J/GrpE）の折りたたみ支援効果
  - tRNA 充填レベルの動的変化
  - 酸化還元環境（GSH/GSSG 比）の影響
  - 温度依存性のアレニウス効果

### 4.3 今後の展望

1. **実験検証**: 本モデルの予測値を、GFP 蛍光を指標とした実験データと照合する
2. **マルチオミクスデータ統合**: プロテオミクス・メタボロミクスデータを取り込み、パラメータの精密化を行う
3. **機械学習の導入**: ODE パラメータ推定にニューラル ODE（Neural ODE）を適用し、実験データからの自動パラメータ学習を実現する
4. **膜タンパク質の拡張**: リポソーム、ポリマーソーム等の代替膜足場との比較研究
