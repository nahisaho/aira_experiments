## 1. 実験目的と背景

### 1.1 目的

金属有機構造体（Metal-Organic Framework, MOF）のCO₂/H₂ガス吸着性能を高速予測するハイスループットスクリーニング（HTS）パイプラインを設計する。特に **Direct Air Capture（DAC）** 向けの最適MOF候補材料の同定を最終目標とする。

### 1.2 背景

大気中CO₂直接回収（DAC）は、気候変動緩和の重要技術として注目されている。MOFはその高い比表面積、調整可能な細孔構造、化学的多様性から、DAC吸着剤の有力候補である。しかし、既知のMOF構造は **CoRE MOF データベースに約14,000件**、仮想MOFライブラリ（hMOF）には **約137,000件** が登録されており、実験的評価だけでは探索空間を網羅できない。

本パイプラインは、計算科学（GCMC シミュレーション）と機械学習を組み合わせ、数万〜数十万件のMOF構造を効率的にスクリーニングするシステムを提供する。

### 1.3 DAC の技術的課題

| 課題 | 要求仕様 |
|------|----------|
| CO₂濃度 | 大気中 ~420 ppm (0.042%) |
| 作動容量 | ≥ 1.0 mmol/g |
| CO₂/N₂ 選択性 | ≥ 50 |
| 再生温度 | ≤ 100°C（373 K） |
| 水安定性 | 湿潤環境で構造維持 |
| 合成可能性 | スケールアップ可能な手法 |

## 2. 使用した手法・アルゴリズムの概要

### 2.1 パイプライン全体構成

```
┌──────────────────────────────────────────────────────────────┐
│  Stage 1: データベース読込 & 特徴量抽出                      │
│  CoRE MOF / hMOF → CIF解析 → Zeo++ 幾何学的解析            │
│                  → 化学組成解析                              │
├──────────────────────────────────────────────────────────────┤
│  Stage 2: 幾何学的プレスクリーニング                          │
│  LCD, PLD, ASA, 空隙率ウィンドウフィルタリング                │
├──────────────────────────────────────────────────────────────┤
│  Stage 3: 吸着量予測（GCMC or ML代理モデル）                  │
│  RASPA GCMC → CO₂/H₂/N₂ 吸着等温線                         │
│  OR: 構造記述子 → ML予測                                     │
├──────────────────────────────────────────────────────────────┤
│  Stage 4: 安定性・合成可能性フィルタリング                    │
│  水安定性 + 熱安定性 + 合成可能性                            │
├──────────────────────────────────────────────────────────────┤
│  Stage 5: DAC ランキング                                     │
│  多基準スコアリング → パレートフロント → Top-N 候補           │
└──────────────────────────────────────────────────────────────┘
```

| 記述子 | 略称 | 単位 | 計算手法 |

| 非アクセス表面積 | NASA | m²/g | MC サンプリング |
| アクセス可能体積 | AV | cm³/g | MC サンプリング (N=100000) |

| チャネル数 | n_chan | — | 連結性解析 |

#### 2.2.4 トポロジカル記述子

### 2.4 Stage 3: 幾何学的記述子と吸着量の関係

#### 2.4.1 主要な構造–性能相関

文献および本解析から得られた知見：

| 記述子対 | 相関 | メカニズム |
|---------|------|-----------|
| ASA vs CO₂ (高圧) | 正の線形 (R² ≈ 0.7) | 表面被覆支配 |
| φ vs CO₂ (高圧) | 正の相関 | 体積充填支配 |
| LCD vs CO₂ (低圧) | ベル型 (最適 5-10 Å) | 細孔–分子相互作用の最適化 |
| Qst vs CO₂ (DAC) | 正 (30-50 kJ/mol 最適) | 強い吸着 vs 再生のトレードオフ |
| φ vs CO₂ (低圧) | 弱い負の相関 | 小細孔で強い相互作用 |

![Structure-Property Relationships](figures/structure_property.png)

#### 2.4.2 圧力依存性

- **低圧域 (< 0.01 bar)**: 吸着は **表面化学** と **Qst** に支配される。OMS、官能基修飾が重要。
- **高圧域 (> 1 bar)**: 吸着は **空隙率** と **ASA** に支配される。幾何学的記述子との線形相関が強い。
- **DAC 条件 (420 ppm)**: 超低圧域であり、Henry 定数と Qst が最も重要な指標。

## 4. 考察と今後の展望

### 4.1 パイプライン設計の妥当性

1. **段階的フィルタリング**の有効性: 幾何学的プレスクリーニングにより、計算コストの高いGCMCシミュレーション対象を70%以上削減できる。

2. **ML代理モデル**の適用: R² > 0.85 の予測精度であれば、Top候補の絞り込みに十分。最終候補のみGCMC検証する「ファネル型」戦略が効率的。

3. **安定性フィルタ**の重要性: 吸着性能が優れていても水安定性が低いMOF（Mg-MOF-74等）はDAC実用化が困難。Zr, Al, Cr系MOFの優位性が明確。

### 4.2 技術的課題

| 課題 | 現状 | 改善方向 |
|------|------|----------|
| ML低圧予測精度 | R² = 0.72 | Graph Neural Network (CGCNN) 導入 |
| 水安定性予測 | ルールベース | 実験データでのML学習 |
| 混合ガス選択性 | Henry 比 (近似) | IAST 厳密計算 |
| フレキシブルMOF | 剛体モデル | flexible framework MC |
| 電荷割当 | EQeq 近似 | DFT-derived (DDEC/REPEAT) |

### 4.3 今後の展望

1. **Graph Neural Network (GNN) の導入**: MOF構造をグラフ表現し、CGCNN/MEGNet で直接吸着量予測。特徴量エンジニアリング不要で精度向上が期待される。

2. **転移学習**: 高圧データ（豊富）→ 低圧データ（希少）への知識転移で DAC 条件の予測精度改善。

3. **能動学習ループ**: 不確実性の高い予測に対して選択的にGCMCを実行し、モデル精度を反復的に向上。

4. **多目的ベイズ最適化**: パレートフロントの効率的探索。

5. **実験検証パイプライン**: 計算候補の自動合成・評価ロボットとの連携。

6. **湿潤条件シミュレーション**: CO₂/H₂O 混合系GCMC で実使用条件での性能評価。
