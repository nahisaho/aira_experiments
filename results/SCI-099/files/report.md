## 1. 実験目的と背景

### 目的
老化の主要メカニズム（Hallmarks of Aging）を統合する常微分方程式（ODE）ベースの数理モデルを構築し、以下を実現する：

1. 老化の12の特徴量（Hallmarks）の相互作用ネットワークの定量的記述
2. 信頼性理論（Reliability Theory）と拮抗的多面発現（Antagonistic Pleiotropy）の統合
3. セノリティクス（老化細胞除去療法）の効果予測
4. カロリー制限（CR）、ラパマイシン、NAD⁺前駆体の作用メカニズムモデリング
5. 種間寿命差の進化的説明
6. 介入組合せ最適化

### 背景
老化は単一の原因ではなく、テロメア短縮、エピジェネティック変化、ミトコンドリア機能低下、プロテオスタシス喪失、栄養感知異常、細胞老化、慢性炎症、幹細胞枯渇、ゲノム不安定性、細胞間通信異常などの多層的プロセスの相互作用として生じる（López-Otín et al., 2013, 2023）。本モデルでは、これらを12変数の連立ODEとして定式化し、損傷蓄積と死亡ハザードを統合的に記述する。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 モデル構造

#### 状態変数（12変数）
| 記号 | 変数名 | 初期値 | 方向性 |
|------|--------|--------|--------|
| T | テロメア長 | 1.0 | 1→0（短縮） |
| E | エピジェネティック完全性 | 1.0 | 1→0（劣化） |
| M | ミトコンドリア機能 | 1.0 | 1→0（低下） |
| P | プロテオスタシス能 | 1.0 | 1→0（低下） |
| N | 栄養感知異常 | 0.0 | 0→1（蓄積） |
| S | 老化細胞割合 | 0.01 | 0→1（蓄積） |
| I | 慢性炎症 | 0.02 | 0→1（増大） |
| SC | 幹細胞機能 | 1.0 | 1→0（枯渇） |
| G | ゲノム安定性 | 1.0 | 1→0（不安定化） |
| IC | 細胞間通信品質 | 1.0 | 1→0（劣化） |
| D | 統合損傷指標 | 0.0 | 0→∞（蓄積） |
| R | 生殖適応度 | 0.0 | 拮抗的多面発現 |

#### ODE体系の特徴
- 各Hallmarkは自律的劣化項 + 他のHallmarkとの交差項を持つ
- 損傷指標D(t)は全Hallmarkの加重平均から Gompertz 型加速で蓄積
- 死亡ハザード: h(t) = h₀ · exp(h_exp · D(t))
- 生存確率: S(t) = exp(−∫₀ᵗ h(τ)dτ)

### 2.2 相互作用ネットワーク
10×10の相互作用行列で定義。主要な経路：
- **テロメア短縮** → 老化細胞蓄積（強度0.8）、幹細胞枯渇（0.5）
- **ミトコンドリア機能低下** → プロテオスタシス喪失（0.5）、炎症（0.4）
- **老化細胞** → 炎症（SASP経由、1.0）、幹細胞枯渇（0.4）
- **炎症** → 細胞間通信劣化（0.6）、幹細胞枯渇（0.4）

### 2.3 信頼性理論（Reliability Theory）
- 生体を並列冗長要素で構成される信頼性システムとしてモデル化
- 損傷蓄積 D(t) は全Hallmarkの正規化損傷平均の β_D 乗に比例（Gompertz加速）
- dD/dt = k_D · (Σ damages / 10)^β_D (β_D = 2.5)

### 2.4 拮抗的多面発現（Antagonistic Pleiotropy）
- 生殖適応度R(t)と損傷D(t)のトレードオフを明示的にモデル化
- 生殖期（t < 30y）: dR/dt = k_R_early · (1-R) − k_R_late · D · R
- 生殖後（t ≥ 30y）: dR/dt = −k_R_late · D · R · (1 + 0.5N)

### 2.5 介入モデル
| 介入 | 作用機序 | 主要ターゲット |
|------|----------|---------------|
| カロリー制限（CR） | 全体的損傷率30%低減 | T, E, N, SC |
| ラパマイシン | mTOR阻害、プロテオスタシス改善25% | P, N |
| NAD⁺前駆体 | ミトコンドリア機能保護20% | M |
| セノリティクス | 老化細胞クリアランス5%追加 | S |

### 2.6 種間スケーリング
- Kleiber則に基づく代謝スケーリング: 老化速度 ∝ M^(-0.25) · 代謝率因子
- DNA修復能によるゲノム安定性補正

### 2.7 数値解法
- SciPy `solve_ivp` (RK45) を使用、rtol=1e-8, atol=1e-10
- 組合せ最適化: 4介入 × 5段階のグリッド探索（625通り）

## 3. 主要な結果と数値

### 3.1 ベースライン老化動態
- **ヒト基準中央値寿命**: 80.7 年
- テロメア長は80歳で初期値の約40%に低下
- 老化細胞割合は80歳で約30%に増加
- 慢性炎症は60歳以降に加速的に増大

![Hallmarks Trajectories](figures/fig1_hallmarks.png)

### 3.2 相互作用ネットワーク
老化細胞→炎症（SASP経由）が最も強い相互作用（強度1.0）であり、炎症カスケードが老化加速のハブとなることを示す。

![Interaction Network](figures/fig2_network.png)

### 3.3 信頼性理論と拮抗的多面発現
- 損傷D(t)はGompertz型（指数的加速）の蓄積パターンを示す
- 生殖適応度Rは30歳までに急速に上昇し、その後損傷蓄積と共に低下
- この R-D トレードオフが拮抗的多面発現の数理的表現

![Reliability & Pleiotropy](figures/fig7_reliability_pleiotropy.png)

## 4. 考察と今後の展望

### 4.1 モデルの意義
1. **統合的フレームワーク**: 12のHallmarkを連立ODEとして統合し、相互作用の定量的記述を可能にした
2. **理論統合**: 信頼性理論の損傷蓄積モデルと拮抗的多面発現の進化理論を同一のフレームワーク内に統合
3. **介入予測**: 単独介入よりも組合せ介入が効果的であることを定量的に予測（最大+17.1%）
4. **タイミング効果**: セノリティクスの早期開始が重要であることを示唆

### 4.2 モデルの限界
1. **パラメータの不確実性**: 多くのパラメータは文献値に基づく推定であり、直接的な実験測定値ではない
2. **線形近似**: 実際の生物学的相互作用は高度に非線形であり、本モデルの1次近似は局所的な妥当性に限られる
3. **確率的効果の欠如**: 決定論的ODEであり、個体間変動や確率的DNA損傷イベントを捕捉できない
4. **空間構造の無視**: 組織・器官レベルの空間的不均一性は考慮されていない
5. **種間スケーリングの簡易性**: 3因子モデルでは種固有のメカニズム（テロメラーゼ活性、Peto's Paradox等）を十分に捉えられない

### 4.3 今後の展望
1. **確率微分方程式（SDE）への拡張**: 個体間変動を表現
2. **空間モデル（PDE）**: 組織レベルの老化伝播をモデル化
3. **マルチスケールモデリング**: 分子→細胞→組織→個体のスケール間接続
4. **ベイズ推定によるパラメータ校正**: 実験データとの統合
5. **遺伝的背景の組み込み**: SNP/エピジェネティック変異による個人差
6. **薬物動態（PK/PD）モデルとの統合**: 介入の時間的投与スケジュール最適化
7. **ネットワーク制御理論の適用**: 最小介入ターゲット同定
