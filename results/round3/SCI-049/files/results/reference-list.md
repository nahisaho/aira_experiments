# Reference List

1. (Killick, 2012) Killick, R., Fearnhead, P., & Eckley, I. A. (2012). Optimal Detection of Changepoints With a Linear Computational Cost. *Journal of the American Statistical Association*, 107(500), 1590-1598. DOI: 10.1080/01621459.2012.737745  
   Key finding: Introduced the PELT algorithm, showing exact changepoint detection with linear computational cost under mild conditions, which makes it suitable as a scalable structural-break baseline.

2. (Yoshizawa, 2020) Yoshizawa, G. (2020). Bayesian Online Change Point Detection for Baseline Shifts. *Statistics, Optimization & Information Computing*, 9(1), 1-16. DOI: 10.19139/soic-2310-5070-1072  
   Key finding: Extended BOCPD to streams with irreversible baseline shifts and showed improved online sensitivity relative to the original BOCPD formulation.

3. (Draayer, 2021) Draayer, E., Cao, H., & Hao, Y. (2021). Reevaluating the Change Point Detection Problem with Segment-based Bayesian Online Detection. In *Proceedings of the 30th ACM International Conference on Information & Knowledge Management* (pp. 2989-2993). DOI: 10.1145/3459637.3482167  
   Key finding: Proposed segment-based BOCPD, arguing that short transition segments are common in real data and improving robustness across diverse time-series benchmarks.

4. (Liu, 2008) Liu, F. T., Ting, K. M., & Zhou, Z.-H. (2008). Isolation Forest. In *2008 Eighth IEEE International Conference on Data Mining* (pp. 413-422). DOI: 10.1109/ICDM.2008.17  
   Key finding: Established isolation-based anomaly detection as an efficient unsupervised baseline with near-linear scaling for large datasets.

5. (Xu, 2023) Xu, H., Pang, G., Wang, Y., & Wang, Y. (2023). Deep Isolation Forest for Anomaly Detection. *IEEE Transactions on Knowledge and Data Engineering*, 35(12), 12591-12604. DOI: 10.1109/TKDE.2023.3270293  
   Key finding: Combined nonlinear representation learning with isolation mechanisms and reported stronger performance than standard isolation-based baselines on high-dimensional data.

6. (Zhou, 2021) Zhou, Y., Liang, X., Zhang, W., Zhang, L., & Song, X. (2021). VAE-based Deep SVDD for anomaly detection. *Neurocomputing*, 453, 131-140. DOI: 10.1016/j.neucom.2021.04.089  
   Key finding: Improved Deep SVDD using variational autoencoder representations, reducing sensitivity to complex data geometry in unsupervised anomaly detection.

7. (Zhang, 2021) Zhang, Z., & Deng, X. (2021). Anomaly detection using improved deep SVDD model with data structure preservation. *Pattern Recognition Letters*, 148, 1-6. DOI: 10.1016/j.patrec.2021.04.020  
   Key finding: Added data-structure preservation to Deep SVDD and improved anomaly discrimination in benchmark datasets.

8. (Antwarg, 2022) Antwarg, L., Mindlin Miller, R., Shapira, B., & Rokach, L. (2022). Explaining anomalies detected by autoencoders using Shapley Additive Explanations. *Expert Systems with Applications*, 186, 115736. DOI: 10.1016/j.eswa.2021.115736  
   Key finding: Demonstrated that SHAP can explain unsupervised autoencoder anomalies by identifying both contributing and offsetting features.

9. (Lin, 2024) Lin, X., Chang, L., Nie, X., & Dong, F. (2024). Temporal Attention for Few-Shot Concept Drift Detection in Streaming Data. *Electronics*, 13(11), 2183. DOI: 10.3390/electronics13112183  
   Key finding: Used temporal attention to improve few-shot concept drift detection in streaming data, reporting gains in accuracy, precision, recall, and F1.

10. (Greco, 2025) Greco, S., Vacchetti, B., Apiletti, D., & Cerquitelli, T. (2025). Unsupervised Concept Drift Detection From Deep Learning Representations in Real-Time. *IEEE Transactions on Knowledge and Data Engineering*, 37(10), 6232-6245. DOI: 10.1109/TKDE.2025.3593123  
    Key finding: Presented a real-time representation-based drift detector that improves detection quality while remaining computationally practical for streaming systems.

11. (Yang, 2021) Yang, L., Manias, D. M., & Shami, A. (2021). PWPAE: An Ensemble Framework for Concept Drift Adaptation in IoT Data Streams. In *2021 IEEE Global Communications Conference (GLOBECOM)* (pp. 1-6). DOI: 10.1109/GLOBECOM46510.2021.9685338  
    Key finding: Showed that ensemble adaptation can stabilize performance under non-stationarity, supporting retraining-trigger logic in streaming applications.

12. (Michailidis, 2023) Michailidis, G. (2023). Challenges for Anomaly Detection in Large-Scale Cyber-Physical Systems. *Harvard Data Science Review*, 5(1). DOI: 10.1162/99608f92.7b8b6a89  
    Key finding: Reviewed the practical barriers to anomaly detection in large-scale cyber-physical systems, especially data heterogeneity, limited labels, and operational interpretability.

13. (Buonsante, 2025) Buonsante, M., Cruciani, M., Simone, F. M., & Venditti, R. (2025). Anomaly detection for data quality monitoring of the Muon system at CMS. *EPJ Web of Conferences*, 337, 01174. DOI: 10.1051/epjconf/202533701174  
    Key finding: Reported detector-specific deep-learning anomaly detection for CMS Muon monitoring, highlighting the need for fine-grained, online data quality control in HEP workflows.
