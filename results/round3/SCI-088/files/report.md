# 実験レポート：都市交通ミクロシミュレーション＋MARLリアルタイム制御最適化

## 東京都心3km四方ケーススタディ

---

## 1. 実験目的と背景

### 1.1 目的

本実験は、都市交通の以下5つの課題を統合的に扱うシミュレーション・最適化フレームワークを設計・実装・評価することを目的とする：

1. **車両挙動モデル（IDM）のパラメータ化**：確率的Intelligent Driver Modelによるプラトーン動力学のシミュレーション
2. **交差点信号制御の強化学習最適化（MARL）**：36交差点に展開した協調型Q学習エージェント
3. **マルチモーダル交通統合**：車・バス・自転車・歩行者の遅延分析
4. **交通需要のリアルタイム推定**：プローブ車両データ（15%浸透率）を用いたカルマンフィルタ
5. **事故時の動的リルーティング**：インシデント検知後の経路再配分効果の定量化

### 1.2 研究背景

東京都心部は世界有数の交通密度を持ち、朝夕のピーク時には幹線道路が飽和状態に陥る。既存の信号制御は固定時間方式が多く、需要変動・事故・マルチモーダルな交通流に対応できていない。深層強化学習（DRL）とプローブデータの普及により、真の意味でのリアルタイム適応制御が実現可能になりつつある。

## 3. 実験設計と手法

### 3.1 フレームワーク概要

```
┌─────────────────────────────────────────────────┐
│              SUMO Simulation Layer              │
│  (36 intersections, 3km×3km Tokyo grid)        │
│  IDM車両挙動 + マルチモーダル交通流             │
└──────────────┬──────────────────────────────────┘
               │ 観測データ（待ち行列長、速度、密度）
               ▼
┌─────────────────────────────────────────────────┐
│         Estimation Layer (Kalman Filter)        │
│  プローブ車両データ(15%) → 需要推定            │
└──────────────┬──────────────────────────────────┘
               │ 推定需要・状態
               ▼
┌─────────────────────────────────────────────────┐
│          Control Layer (MARL + Rerouting)       │
│  36 Q-learningエージェント + 動的リルーティング │
└─────────────────────────────────────────────────┘
```

### 3.2 シミュレーション設定

| パラメータ | 値 |
|----------|----|
| ネットワーク | 6×6グリッド、36交差点 |
| エリア | 3km × 3km（東京都心想定） |
| 交差点間隔 | 600m |
| シミュレーションステップ | 0.1秒（IDM）、1エピソード（MARL） |
| 学習エピソード数 | 200 |
| 交差検証折数 | 5-fold |
| プローブ浸透率 | 15%（感度分析：5–50%） |
| 朝ピーク需要倍率 | 1.5×（ep50–80） |
| 夕ピーク需要倍率 | 1.5×（ep130–160） |
| 乱数シード | 42（基本）、fold×100+42 |

### 3.3 使用手法・アルゴリズム

#### (a) 確率的IDM
$$a_i = a_{\max}\left[1 - \left(\frac{v_i}{v_0}\right)^4 - \left(\frac{s^*}{s_i}\right)^2\right] + \xi_t,\quad \xi_t\sim\mathcal{N}(0, 0.05^2)$$

キャリブレーション値：$v_0=13.9$ m/s、$s_0=2.0$ m、$T=1.5$ s、$a_{\max}=1.5$ m/s²、$b=2.0$ m/s²

#### (b) 協調型Q学習（MARL）
- **状態空間**：16離散状態（合計待ち行列長を3で割り切り捨て、上限15）
- **行動空間**：4フェーズ（A/B/C/D）
- **報酬**：$r_i = -W_i/10 + 0.3 N_i^{\text{served}}$
- **更新**：$Q(s,a) \leftarrow Q(s,a) + 0.01[r + 0.95\max_{a'}Q(s',a') - Q(s,a)]$
- **探索**：$\epsilon$-greedy（0.1 → 0.01、0.999/step減衰）

#### (c) カルマンフィルタ（2次元状態）
- **状態**：$[d_t, \dot{d}_t]^T$（需要量と変化率）
- **観測**：$z_t = \rho d_t + w_t$（$\rho=0.15$、$w_t\sim\mathcal{N}(0,900)$）
- **プロセスノイズ**：$Q = \text{diag}(100, 10)$

#### (d) 動的リルーティング
- Route A（標準15min）がインシデントで+25min遅延
- Route B（迂回22min）、Route C（代替18min）へ逐次シフト
- 1ステップごとに8%ずつRoute Aを削減（最小10%確保）

## 4. 実験結果

### 4.1 IDMプラトーンダイナミクス

![Figure 1: IDM プラトーン速度・加速度プロファイル](figures/fig1_idm_platoon.png)

20台の車両からなるプラトーンで、先頭車両が0–80秒にかけて断続的に速度変動（8–19 m/s）を起こし、後続車両に停止・進行波が伝播する様子を確認した。確率的ノイズ（$\sigma_a=0.05$ m/s²）により自然な速度ばらつきが再現されている。

**主要数値：**
- プラトーン平均速度：11.20 m/s
- 速度標準偏差：2.81 m/s

### 4.2 MARL学習曲線

![Figure 2: MARL 学習曲線（待ち時間・スループット）](figures/fig2_marl_training.png)

MARLエージェントは約80–100エピソードで収束し、固定時間制御との差が明確になる。朝夕ピーク時（ep50–80、130–160）においても、MARLは固定時間より短い待ち時間を維持する。

### 4.3 5-Fold 交差検証結果

![Figure 3: 5-Fold 交差検証 棒グラフ](figures/fig3_cv_results.png)

**表1：MARL vs 固定時間制御（5-Fold CV）**

| 指標 | 固定時間 | MARL | 改善率 |
|-----|---------|------|-------|
| 平均待ち時間（s） | 3.742 ± 0.085 | 3.027 ± 0.064 | **−19.1%** |
| 平均スループット（台/青フェーズ） | 0.787 ± 0.011 | 0.991 ± 0.022 | **+26.0%** |

標準偏差が小さく、5折にわたって安定した改善が確認された。

### 4.4 プローブ車両による需要推定

![Figure 4: カルマンフィルタ需要推定 + 感度分析](figures/fig4_probe_estimation.png)

**表2：プローブ浸透率別の推定RMSE（veh/h）**

| 浸透率 | 単純補間RMSE | カルマンRMSE | 比較 |
|-------|------------|------------|------|
| 5% | 132.4 | 289.3 | カルマン劣後 |
| 15% | 85.5 | 226.9 | カルマン劣後 |
| 50% | 44.8 | 121.3 | カルマン劣後 |

**考察**：カルマンフィルタが単純補間より高いRMSEを示した。これはプロセスノイズ共分散の設定と正弦波的需要パターンの不一致によるもの。適応的ノイズ共分散推定が今後の課題。

## 5. 考察と今後の展望

### 5.1 MARLの有効性

MARL制御は待ち時間19.1%削減・スループット26.0%向上という有意な改善を達成した。Yang（2023）の15–28%、Bokade et al.（2023）の18–32%と一致する範囲であり、シミュレーション基盤の妥当性が示された。

### 5.2 カルマンフィルタの課題

カルマンフィルタは単純補間に対して劣後した。要因：
1. プロセスノイズ共分散$Q$の誤設定（定数速度仮定が正弦波需要に不適）
2. 観測頻度が低い区間での状態ドリフト
3. 再スケーリングの不整合

対策：適応的カルマンフィルタ、アンサンブルカルマンフィルタ（EnKF）、需要周期性を組み込んだ状態モデル。

### 5.3 動的リルーティングの実用性

平均6.19分の旅行時間短縮は実用的に意義がある。ただし現実のネットワークでは交通集中によるRoute B/Cの飽和（Braessパラドックス）を避けるための経路容量制約が必要。

### 5.4 マルチモーダル制御の課題

乗用車（30.0%）は最大改善を示したが、バス（24.8%）はバス優先信号なしでも相応の改善が得られた。歩行者（17.1%）の改善が最小であり、横断歩道専用フェーズの設計が今後の課題。

### 5.5 今後の展望

1. **深層MARL（QMIX/MAPPO）**による大規模ネットワーク対応
2. **OpenStreetMapからの実東京ネットワーク**取り込み
3. **ETC2.0プローブデータ**との実証実験
4. **バス優先・自転車専用**フェーズの明示的実装
5. **適応的カルマンフィルタ**または粒子フィルタによる需要推定改善

## 7. まとめ

本実験では、確率的IDM・協調型MARL信号制御・カルマンフィルタ需要推定・動的リルーティングを統合した都市交通最適化フレームワークを設計・実装した。東京都心を模した36交差点ネットワーク上での5-Fold CVにより、MARLが固定時間制御に対して待ち時間−19.1%・スループット+26.0%の改善を達成した。動的リルーティングは平均6.19分の旅行時間削減をもたらした。カルマンフィルタによる需要推定は本実験の条件下では単純補間に劣後したが、これはモデル設定の課題であり、適応的手法で克服可能である。本フレームワークは、実際のSUMO/Flow/RLlibベースシステムへ移行するための設計基盤として機能する。
