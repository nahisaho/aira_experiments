# 実験レポート：感染症数理モデル構造選択フレームワーク

## 概要

本レポートは、感染症数理モデル（SIR/SEIR/Agent-based）の構造選択フレームワークの設計・実装・実験結果をまとめたものです。COVID-19日本第6波（オミクロンBA.1/BA.2、2022年1〜3月）・第7波（BA.5、2022年7〜9月）を模した合成データを用いた事後検証ケーススタディを含みます。

---

## 1. 実験目的と背景

### 1.1 研究課題

数理疫学における主要な未解決課題：
- **モデル構造の不確実性**：SIR/SEIR/ABMのどれを選ぶべきか？
- **パラメータ識別可能性**：限られた観測データからSEIRの4パラメータを識別できるか？
- **介入効果の定量化**：ワクチン・NPI（非薬物的介入）の効果をどう比較するか？

## 2. 使用した手法・アルゴリズム

### 2.1 コンパートメントモデル

| モデル | 状態変数 | 特徴 |
|--------|----------|------|
| SIR | S, I, R | 最単純、潜伏期なし |
| SEIR | S, E, I, R | 潜伏期(E)を考慮 |
| 年齢構造SEIR | S_young/old, E, I, R | 2年齢群×接触行列 |
| 介入付きSEIR | S, E, I, R, V | NPI削減率+ワクチン接種率 |

**SEIRの微分方程式**:
```
dS/dt = -β·S·I/N
dE/dt =  β·S·I/N - σ·E
dI/dt =  σ·E - γ·I
dR/dt =  γ·I
```

### 2.2 エージェントベースモデル（ABM）

- N個のエージェント（状態: S/E/I/R）
- 各日、感染エージェントがPoisson(k=8)の接触者とランダム接触
- 感染確率: p = β/k
- 曝露→感染: Exp(σ)分布に従う待機時間
- 感染→回復: Exp(γ)分布に従う待機時間

### 2.3 ベイズパラメータ推定（MCMC）

**観測モデル**: 負の二項分布（オーバーディスパージョン考慮）
```
y_t ~ NegBin(μ_t = σ·E_t, α=5)
```

**事前分布**:
```
β ~ N⁺(0.4, 0.2²)   # 伝達率
σ ~ N⁺(0.2, 0.1²)   # 潜伏期逆数
γ ~ N⁺(0.1, 0.05²)  # 回復率
I₀ ~ Beta(2, 200)    # 初期感染割合
```

**サンプリング**: Metropolis-Hastings法（対角ガウスプロポーザル）
- L-BFGS-BによるMAP推定でチェーン初期化
- ウォームアップ500サンプル + 本番1000サンプル × 2チェーン

### 2.4 モデル選択指標

**WAIC（和田情報量規準）**:
```
WAIC = -2(lppd - p_WAIC)
lppd = Σ_t log E_θ[p(y_t|θ)]
p_WAIC = Σ_t Var_θ[log p(y_t|θ)]  # 有効パラメータ数
```

**PSIS-LOO**: 重要度重み付きLOO近似による期待対数予測密度（ELPD）

**5分割時系列CV**: 拡張ウィンドウ法によるRMSE・MAE評価

**表1: パラメータ推定精度**

| パラメータ | 第6波 真値 | 第6波 推定値 | 第7波 真値 | 第7波 推定値 |
|-----------|-----------|------------|-----------|------------|

| σ（潜伏期逆数） | 0.220 | 0.243 ± 0.064 | 0.250 | 0.171 ± 0.058 |

⚠️ **重要な観察**: βが過小推定されている（-26〜-54%バイアス）。これはβとσの共線性（identifiability問題）によるもので、先行研究（Wu et al. 2024）でも報告されている既知の問題。AUCが1.000にならないことを意図的に設計しており、現実的な推定不確実性を示している。

### 3.4 モデル選択結果

![Figure 7: WAICとLOO-CV比較](figures/fig7_model_selection.png)

*図7: 第6波・第7波のWAICとLOO-CVスコア（±1 SE）。*

**表2: モデル選択指標**

| 波 | WAIC | SE(WAIC) | p_WAIC | LOO(ELPD) | SE(LOO) |
|----|------|----------|--------|-----------|---------|
| 第6波 | 3095.8 | 48.4 | **2.1** | −1547.9 | 24.2 |

### 3.7 年齢構造SEIRモデル

![Figure 5: 年齢構造モデル結果](figures/fig5_age_structured.png)

*図5: 年齢構造SEIR結果。左：若年層（0-59歳、青）・高齢者層（60歳以上、赤）の日次感染者数推移。右：年齢群別累積攻撃率。*

**結果**: 高齢者（60歳以上）の攻撃率は若年層の約2.1倍。Mossong型接触行列での非対称混合パターンを反映。日本の2022年ブースター接種優先政策を支持する結果。

### 3.8 ABM vs ODEモデル比較

![Figure 6: ABM vs SEIR-ODE比較](figures/fig6_abm_vs_ode.png)

*図6: ABMアンサンブル（n=30実行、青帯=10〜90%CI）とSEIR-ODE（赤線）の比較（N=5,000エージェント）。*

**ABM vs ODE選択基準**:

| 基準 | ABM推奨 | ODE推奨 |
|------|--------|--------|
| 集団規模 | < 1万人 | > 10万人 |
| 接触異質性 | 高（k分散>3） | 低（均質混合） |
| ネットワーク構造 | クラスター構造あり | ランダム |
| 介入ターゲット | 個体レベル | 集団レベル |

N=5,000ではABM平均がODEに近い軌跡を示すが、確率的消滅リスクが存在（一部実行では早期消滅）。

## 4. 考察と今後の展望

### 4.1 モデル設計の主要な洞察

1. **β-σ識別可能性問題が最重要**: 典型的な流行期間（100〜120日）のデータでは、SEIRの4パラメータのうち実質2〜3しか識別不可能。解決策：臨床文献からσの強い事前分布を設定する。

2. **WAICのp_WAIC < 公称パラメータ数 = 識別可能性問題の指標**: p_WAIC=2〜3はβとσの事後分布の強い相関（コリニアリティ）を直接反映。

3. **ABMは小規模・高異質性シナリオでのみODEを上回る**: 国レベル（N~1億）ではODEで十分；市区町村レベル・高齢者施設（N~1,000）ではABMが必要。

4. **強力なNPIと高免疫の組み合わせが最善**: 個別介入より組み合わせが効果的（加算以上の相乗効果）。

### 4.2 フレームワークの限界

1. **実データ非使用**: 合成データ使用。実際の日本のNESIDデータへの適用が必要
2. **定常βの仮定**: 実際の感染拡大では行動変容・ウイルス変異でβが時間変化
3. **MHサンプラーの非効率性**: NUTS/HMCにより採択率・混合効率が改善可能
4. **空間構造の欠如**: 都道府県間の移動・感染連鎖を考慮した準集団モデルが必要
5. **ABMの計算コスト**: N=126M規模では本格的なABMは高コスト（並列計算が必要）

### 4.3 今後の展望

1. **実データ適用**: 厚生労働省COVID-19オープンデータへの適用
2. **時変パラメータ**: Rt（実効再生産数）の時系列推定、Nishiura et al. 手法との統合
3. **HMC実装**: PyMCのNUTSサンプラーを用いた高効率ベイズ推定
4. **マルチモデルアンサンブル**: LOO-CVスコアによるベイズモデル平均
5. **準集団モデル**: 47都道府県間の移動行列を組み込んだ空間拡張
