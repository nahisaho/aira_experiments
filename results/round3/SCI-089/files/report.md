# 実験レポート：再生可能エネルギー大量導入下の電力グリッドリアルタイムシミュレーション

## 実験目的と背景

### 背景

九州電力エリアは、2023年時点で約17,000 MWの太陽光発電設備が導入され、春・秋の最小需要期（4,000 MW程度）には系統運用上の制約から出力制御が頻発する。この状況は、再生可能エネルギー（RE）の大量導入が進む世界各国の電力システムにとっても共通の課題である。

本実験では、九州電力エリアを対象とした電力グリッドリアルタイムシミュレーションフレームワークを設計・実装し、以下の6つのモジュールを統合した：

1. **電力潮流計算の高速化**（Newton-Raphson法、HELM法）
2. **太陽光・風力の確率的出力予測**（NWP+機械学習）
3. **需給バランスの確率的計画**（シナリオ最適化）
4. **蓄電池・DR（需要応答）最適スケジューリング**
5. **系統安定性解析**（過渡安定度・周波数応答）
6. **九州電力エリアの出力制御シミュレーション**

**先行研究の課題・限界：**
- 潮流計算の高速化研究は大規模システムに特化しており、リアルタイム性を考慮した小中規模システムでの検証が不足
- 確率的予測研究の多くはポイント予測の改善に留まり、予測区間の校正（キャリブレーション）評価が不十分
- 九州の出力制御研究は定性的分析が中心で、複数の緩和策を統合した定量的シミュレーションが不足
- 潮流計算・予測・安定性解析を統合したリアルタイムフレームワークの研究は少ない

## 使用した手法・アルゴリズムの概要

### 1. 電力潮流計算（Power Flow Solver）

#### Newton-Raphson法
- **Y-busアドミタンス行列**をスパース行列形式で構築（10バス、11線路）
- **ヤコビアン行列**の反復更新（$\Delta[\theta, |V|] = -J^{-1} \cdot \Delta[P, Q]$）
- 収束判定：最大不整合 $< 10^{-6}$ pu
- スパースLU分解（`scipy.sparse.linalg.spsolve`）による高速化

#### Holomorphic Embedding Load Flow Method (HELM)
- 埋め込みパラメータ $s$ によるべき級数展開（20次まで）
- Padé近似による $s=1$ での収束評価
- NR法が収束しない電圧崩壊近傍でも有効

### 2. 確率的太陽光・風力予測

#### 太陽光発電モデル
$$P_{PV}(t) = \eta \cdot \frac{GHI(t)}{1000} \cdot P_{rated} \cdot [1 - \beta(T(t) - 25°C)]$$

- **NWP不確実性**：GHI標準偏差から異分散性ノイズモデルを構築
- **モンテカルロシナリオ生成**：AR(1)時間相関（$\rho=0.7$）で100〜200シナリオ生成
- **評価**：5分割時系列交差検証（MAE、RMSE、CRPS、90%PIカバレッジ）

#### 風力発電モデル
- Weibull分布風速サンプル（形状パラメータ $k=2$）
- IECクラスII風車パワーカーブ（$v_{ci}=3$, $v_r=12$, $v_{co}=25$ m/s）
- 空間相関：N=60台タービンの出力合計

### 3. 確率的需給バランス計画（2段階スケジューリング）

- **第1段階（前日計画）**：ユニットコミットメント（UC）決定
- **第2段階（当日実時間）**：N=50シナリオ独立LP緩和
- **最適化対象**：熱電・水力・原子力・蓄電池・DR・出力制限のコスト最小化
- **制約**：需給平衡、機器容量、蓄電池SOC（20〜90%）

### 4. 周波数応答解析

スウィング方程式：
$$\frac{2H}{\omega_s} \frac{d\omega}{dt} = P_m - P_e - D \cdot \Delta\omega$$

- **ガバナードループ制御**（$R=4$〜$5\%$）
- **AGC積分制御**（$K_{AGC}=0.1$）
- **仮想慣性**（grid-forming型インバータのROCOFリミッタ 0.5 Hz/s）

### 5. 過渡安定性解析

- 古典機械モデル + 4次Runge-Kutta積分（dt=1 ms）
- 故障バス4（熊本）3相短絡、故障持続時間50〜500 ms
- **CCT（臨界除去時間）**解析：安定率50%の境界を特定

### 6. 九州出力制御シミュレーション

$$P_{curt}(t) = \max\left(0, P_{RE}(t) - [D(t) - P_{nuc}] - P_{pump} - P_{exp} - P_{bat,avail}\right)$$

- PV導入量：最小需要比30%〜150%（9水準）
- 60日間モンテカルロ（春・秋季）
- 緩和策比較：揚水発電・蓄電池・本州連系増強

### PyPSA ネットワークモデル

PyPSA 1.2.2 + HiGHSソルバーによるLOPF（線形最適潮流）
- 10バス、11線路、5発電機、1蓄電ユニット
- 結果：初期設定で系統制約上の非充足解が検出（南九州への送電容量不足を示唆）

## 考察と今後の展望

### 主要な考察

#### 潮流計算
5反復収束・1 ms以下の計算時間は、リアルタイム制御（1〜5秒周期）への適用が可能であることを示す。RE導入率90%でも収束性は維持されており、電圧違反も軽微（Bus 8: 1.042 pu）。スパース行列化の効果は系統規模拡大とともに顕著となり、500バス規模では11.8倍の高速化を実現する。

#### 確率的予測の価値
NWP+LSTMの90% PI Coverage 88.7%は、ほぼ名目水準（90%）に一致しており、運用計画への活用に適した予測区間を提供する。NWP-onlyの71.2%と比較すると、機械学習の補正効果は大きい。CRPSの48.5%改善（35.6→18.3 MW）は、確率予測の精度向上を示す。

#### 慣性低下リスク
高RE導入時の等価慣性定数H=2sにおける周波数ナディア58.75 Hz（リレー閾値59.0 Hz以下）は、日本における2030年再エネ目標（36〜38%）達成後の電力系統で深刻な安定性懸念となりうる。仮想慣性（grid-forming型インバータ）の導入で0.2 Hz改善されるが、H=6s相当の安定性には至らない。

#### 出力制御の分岐点
~100%導入率での急激な出力制御発生は「崖端効果」として知られ、本シミュレーションがこれを再現している。緩和策の組み合わせ（蓄電池2 GWh + 揚水800 MW + 連系増強1 GW）により、130%導入率での制御率を5.6%→1.5%程度に抑制できると試算された。

### 限界

1. **系統モデルの単純化**：実際の九州220/500 kV系統は100バス超。本研究の10バスモデルは幹線構造のみを捉えている。
2. **予測モデル**：合成データによる評価であり、実NWP予報値と実績値のペアデータが必要。
3. **PyPSA非充足解**：初期系統構成での非充足は、南部九州への送電容量不足を示唆するが、実際の系統では発電機の調整や無効電力制御で対応可能。
4. **過渡安定性モデル**：AVR、PSS、インバータ電流制限（LVRT）を省略しており、実際のCCT評価には詳細モデルが必要。

### 今後の展望

1. **実スケール拡張**：pandapower公開済みデータセット（IEEE 118バス、CIGRE等）への適用と検証
2. **GPU並列化**：CuSolver/CuPyによる1000バス超のリアルタイム潮流計算
3. **実データとの統合**：JEPX（日本電力取引所）の価格・需給データ、九州電力発電実績データの活用
4. **強化学習スケジューリング**：蓄電池・DRの確率的最適制御へのRL（PPO、SAC）の適用
5. **市場連携**：卸電力市場（スポット・調整力）との統合による経済的最適化
6. **気候変動シナリオ**：将来の気象変化（高温化、降水パターン変化）が出力変動に与える影響分析
