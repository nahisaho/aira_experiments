# 実験レポート: 都市大気二次有機エアロゾル（SOA）生成メカニズム解析システム

**実施日**: 2026-05-28  
**システム名**: SOA Reaction Network Analysis System (SRNAS)  
**実装言語**: Python 3.11 (NumPy, SciPy, scikit-learn, Pandas, NetworkX, Matplotlib)

---

## 1. 実験目的と背景

### 1.1 研究背景

都市大気中の二次有機エアロゾル（SOA）は、微小粒子状物質（PM2.5）の主要成分であり、大気汚染による健康被害・気候変動に大きく寄与している。SOAは揮発性有機化合物（VOC）のOHラジカル・オゾン・NO₃ラジカルによる酸化を通じて形成されるが、その反応ネットワークは数千種の化学種・反応を含む複雑な系であり、現在の大気化学モデルは実測値の数倍〜10倍の過小評価が報告されている。

### 1.2 研究目的

本研究では、以下の6つのモジュールを統合した自動化SOA解析システムを設計・実装した：

1. **VOC酸化反応ネットワーク自動生成**（RMG inspired）
2. **気相−粒子相分配の熱力学モデリング**（VBS + UNIFAC/AIOMFAC）
3. **光化学反応速度定数のML予測**（Evans-Polanyi関係の拡張）
4. **大気箱モデルシミュレーション**（0次元光化学箱モデル）
5. **感度解析による主要経路の同定**（局所感度 + Sobol指標）
6. **テルペン/イソプレン系SOA収率予測**（ランダムフォレスト）

### 2.3 先行研究の課題・限界

- **SOA過小予測問題**: 現在のモデルは実測値を2〜10倍過小評価。主因はHOM（高酸素化有機分子）の欠如
- **手動メカニズム構築**: MCM v3.3.1の5,000種・17,000反応は手動で構築されており、新規VOCへの拡張が困難
- **活量係数の不確かさ**: UNIFAC/AIOMFACモデルは官能基の組み合わせによっては精度が低い
- **ML速度定数の汎化**: 既存のMLモデルは量子化学計算データが主体で、実大気条件に不確かさが残る

## 3. 実装した手法・アルゴリズム

### 3.1 反応ネットワーク生成（RMGライクフレームワーク）

グラフ理論に基づく反応ネットワーク自動生成器を実装。化学種をノード（熱力学パラメータ付き）、反応をエッジとして表現。以下の反応クラスを自動生成：

- OH付加反応 → アルコキシ/ペルオキシラジカル
- オゾン分解（ozonolysis）→ カルボニル + クリージー中間体
- NO₃付加 → 硝酸エステル-RO₂
- RO₂消費経路（+ HO₂, + NO, + RO₂）

### 3.2 気相−粒子相分配（VBS + UNIFAC/AIOMFAC）

Pankow（1994）の吸収分配理論に基づくVBSモデルを実装：

**分配係数**: Kp = 1 / (C*_i × γ_i)

**粒子相分率**: F_p = (Kp × C_OA) / (1 + Kp × C_OA)

**温度補正**: Clausius-Clapeyronによる C*(T) の補正（ΔH_vap = 50 kJ/mol）

**活量係数 γ**: 官能基クラス（ジカルボン酸・ヒドロキシカルボニル・エポキサイドジオール等）ごとにAIOMFAC文献値から設定し、湿度依存補正を適用

### 3.3 ML速度定数予測（Evans-Polanyiの拡張）

**特徴量（10次元）**: 反応エンタルピー ΔH, イオン化ポテンシャル IP, H引き抜き部位数, 不飽和度, OH基数, カルボニル基数, 分子量, log蒸気圧, 炭素数, 酸素数

**モデル**: 勾配ブースティング回帰木（200本, 学習率0.05, 最大深さ4, サブサンプル0.8）

**Evans-Polanyiベースライン（比較用）**: Ea = max(0, Ea₀ − α|ΔH|), Ea₀=20 kJ/mol, α=0.5

### 3.4 大気箱モデル（0次元）

疑似定常状態の酸化剤濃度下でのVOC減衰と SOA生成を数値積分：

[VOC](t) = [VOC]₀ × exp(−k_eff × t), k_eff = k_OH[OH] + k_O₃[O₃]

SOA蓄積量 = Σ (delta_C_reacted × MW / N_A × 10¹² × Y_SOA)  [µg/m³]

NOx依存収率（Y_SOA）: 高NOx（>5 ppb）と低NOxで異なる収率を適用

### 3.5 感度解析

- **局所感度**: パラメータを+10%摂動し規格化感度指標 S₁ = (ΔY/Δp)(p/Y) を計算
- **分散ベースSobol指標**: モンテカルロサンプリング（n=400）による条件付き分散法

### 3.6 SOA収率予測ML

ランダムフォレスト（300木, 最大深さ8）をチャンバー実験データ（文献値較正済み合成データ, ~450件）で学習。特徴量: C_OA, log C*(製品1,2), NOx, T, RH, 不飽和度, 分子量, 酸化剤種別

## 5. 考察と今後の展望

### 5.1 主要な発見

1. **初期VOC濃度が支配的制御因子**: Sobol指標でS₁=0.92。VOC排出規制が最も効果的なSOA低減策
2. **温度の重要性**: 感度S₁=−0.91。気温1K低下でSVOCのKpが増加し、冬季・高緯度での高いSOA負荷を説明
3. **テルペン vs 芳香族の対比**: テルペンは速い反応だが低揮発性製品の絶対量も大きい。芳香族は高収率だが遅い反応で都市SOAへの寄与は条件依存
4. **ML速度定数の優位性**: Evans-PolanyiをRMSE 54%削減。分子構造情報（不飽和度、IP）が重要な追加情報

### 5.2 現在の限界

| 限界 | 影響 | 対処方針 |
|------|------|---------|
| HOM自動酸化経路の欠如 | SOA収率の過小評価（特に低NOx・冷温） | ケトラジカル異性化反応の実装 |
| イソプレン水相化学の簡略化 | IEPOX-SOA収率の不確かさ | 完全AIOMFAC水相モデルの統合 |
| ベンゼンの予測誤差大 | 芳香族SOAの不確かさ | 訓練データ追加（AMS-Net、文献収集） |
| 0次元箱モデルの限界 | 空間的変動の無視 | CMAQ/WRF-Chemとの連携 |

### 5.3 今後の展望

1. **HOM形成経路の実装**: Ehn et al.（2014）の急速H転移によるHOM生成経路（log C* < −5）の追加
2. **多世代酸化の明示的記述**: VBSエージングパラメータ（Koo et al.）の実装でO:C比の増加とC*低下を表現
3. **グラフニューラルネットワーク（GNN）**: 分子グラフ表現を使ったk_OH予測の高度化
4. **3D化学輸送モデルとの結合**: CMAQ v5.3との連携による都市域SOA予報
5. **リアルタイム観測データとの同化**: アエロゾル質量分析計（AMS）データとの比較検証
