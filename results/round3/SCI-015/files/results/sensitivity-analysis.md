# Sensitivity Analysis

Seed variation was evaluated across five independent simulation seeds using the logistic-regression classifier on a reduced cohort (24 participants per class).
Mean macro-AUC = 0.905 ± 0.025 (95% CI ± 0.031).

A ±20% perturbation of EEG channel count produced the following PCI surrogate values:
- 26 channels: PCI = 0.370
- 32 channels: PCI = 0.229
- 38 channels: PCI = 0.146
