# Literature Search Strategy

## Research Topic
AI-automated Life Cycle Assessment (LCA): NLP-based process tree construction, Ecoinvent matching, uncertainty propagation, hotspot analysis, Scope 3 estimation, EV battery case study

## Search Databases
- Semantic Scholar (MCP: `SemanticScholar_search_papers`) — 429 rate limit encountered; retried
- Fatcat/Internet Archive Scholar (MCP: `Fatcat_search_scholar`) — returned empty results
- CORE API (MCP: `CORE_search_papers`) — API error 500
- Web Search (fallback) — successful

## Inclusion Criteria
- Published 2016–2024
- Peer-reviewed journal or conference paper / reputable preprint
- Topic: LCA automation, ML/NLP for LCA, uncertainty propagation in LCA, EV battery LCA
- English language

## Exclusion Criteria
- Pure theoretical papers with no quantitative results
- Papers not addressing LCA directly
- Papers before 2016 (except foundational ecoinvent reference)

## Date Range
2016–2024 (with 2020–2024 emphasis)
