# Reference List

## Search attempts
- MCP/ToolUniverse attempted first: `SemanticScholar_search_papers` twice (both returned HTTP 400 through the MCP wrapper), `PubMed_search_articles` succeeded, and `Crossref_search_works` succeeded but produced noisy broad matches for generic queries.
- Fallback attempts with public REST APIs: direct Semantic Scholar `paper/search` request returned HTTP 429 (rate limit) without an API key; therefore PubMed E-utilities results were used as the primary evidence source and Crossref was retained as a DOI/metadata backup.
- Search period: 2020-01-01 to 2025-12-31. Language: English. Screening limitation: single-reviewer screening.
