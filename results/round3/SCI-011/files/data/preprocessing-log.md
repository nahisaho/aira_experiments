# Preprocessing Log

Synthetic BOLD data were generated with latent resting-state networks, global drift, respiratory contamination, temporal autocorrelation, and sparse spikes. Each subject then underwent simulated MCFLIRT-style motion correction, band-pass filtering (0.01-0.1 Hz), and nuisance regression using motion, derivative, white-matter, and CSF terms. Structural connectivity used simulated eddy/BET/dtifit-surrogate processing before probabilistic tractography parameterization.
