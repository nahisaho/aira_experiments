# Literature Search Strategy

## Approach
Attempted ToolUniverse MCP tools (SemanticScholar_search, PubMed_search, Crossref_search_works). MCP server not available in this runtime, so fell back to curated knowledge of the field combined with Semantic Scholar / Crossref REST APIs for DOI verification.

## Keyword Sets
1. "dark matter direct detection WIMP axion"
2. "neutrino floor coherent scattering dark matter"
3. "directional dark matter detection CYGNUS MIMAC"
4. "annual modulation dark matter detection"
5. "dark photon primordial black hole direct detection"
6. "xenon argon germanium dark matter target"
7. "background reduction dark matter experiment"

## Inclusion Criteria
- Peer-reviewed or major preprint (arXiv) papers on DM direct detection
- Recent flagship experimental results (LZ, XENONnT, PandaX, DarkSide, SuperCDMS, COSINE-100, ANAIS)
- Theoretical frameworks for neutrino floor, directional detection, multi-target complementarity
- ≥30% from 2020 onward
