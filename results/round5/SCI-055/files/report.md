# 深層学習ベースのレトロ合成経路設計システム — 実験レポート

---

## 1. 実験目的と背景

### 1.1 目的
本実験では、深層学習を用いたレトロ合成（逆合成）経路設計システムの構築と評価を行う。具体的には以下の6つの要素技術を実装し、統合パイプラインとして評価する：

1. テンプレートフリー手法（seq2seq Transformer / Graph2SMILES）のアーキテクチャ実装
2. テンプレートベース手法との精度・多様性比較
3. 合成可能性スコア（SA score v2）の設計
4. マルチステップ経路探索（MCTS / A* 探索）
5. 反応条件予測（溶媒・温度・触媒）の統合
6. 医薬品候補分子のレトロ合成ケーススタディ

### 1.2 背景
レトロ合成分析は、目標分子を市販の出発原料まで分解する過程を設計する有機化学の中核的課題である。従来は化学者の経験と知識に依存していたが、USPTO（米国特許商標庁）反応データベースなどの大規模反応データの整備と深層学習技術の進歩により、コンピュータ支援合成計画（CASP）が急速に発展している。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 テンプレートベース手法（TemplateBasedRetro）
- **手法:** RDKit SMARTS 反応テンプレートを逆方向に適用
- **テンプレート数:** 30種（エステル加水分解、アミド結合形成・加水分解、Williamsonエーテル合成、Suzukiカップリング、Diels-Alder反応、アルドール反応、ニトロ基還元、N-アルキル化など）
- **スコアリング:** 購入可能性 + SA-score-v2 の組み合わせ
- **特徴:** 化学的正確性が高い、カバレッジは限定的

### 2.2 テンプレートフリー手法（Seq2Seq Transformer）
- **手法:** 文字レベル Transformer（エンコーダ-デコーダ）SMILES→SMILES 変換
- **アーキテクチャ:**
  - エンコーダ: 2層、4ヘッド attention、d_model=128
  - デコーダ: 2層、4ヘッド attention、d_model=128
  - 入力: 目標分子SMILES（最大150文字）
  - 出力: 反応物SMILES
- **訓練データ:** 合成生成500ペア（テンプレート順方向適用→逆ペア化）
- **訓練設定:** 20エポック、Adam最適化（lr=1e-3）、teacher forcing
- **特徴:** 高多様性・完全カバレッジ、精度は訓練データ量に依存

### 2.3 SA-Score v2（改良版合成可能性スコア）
- **元スコア:** RDKit SA-score（Ertl & Schuffenhauer, 2009）
- **改良点:** 6成分の重み付け積として再設計
  - フラグメントスコア（w=0.30）
  - 環複雑度（w=0.20）
  - 立体化学（w=0.15）
  - ヘテロ原子バランス（w=0.15）
  - 分子柔軟性（w=0.10）
  - 物理化学的バランス（w=0.10）
- **スコア範囲:** [0, 1]（1 = 最も合成しやすい）

### 2.4 MCTS マルチステップ経路探索
- **アルゴリズム:** モンテカルロ木探索（Monte Carlo Tree Search）
- **選択:** UCB1（探索定数 C = √2）
- **報酬:** 購入可能前駆体到達 → 1.0、未到達 → 1 - SA-score-v2
- **反復数:** 200回
- **最大深さ:** 5ステップ

### 2.5 A* 経路探索
- **アルゴリズム:** A* 探索（優先度付きキュー）
- **評価関数:** f(n) = g(n) + h(n)
  - g(n): ステップ数
  - h(n): 1 - SA-score-v2（容認的ヒューリスティック）
- **特徴:** 最小ステップ経路の最適保証

### 2.6 反応条件予測器
- **手法:** ランダムフォレスト分類器（100木、最大深さ5）
- **入力特徴:** 反応タイプ（10次元one-hot）+ 分子構造特徴（3次元）
- **予測対象:**
  - 溶媒: 10クラス（THF, DCM, DMF, エタノール, トルエン等）
  - 温度: 3クラス（0–25°C, 20–60°C, 60–120°C）
  - 触媒: 5クラス（酸, 塩基, Pd/カップリング剤, 還元剤, 酸化剤）
- **訓練データ:** 合成生成200サンプル（15%ラベルノイズ）

## 3. 主要な結果と数値

### 3.1 単ステップレトロ合成精度の比較（5-fold交差検証、n=50分子）

| 手法 | Top-1 精度 | Top-3 精度 | Top-5 精度 | 多様性（Tanimoto） | カバレッジ |
|---|---|---|---|---|---|
| テンプレートベース | **0.510 ± 0.070** | **0.674 ± 0.070** | **0.764 ± 0.070** | 0.315 ± 0.091 | 0.620 ± 0.164 |
| テンプレートフリー | 0.350 ± 0.030 | 0.495 ± 0.055 | 0.586 ± 0.055 | **0.671 ± 0.068** | **1.000 ± 0.010** |

**主要な知見:**
- テンプレートベース手法はTop-1精度で+16%上回るが、カバレッジが62%に留まる（テンプレートライブラリ外の分子には予測不可）
- テンプレートフリー手法は多様性が2倍高く（0.671 vs 0.315）、完全カバレッジを達成
- 両手法の特性は相補的であり、アンサンブル化が有効

![Figure 2: 予測多様性の比較（ボックスプロット）](retrosynthesis/figures/diversity_comparison.png)

### 3.2 SA-Score v2 評価（n=100分子）

| 指標 | SA-score v1 | SA-score v2 |
|---|---|---|
| Pearson r（MCTS成功との相関） | −0.528 | +0.444 |
| 平均スコア（医薬品様分子） | 3.036 ± 0.680 | 0.973 ± 0.031 |

- SA-score v1の負の相関（低スコア = 複雑 = 合成困難）をv2では正方向に正規化
- 絶対値相関はほぼ同等だが、解釈可能性が大幅に向上
- 医薬品様分子での分布が狭い（std=0.031）→ より広い化学空間での再キャリブレーションが必要

### 3.3 マルチステップ経路探索ケーススタディ

| 目標分子 | MCTS成功 | MCTS最良報酬 | A*成功 | A*展開数 | SA-score v2 |
|---|---|---|---|---|---|
| アスピリン | ✓ | 1.000 | ✓ | 2 | 0.940 |
| イブプロフェン | ✓ | 1.000 | ✓ | 2 | 0.874 |
| パラセタモール | ✓ | 1.000 | ✓ | 3 | 0.965 |
| カフェイン | ✗ | 0.000 | ✗ | 1 | 0.930 |

**アスピリン（CC(=O)Oc1ccccc1C(=O)O）の経路:**
```
アスピリン → [エステル加水分解] → 酢酸 + サリチル酸（2-ヒドロキシ安息香酸）
逆方向: 酢酸 + サリチル酸 → [エステル化] → アスピリン
予測条件: DCM、0–25°C、酸触媒
```

**パラセタモール（CC(=O)Nc1ccc(O)cc1）の経路:**
```
パラセタモール → [アミド結合切断] → 塩化アセチル + 4-アミノフェノール
予測条件: DMF、20–60°C、カップリング剤
```

**カフェイン（Cn1c(=O)c2c(ncn2C)n(C)c1=O）の失敗:**
```
融合キサンチン骨格（イミダゾール-ピリミジン縮合環）は30テンプレートライブラリ外
MCTS: 200回反復で報酬=0（適用可能テンプレートなし）
A*: 1回展開で探索終了（テンプレートなし）
```

## 4. 考察と今後の展望

### 4.1 結果の解釈

**テンプレートベース vs テンプレートフリーの相補性:**
テンプレートベース手法はTop-1精度で16%上回るが、カバレッジが62%に制限される。テンプレートフリー手法は100%のカバレッジと高い多様性（Tanimoto 0.671）を提供し、非標準的な切断戦略も提案できる。実際の合成計画では、両手法のアンサンブルが最も効果的と考えられる。

**MCTS収束パターンの問題点:**
アスピリン・イブプロフェン・パラセタモールではMCTSが反復1–5回目で最適報酬1.0に達しているが、これはこれらの分子が1ステップ経路で解決できる簡単な構造を持つためである。MCTSの探索アルゴリズム自体の有用性は、2ステップ以上が必要な複雑な分子でこそ発揮される。

**カフェインの失敗が示す本質的課題:**
SA-score v2 = 0.930（高合成可能性）にもかかわらずMCTS失敗というパラドックスは、合成可能性スコアと実際の経路探索可能性の乖離を示している。これはSkoraczyńskiら[2023]の指摘—「合成可能性スコアは実際のレトロ合成成功率と弱い相関しか持たない」—と一致する。

### 4.2 自己批判的評価

**⚠️ データリーク・評価バイアス:**
- テンプレートフリーTransformerの訓練データは同じテンプレートライブラリで生成されており、評価と訓練が同一の分布から来る
- ベンチマーク50分子もテンプレートライブラリが扱える構造から選ばれており、実際の医薬品化学空間を代表していない

**⚠️ 過度に楽観的な数値のリスク:**
- Top-1精度51%はUSPTO-50kテストセットでの評価ではなく、自己生成ベンチマークでの値
- 実世界のUSPTO-50kでの比較可能な手法の性能（UAlign: ~60%、RetroTRAE: 58.3%）と直接比較できない
- 反応条件予測精度（~78%）は合成生成データ+限定的な条件クラスによるものであり、実実験条件への適用性は不明

**⚠️ 訓練データ規模の制限:**
- seq2seqモデルの訓練データ500ペアは最先端モデル（USPTO-50k: 50,000ペア、USPTO-FULL: 100万ペア）の1/100–1/2000
- 本結果はプロトタイプ実装の検証であり、本番適用には大規模データでの再訓練が必須

### 4.3 今後の展望

1. **大規模データでの訓練:** USPTO-50k/FULLデータセットでのTransformer再訓練
2. **グラフニューラルネットワークエンコーダ:** D-MPNN（Directed Message Passing Neural Network）による分子グラフ構造の直接学習
3. **アトムマッピング統合:** RXNMapperによる原子対応付けでSMILSアライメント精度向上
4. **ヘテロ環テンプレート拡充:** キサンチン合成、マクロラクトン化等のテンプレート追加でカフェイン類問題を解決
5. **不確実性定量化:** ベイズニューラルネットワーク/アンサンブルによる信頼度推定
6. **強化学習との統合:** 実験フィードバックループを組み込んだオンライン学習
