# 実験レポート：生態系サービスの経済的価値評価統合フレームワーク
## — 里山生態系を対象としたInVEST/選択実験/SEEA-EAパイプラインの設計と実施 —

---

## 1. 実験目的と背景

### 1.1 研究目的

本実験は、里山生態系における生態系サービス（Ecosystem Services: ES）の経済的価値を定量評価するための統合フレームワークを設計・実施することを目的とした。具体的には以下の4つの方法論を一貫したパイプラインとして統合した：

1. **InVESTモデル（空間的ES定量化）**: 土地利用分類に基づく6種類のESの空間分布とその貨幣価値を推定
2. **選択実験（Choice Experiment: CE）**: 生物多様性・水質・文化的景観の3属性に対する支払意思額（WTP）を条件付きロジットモデルで推定
3. **SEEA-EA自然資本勘定**: 現状維持シナリオと保全政策シナリオの10年間ES価値推移を比較
4. **割引率感度分析**: 一定割引率とWeitzman型逓減割引率によるES現在価値の比較（世代間公平性の観点）

### 1.2 研究背景

日本の里山は、水田・雑木林・草地・水辺が複雑に入り組んだモザイク景観であり、食料供給・炭素固定・水質浄化・生物多様性保全・文化的価値など多様なESを提供する。しかし農村過疎化・高齢化による耕作放棄（2024年時点で水田は年1.5%減少トレンド）により、こうしたESが失われつつある。にもかかわらず、里山ESの統合的経済評価手法は確立されておらず、政策立案に必要な定量的根拠が不足している。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 先行研究調査（ToolUniverse MCP）

OpenAlexおよびCrossref APIを活用し、以下のキーワードで2020年以降の先行研究を調査した：
- "ecosystem services valuation InVEST spatial"
- "willingness to pay choice experiment ecosystem services biodiversity"
- "natural capital accounting SEEA ecosystem"
- "satoyama Japan land use ecosystem services"

収集した主要文献10件の知見を実験設計に反映した。

### 2.2 空間データ構造

| パラメータ | 設定値 |
|----------|-------|
| グリッドサイズ | 20×20セル（1セル=1 ha） |
| 総面積 | 400 ha |
| 土地利用区分 | 6区分（水田・畑地・二次林・草地・水辺・集落） |
| 標高勾配 | 50〜400 m（線形） |
| 空間ノイズ | σ=0.08（対数正規分布） |

### 2.3 InVEST型空間定量化

各セルのES量：
$$ES_{c,k} = \beta_{l,k} \cdot f(\text{elevation}_c) \cdot \epsilon_c, \quad \epsilon_c \sim \mathcal{LN}(0, 0.08^2)$$

貨幣換算係数（便益移転値）：

| ES種別 | 単価 |
|-------|-----|
| 食料供給 | ¥250/kg |
| 炭素固定 | ¥4,500/tCO₂ |
| 水資源調整 | ¥15/m³ |
| 土壌保全 | ¥120,000/指数単位 |
| 生物多様性 | ¥80,000/指数単位 |
| レクリエーション | ¥3,500/訪問 |

### 2.4 選択実験設計と推定

**実験設計**:
- 回答者数: N=450（シミュレーション）
- 選択セット数: 16セット/回答者
- 選択肢: オルタナティブA・B・オプトアウト（現状維持）
- 属性: 生物多様性（3水準）、水質（3水準）、文化的景観（2水準）、年間費用（5水準）

**真のパラメータ（シミュレーション基準値）**:
```
β_生物多様性 = 0.65
β_水質 = 0.55
β_文化的景観 = 0.80
β_費用 = -0.00025
β_ASC = 0.40
```

**推定手法**: 条件付きロジットモデル（ロジスティック回帰近似、5分割交差検証）

WTP推定式：
$$\text{WTP}_k = -\frac{\hat{\beta}_k}{|\hat{\beta}_\text{cost}|}$$

95%信頼区間: ブートストラップ法（B=500回）

### 2.5 SEEA-EA勘定

シナリオ設定：

| シナリオ | 水田 | 畑地 | 二次林 | 草地 |
|--------|------|------|--------|------|
| 現状維持(BAU) | −1.5%/yr | −1.2%/yr | +2.5%/yr | +0.8%/yr |
| 保全政策 | −0.5%/yr | −0.3%/yr | +1.2%/yr | +1.5%/yr |

### 2.6 割引率分析

- **一定割引率**: $r \in \{1\%, 2\%, 3\%, 5\%, 7\%, 10\%\}$
- **Weitzman逓減割引率**: $r_t = r_0 \cdot e^{-0.02t}$（長期的な世代間公平性を考慮）

## 4. 考察

### 4.1 主要知見の解釈

**InVEST vs. WTP乖離の意味**: InVESTによる合計価値（¥213百万/年）とCEによる集計WTP（¥37.6百万/年）の差は、方法論的に予測されるものである。InVESTは市場価格を含む便益移転値を使用するのに対し、CEは非市場的な非利用価値の限界的改善分を捉える。この補完性がまさに統合フレームワークの意義である。

**生物多様性WTPの高さ**: 文化的景観のWTP（¥2,971/世帯/年）が生物多様性（¥2,453/世帯/年）を上回った点は、Jo et al. (2020)による韓国の都市林研究と整合的であり、視覚的・審美的サービスへの相対的な強い選好を示唆する。

### 4.2 自己批判的評価

#### ❗合成データへの依存

本実験の最大の限界は、すべての結果が合成シミュレーションデータに基づいている点である。以下の問題が存在する：

1. **循環性**: CEデータはモデルが推定しようとする真のパラメータ（β値）をそのまま入力して生成されたため、高い回帰精度は当然であり、「実験の成功」とは言い難い
2. **土地利用係数の恣意性**: 生物物理的係数は文献から採用したが、日本の里山に特化した実測値との乖離が大きい可能性がある
3. **貨幣換算の不確実性**: 便益移転値は日本以外のコンテキストから転用しており、地域差・社会経済差を反映していない

#### ❗モデルの簡略化

- **混合ロジット未使用**: 実際のCEでは回答者間の選好不均質性を混合ロジットまたは潜在クラスモデルで明示すべきだが、本研究ではロジスティック回帰で近似した
- **InVESTモジュール不完全**: 年間水収支、土砂流出、栄養塩流出など重要モジュールが未実装
- **SEEA-EA簡略化**: 生態系状態勘定（生息地面積・質指数）が省略されており、完全なSEEA-EA適合には至っていない

#### ❗実世界への一般化可能性

- AUROCが0.726という値は合成データ上のもので、実際のCEデータでの性能は未検証
- 割引率感度分析は経済学的に意味ある示唆を含むが、実際の社会的割引率はコンセンサスがなく、倫理的・政治的判断を含む
- 保全政策の便益（¥8.3百万/年）は土地利用遷移率が実際の農業政策効果と一致する場合にのみ有効

### 4.3 先行研究との比較

本研究のWTP推定値（¥2,095〜¥2,971/世帯/年）は、Jo et al. (2020)の韓国都市林研究（KRW 12,176〜21,036/年 ≈ ¥1,300〜¥2,260/年）と概ね整合的であり、オーダーとしての妥当性を示す。ただし、都市・農村・生態系タイプの差を考慮した直接比較には慎重であるべきである。

### 4.4 政策的含意

1. **農業環境政策**: 保全政策シナリオのNPV（¥71百万、10年・3%割引）は、里山保全のための環境直接払いの費用対効果を示す指標となる
2. **グリーンボンド**: Weitzman型割引率の採用により、里山ESの長期価値は従来の評価の2倍以上となり、自然資本担保型金融商品の価格設定に影響する
3. **生物多様性クレジット市場**: WTPデータをSEEA-EA勘定に連携させることで、生物多様性ネットゲインクレジットの参照価格設定が可能
