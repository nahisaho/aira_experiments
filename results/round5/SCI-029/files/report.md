# SOA-RxNet: 都市大気中の二次有機エアロゾル生成メカニズム解析システム — 実験レポート

---

## 1. 実験目的と背景

### 1.1 研究背景

二次有機エアロゾル（Secondary Organic Aerosol: SOA）は、都市大気における微小粒子状物質（PM₂.₅）の主要成分であり、全有機エアロゾルの20〜80%を占める。SOAは揮発性有機化合物（VOC）の気相酸化によって生成される半揮発性・低揮発性有機化合物が気相から粒子相へ分配されることで形成される。主要な生物起源VOC前駆体としてはイソプレン（C₅H₈）やα-ピネン（C₁₀H₁₆）が挙げられ、人為起源前駆体としてはトルエン・キシレン等の芳香族炭化水素が重要である。

SOA形成の予測は以下の理由から困難である：
- **反応ネットワークの複雑さ**: 単一VOCが数百〜数千種の酸化中間体を生成
- **熱力学的非理想性**: 有機エアロゾル混合物における活量係数（γ≠1）
- **速度定数の不確かさ**: 大多数の大気ラジカル反応の測定データが不足

### 1.2 実験目的

本実験では、以下の6つのコンポーネントを統合した自動化学反応ネットワーク解析システム「SOA-RxNet」を設計・実装し、その性能を評価する：

1. **RMGベースの自動反応経路生成** — イソプレン・α-ピネン酸化ネットワーク
2. **UNIFAC/AIOMFACベースの気相-粒子相分配モデル** — 活量係数計算含む
3. **拡張Evans-Polanyi関係によるML速度定数予測** — GBM/RF/MLP比較
4. **大気箱モデル** — 24時間光化学シミュレーション（3シナリオ）
5. **Morris法による感度解析** — 主要支配パラメータの特定
6. **SOA収率予測** — 二成分Odumモデルによる前駆体別収率曲線

## 2. 使用した手法・アルゴリズムの概要

### 2.1 反応ネットワーク生成

RMG（Reaction Mechanism Generator）v3.0 [Liu et al., 2021] の反応ファミリーテンプレートを参考に、以下の反応クラスを実装した：

**イソプレン酸化ネットワーク（6反応クラス）**:
```
isoprene + OH → ISOP-peroxy (k = 1.00×10⁻¹⁰ cm³/molecule/s)
ISOP-peroxy + HO₂ → ISOPOOH + O₂ (k = 2.1×10⁻¹¹)
ISOP-peroxy + NO → MVK + MACR + HCHO + NO₂ (k = 9.1×10⁻¹²)
ISOPOOH + OH → IEPOX + HO₂ (k = 4.0×10⁻¹¹, 低NOx経路)
IEPOX + H⁺ → 2-methyltetrol (酸触媒水溶液反応)
MACR + OH → HMML (k = 2.9×10⁻¹¹, 高NOx経路)
```

**α-ピネン酸化ネットワーク（5反応クラス）**:
```
α-pinene + O₃ → pinic-acid + pinonic-acid + HOM (k = 8.66×10⁻¹⁷)
α-pinene + OH → APINOO (k = 5.37×10⁻¹¹)
APINOO → HOM (自動酸化, k_auto = 0.1 s⁻¹, 分岐比0.15)
HOM + HOM → HOM-dimer (k = 1×10⁻¹⁰, 付加反応)
APINOO + HO₂ → pinonic-acid (k = 1.8×10⁻¹¹)
```

NetworkXを用いて有向グラフとして実装し、次数中心性による主要中間体の同定を行った。

### 2.2 気相-粒子相分配モデル

**修正Raoult則（吸収分配法）**:
$$F_p = \frac{1}{1 + C^*/C_{OA}}, \quad C^* = \gamma \cdot P_{sat}^0 \cdot M_W / (RT)$$

**UNIFAC活量係数（簡略版）**:
$$\gamma = \gamma_{dry} \cdot [1 - 0.4 \cdot RH \cdot (O/C)], \quad \gamma_{dry} = \exp[2.5(1 - O/C)]$$

系の自己無撞着解をPicard反復法（50反復、緩和係数0.5）で求めた。

### 2.3 ML速度定数予測

**11次元特徴量ベクトル**:
$$\mathbf{x} = [n_C, n_H, n_O, n_{C=C}, n_{OH}, n_{C=O}, IP, \Delta H_{rxn}, n_{\alpha H}, \text{ring}, b]$$

**拡張Evans-Polanyi（Bell-Evans-Polanyi）関係**:
$$\log k = \log k_0 + \sum_i a_i x_i + \frac{\alpha_{BEP} \cdot \Delta H_{rxn}}{RT \ln 10}$$

合成訓練データ（n=300）を5-fold交差検証で評価。実験測定の不確かさを模倣したガウスノイズ（σ=0.15 log単位）を付加。

### 2.4 大気箱モデル

13化学種（OH, HO₂, O₃, NO, NO₂, イソプレン, α-ピネン, トルエン, 5種SOAトレーサー）の連立ODE系：
$$\frac{d[SOA]}{dt} = Y_{SOA}(f_{NOx}) \cdot k_{OH} \cdot [OH] \cdot [VOC] \cdot \frac{M_W}{24.45}$$

scipy.integrate.solve_ivp（LSODA法）で数値積分（rtol=10⁻⁶）。3シナリオ：都市夏季・郊外夏季・夜間。

### 2.5 感度解析（Morris法）

50軌跡、段階幅Δ=0.5で8パラメータを探索。Elementary Effect（EE）のμ*とσを計算：
$$EE_k = \frac{Y(\mathbf{x} + \Delta \mathbf{e}_k) - Y(\mathbf{x})}{\Delta}$$

### 2.6 SOA収率予測（二成分Odumモデル）

$$Y_{SOA}(C_{OA}) = \sum_{i=1}^{2} \frac{\alpha_i \cdot C_{OA}}{C_{OA} + C_i^*}$$

6前駆体システムについてCoa=0.1〜100 μg/m³の範囲で収率曲線を計算。

## 4. 考察と今後の展望

### 4.1 主要な知見のまとめ

本実験の最も重要な知見は以下の3点である：

1. **HOM二量体の支配的粒子相寄与**: C*≈0.0001 μg/m³のHOM二量体は、低エアロゾル負荷（<1 μg/m³）においても完全に粒子相に分配される。これはα-ピネンオゾン分解由来の超低揮発性有機物（ELVOC）がSOA核形成・初期成長に決定的な役割を果たすことと一致する。

2. **OH速度定数の感度支配**: Morris解析でk_OH（μ*=329）が最高感度パラメータとして特定された。これはOHラジカルがVOC酸化の「律速段階」として機能し、速度定数の不確かさ（1〜2 log単位）がSOA予測に直接伝播することを意味する。ML予測の高い優先度を支持する結果である。

3. **イソプレンSOAの相対的低さ**: 高排出量にもかかわらずイソプレンSOAの寄与は小さい（<0.5%）。これは低収率（Y≈0.025）と中揮発性の酸化生成物（IEPOX, C*≈0.4 μg/m³）に起因する。水相化学（IEPOX反応性取り込み）を含めると寄与は2〜5倍増加する可能性がある。

### 4.2 モデルの限界と前提条件への依存性

**合成訓練データへの依存**: ML速度定数予測は合成データ（SAR導出、n=300）で訓練されており、実測データへの一般化可能性は限定的である。特に双環式テルペン（α-ピネン、β-ピネン）と芳香族化合物で系統的過大予測（Δ≈1〜2 log単位）が観察された。

**簡略UNIFAC活量係数**: 使用したUNIFAC近似は完全なAIOMFAC計算の代替であり、液-液相分離、粘性制限拡散、無機成分との相互作用を無視している。ピニン酸（γ=3.65）の活量係数の過大評価により、実際には水性エアロゾル相に取り込まれる成分が気相に留まると誤予測される可能性がある。

**実世界への一般化可能性**: 箱モデルは希釈・乾湿沈着・鉛直混合を無視しており、24時間積算SOAは実観測値より過大評価傾向にある。地表O₃濃度の固定的な初期設定もオゾン分解反応の現実的な減衰を再現しない。

### 4.3 今後の展望

1. **GNNによる速度定数予測**: 分子グラフを入力とするGraph Neural Networkで手作業特徴量を排除
2. **完全AIOMFAC統合**: 液-液相分離・粘性エアロゾル・無機成分を考慮
3. **水相化学**: IEPOX反応性取り込み・グリオキサール水相反応の実装
4. **フィールド測定との比較**: SOAS 2013・BEACHON-RoMBAS・APHH-Beijing等のAMSデータとの定量比較
5. **3D CTMへの組み込み**: CMAQ・WRF-Chem等との連携による地域スケールシミュレーション
