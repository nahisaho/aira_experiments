# 実験レポート: 合成遺伝子回路自動設計・最適化フレームワーク

---

## 1. 実験目的と背景

### 1.1 研究目的

合成遺伝子回路の自動設計・最適化フレームワークを開発し、以下の6つの機能を統合実装することを目的とした：

1. **形式言語による回路仕様記述**（論理ゲート、フィードバック接続）
2. **部品カタログからのアセンブリ**（プロモーター、RBS、ターミネーター）
3. **確率的シミュレーション**（ギレスピーアルゴリズム + τリーピング）
4. **パラメータ不確実性下でのロバスト設計**
5. **遺伝的コンテキスト効果の予測と補正**
6. **トグルスイッチ/リプレッシレーターの再設計ケーススタディ**

### 1.2 研究背景

合成生物学における遺伝子回路設計は、論理ゲートによる回路記述（Cello, Nielsen et al. 2016）、SBOL標準によるデータ交換（McLaughlin et al. 2020）、確率的シミュレーションによる分子ノイズ評価（Gillespie 1977; Sequeiros et al. 2023）という3つの柱を中心に発展してきた。本研究ではこれらを統合した Pythonベースのオープンフレームワークを構築した。

### 1.3 先行研究調査結果

ToolUniverse MCPを用いた文献検索で特定した主要先行研究（2020年以降）：

## 2. 使用した手法・アルゴリズムの概要

### 2.1 部品カタログ（Parts Catalog）

E. coliの特性評価済み部品に基づくカタログを構築：

- **プロモーター** (5種): pTet, pLac, pCI, pLacI, pAraBAD  
  パラメータ: 最大転写速度 (α_max)、漏れ転写 (ε)、リプレッサーKd、Hill係数 (n)、コンテキスト因子
  
- **RBS** (5種): B0034, B0032, BCD2, BCD12, RBS30  
  パラメータ: 翻訳速度 (β_tl)、コンテキスト感受性 (s_rbs)

- **ターミネーター** (4種): L3S2P21, L3S2P55, ECK120029600, T1  
  パラメータ: 終結効率 (η)、リードスルーペナルティ (ρ)

### 2.2 形式言語による回路記述

`GeneDevice`（プロモーター→RBS→コーディング配列→ターミネーター）を最小単位として、`GeneticCircuit`クラスに複数デバイスを接続（抑制関係のエッジ）することで回路トポロジーを定義する。

**有効転写速度モデル（Hill関数型リプレッション）:**
```
α_eff([R]) = ε·α_max·c_p + (α_max·c_p - ε·α_max·c_p) · K_d^n / (K_d^n + [R]^n)
```

### 2.3 決定論的ODEモデル

**トグルスイッチ（Gardner et al., 2000）:**
```
du/dt = α₁/(1 + v^β) - u
dv/dt = α₂/(1 + u^γ) - v
```

**リプレッシレーター（Elowitz & Leibler, 2000）:**
```
dm_i/dt = -m_i + α/(1 + p_j^n) + α₀
dp_i/dt = -β(p_i - m_i)   (i,j: 循環インデックス)
```

積分法：scipy Radauソルバー（絶対/相対許容差: 10⁻¹⁰/10⁻⁸）

### 2.4 確率的シミュレーションアルゴリズム

**ギレスピー直接法 (SSA):**
- 反応プロペンシティ a_j を計算し、指数分布から次の反応時間を決定
- プロペンシティに比例した確率で反応 j を選択
- 化学量論ベクトルにより分子数を更新

**τリーピング（Cao et al., 2006）:**
- リープ条件 ε = 0.03 で時間ステップ τ を決定
- 各反応 j に対し Poisson(a_j·τ) 回発火
- 分子数の非負値保証（負値をゼロにクランプ）

### 2.5 ロバスト設計評価

- パラメータ不確実性 δ ∈ {5%, 10%, 15%, 20%, 30%, 40%} に対し
- 一様分布 U[p(1-δ), p(1+δ)] から N=200–300 サンプル
- 各サンプルでODEシミュレーション → 双安定/振動の判定

### 2.6 遺伝的コンテキスト効果モデル

アセンブリ順序 k における補正係数:
```
c_k = c_p,k · (1 - s_rbs,k · ρ_(k-1) · 10)
```
ρ_(k-1): 上流ターミネーターのリードスルーペナルティ

### 2.7 SBOLインスパイアードエクスポート

SBOL3仕様に基づくJSONシリアライズ：部品メタデータ（プロモーター・RBS・ターミネーター・リプレッサーID）、機能アノテーション（produces, repressed_by）、接続トポロジーを保存。

## 4. 考察と限界

### 4.1 双安定回路 vs. 振動回路のロバスト性の差

最も重要な発見はトグルスイッチとリプレッシレーターのロバスト性の根本的な差異である。トグルスイッチは10%のパラメータ不確実性でビスタビリティが49.3%に低下する一方、リプレッシレーターは15%まで100%の振動維持を示した。これはサドルノード分岐点近傍で動作する双安定スイッチの理論的な敏感性と一致する。

### 4.2 確率的シミュレーションの知見

リプレッシレーターの確率的振幅（34.2 a.u.）はODE振幅（57.96 a.u.）の約59%であった。この振幅減少は分子ノイズがリミットサイクル振動子に与える既知の影響（位相拡散、振幅縮小）と定性的に一致する。τリーピングはΩ=50–100程度の分子数では近似誤差を含む可能性があり、より正確な評価には正確なSSAまたはΩの増大が必要である。

### 4.3 ⚠️ 自己批判的評価

#### (a) 非現実的な最適化結果
パラメータ最適化（物理的制約なし）は完全に非現実的な解（α₁ = 55,414、On/Off比 = 5.5×10¹⁰）に収束した。これは実際のプロモーター最大転写速度（~300 mRNA/min）を大幅に超えており、代謝負荷を無視した人工的最適解である。実世界への適用には生物学的に妥当な制約境界と多目的コスト関数（性能 + 代謝負荷）が不可欠である。

#### (b) 無次元ODEモデルへの依存
本フレームワークの主要モデルはGardner/Elowitz型の無次元ODEであり、実際の分子速度定数（mRNA半減期、リボソーム占有率、プラスミドコピー数変動）を抽象化している。定量的予測（On/Off比の正確な値、振動周期）は実験値と2–10倍の乖離が予想される。

#### (c) コンテキスト効果モデルの単純さ
本研究のコンテキスト効果モデルはリードスルーとRBS感受性の1次線形結合に限定される。実際には、RBS近傍のmRNA二次構造、潜在的転写開始部位、インシュレーター要素の有効性、染色体位置効果など多くの因子が関与しており、定量的正確性は限定的である。

#### (d) 合成データの前提
全シミュレーションはin silicoデータに基づいており、実験データによる検証は行われていない。名義パラメータは教科書的な双安定性・振動を得るよう選択されており、実際の生物学的系の複雑さ（宿主コンテキスト依存性、経時変化、成長依存性）は反映されていない。

#### (e) 交差検証の解釈上の注意
提示した交差検証RMSEは、パラメータ推定の実際の性能指標ではなく、名義パラメータに微小ノイズを加えた「モデル評価」の指標である。実際のパラメータ同定問題はより困難であり、勾配なし最適化や大域的最適化が必要である。

### 4.4 今後の展望

1. **物理的制約付きの多目的最適化**（性能・ロバスト性・代謝負荷のトレードオフ）
2. **シーケンスレベルのツールとの統合**（RBSカルキュレーター、DNAWeaver）
3. **実験データによるパラメータキャリブレーション**（蛍光時系列データ）
4. **より大きな分子数でのSSAシミュレーション**（τリーピング近似誤差の低減）
5. **ホスト資源競合モデルの組み込み**（転写・翻訳機械の共有リソースとしてのモデリング）
