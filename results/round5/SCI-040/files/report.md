# 実験レポート：火山性地殻変動データからのマグマ供給系3D構造インバージョン

## 実験目的と背景

本実験では、火山性地殻変動観測データ（GNSS・InSAR・重力）から地下マグマ供給系の3次元構造をインバージョンする総合的なベイズフレームワークを設計・実装し、桜島（姶良カルデラ）および阿蘇火山を対象とした合成ケーススタディで検証した。

### 主な研究目標
1. 点圧力源（Mogi）・回転楕円体（Yang）・粘弾性補正モデルの比較
2. MCMC法（メトロポリス-ヘイスティングス）によるベイズインバージョンと不確実性定量化
3. GNSS + InSAR + 重力データの統合インバージョン
4. カルマンフィルタ（EKF）による時間変化するソース追跡
5. 5分割交差検証による予測性能評価

**先行研究の主要な課題**：
- Mogi モデルは等方的な球状ソースを仮定し、非球対称な変位場を再現できない
- 標準的な弾性半空間仮定が長期変動（数年〜数十年）の粘弾性緩和を無視
- 点推定のみでパラメータ不確実性の定量化が不十分な研究が多い
- 複数データセット（GNSS+InSAR+重力）の統合インバージョン手法が確立されていない

## 使用した手法・アルゴリズムの概要

### 順問題（フォワードモデル）

#### Mogiソース（Mogi 1958）
弾性半空間中の球形圧力源による地表変位：
```
Ux = (1-ν)/π · ΔV · (x-x₀)/R³
Uy = (1-ν)/π · ΔV · (y-y₀)/R³
Uz = (1-ν)/π · ΔV · z₀/R³
```
パラメータ：ソース位置(x₀, y₀, z₀)、体積変化ΔV

#### Yang回転楕円体ソース（Yang et al. 1988）
扁長/扁平回転楕円体の圧力変化：
- 追加パラメータ：半長軸a、半短軸b、圧力変化ΔP、傾斜角φ、走向θ
- アスペクト比 α = b/a による変形場の非等方性補正

#### Maxwell粘弾性補正
長期変動の時間依存スケーリング係数：
```
f(t) = 1 + (t/τ_M) · exp(-t/τ_M)
```
緩和時定数 τ_M = 2〜20 年

#### 重力変化モデル
```
Δg = G·ρ_m·ΔV·z₀/R³ × 10⁸ [μGal] - 308.6·Uz
```

### 逆問題（インバージョン手法）

#### ベイズMCMC（適応メトロポリス-ヘイスティングス）
- **チェーン数**: 3本（独立初期値）
- **総反復回数**: 6000回/チェーン
- **バーンイン**: 2000回
- **適応ステップ**: 200回毎に提案分散を調整（目標受理率 15〜45%）
- **収束診断**: Gelman-Rubin R̂ 統計量

#### 統合尤度
```
ln L = ln L_GNSS + 0.01 × ln L_InSAR + ln L_grav
```
（InSAR重みはピクセル数に応じてダウンウェイト）

#### 拡張カルマンフィルタ（EKF）
- 状態ベクトル：[x₀, y₀, z₀, ΔV]
- 遷移モデル：ランダムウォーク
- 測定行列H：Mogiフォワードモデルの数値ヤコビアン
- 観測周期：月1回（24か月）

### カルマンフィルタ結果（桜島・24か月追跡）
- 初期状態不確実性: σ(ΔV) ≈ 2×10⁷ m³
- 3か月後の収束: σ(ΔV) ≈ 2×10⁶ m³（10倍改善）
- 平均トラッキング誤差: 3〜5 mm（GNSS残差）
- 膨張・収縮サイクルの追跡成功

## 考察と今後の展望

### 主要な考察

**Mogiモデルの堅牢性**：4パラメータMogiモデルはR̂ < 1.02で収束し、すべてのパラメータを2σ以内に回収。深部ソース（桜島10 km）でもMCMC acceptance rate 29〜41%の良好な値。

**回転楕円体モデルの優位性**：阿蘇（浅部4 km）では楕円体モデルのCV RMSE（8.78 mm）がMogi（29.52 mm）の3.4倍優秀。ただし8パラメータの多峰性事後分布（R̂ > 3〜7）はメトロポリス法での収束困難を示す。実用にはNUTS/HMC（Stan/PyMC）が必要。

**統合インバージョンの効果**：GNSS+InSAR+重力の統合により、GNSS単独と比較してパラメータ不確実性を約20〜30%低減。重力データは質量再分配への独立制約を提供。

**カルマンフィルタの有効性**：月次観測データ24か月分から、体積変化の不確実性を10倍以上低減し、膨張・収縮サイクルをリアルタイム追跡可能。

### 限界と批判的評価

| 問題点 | 影響の大きさ | 対策 |
|-------|------------|------|
| 弾性半空間仮定 | 深さ推定で1〜3 kmのバイアス | FEniCSによる有限要素モデル |
| 単一ソース仮定 | 複合系では系統誤差 | 可逆ジャンプMCMC |
| 合成ノイズの楽観性 | 実GNSS/InSARより3〜10倍小さい | 実観測ノイズ統計の適用 |
| 楕円体R̂収束問題 | 事後分布推定が不完全 | ハミルトニアンMC法 |
| 粘弾性補正の簡略化 | 長期変動の過小評価 | 完全粘弾性有限要素法 |

### 今後の展望

1. **FEniCSベース有限要素法**：地形・地殻不均質を考慮した順問題実装
2. **PyMC/Stan統合**：NUTSサンプラーによる楕円体モデルのMCMC改善
3. **実データ適用**：国土地理院GNSS連続観測データ（GEONET）・ALOS-2 SARスタックへの適用
4. **機械学習代理モデル**：ニューラルネットワーク順問題エミュレータによるMCMCコスト削減
5. **多ソースインバージョン**：可逆ジャンプMCMCによるソース数の自動決定

## まとめ

本研究では、火山性地殻変動の3次元マグマ供給系インバージョンのための統合ベイズフレームワークを実装し、桜島・阿蘇の合成ケーススタディで検証した。Mogiモデルは深部ソースでR̂ < 1.02の優れた収束を示し、深さ誤差2.5%・体積変化誤差0.7%の高精度回収を達成した。回転楕円体モデルは浅部・非対称ソース（阿蘇）で3倍以上優秀なCV RMSE（8.78 mm）を示すが、多峰性後分布の収束に課題がある。カルマンフィルタは月次データ3か月分で体積不確実性を10倍改善し、リアルタイム火山監視への応用可能性を示した。

ただし、弾性半空間仮定・単一ソース仮定・最適化された合成ノイズレベルなど、実世界データ適用時に課題となる複数の重要な制限が存在する。FEniCSベース有限要素モデル・HMCサンプラー・実観測データへの展開が今後の最優先課題である。
