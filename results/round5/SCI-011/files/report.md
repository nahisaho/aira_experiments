# 全脳コネクトーム解析パイプライン 実験レポート

---

## 1. 実験目的と背景

本実験では、fMRI（機能的磁気共鳴画像）とdMRI（拡散磁気共鳴画像）データから全脳コネクトームを推定・解析するパイプラインを設計・実装し、以下の目標を達成することを目的とした：

1. **前処理最適化**: 動き補正・歪み補正・空間標準化の最適パラメータ選定（高域通過フィルタカットオフ周波数の比較）
2. **構造的コネクティビティ（SC）推定**: 確率的トラクトグラフィーのプロキシモデルによる白質繊維トラクトの推定
3. **機能的コネクティビティ（FC）計算**: ピアソン相関・偏相関・動的FC（スライディングウィンドウ）
4. **グラフ理論解析**: スモールワールド性（σ）、モジュール性（Q）、クラスタリング係数（CC）、ハブ構造
5. **疾患バイオマーカー同定**: 統合失調症（SZ）とアルツハイマー病（AD）の分類
6. **テスト-リテスト信頼性評価**: ICC（級内相関係数）による再現性評価

---

## 2. 使用した手法・アルゴリズムの概要

### 2.1 アトラスと対象領域

- **アトラス**: Desikan-Killiany皮質アトラス（68 ROI）
- **モジュール数**: 6（視覚、体性感覚、辺縁、前頭、頭頂、側頭ネットワークに対応）
- **被験者数**: HC 40名、SZ 30名、AD 30名（合計100名）

### 2.2 データ生成（合成データ）

実際のFSL/FreeSurferパイプラインの設計に基づき、以下の合成データを生成：

**構造的コネクティビティ**:
- 被験者内モジュール内接続確率: p_w = 0.60
- モジュール間接続確率: p_b = 0.08
- 個人差ノイズ: σ = 0.15（ガウス分布）

**BOLD時系列**:
- T = 240 ボリューム、TR = 2秒（実効8分間）
- 呼吸雑音 (0.25 Hz, 振幅0.05) + 心拍雑音 (1.1 Hz, 振幅0.03) を付加
- 頭部動き (6パラメータ, σ = 0.03) を付加

**疾患グループの変調**:
| グループ | 変調 |
|---------|------|
| HC | なし（テンプレートSCに基づく） |
| SZ | モジュール内FC結合を70%に低減、モジュール間ノイズ増加 |
| AD | 全体FC結合を60%に低減、ハブ領域を追加50%低減 |

### 2.3 前処理パイプライン

```
生データ
→ デトレンド（線形ドリフト除去）
→ 帯域通過フィルタ（0.01–0.10 Hz、4次Butterworth）
→ スクラビング（FD > 0.5 mm フレームを除外、~5%）
→ 前処理済み時系列
```

**FSL実装相当**:
- `slicetimer`: スライスタイミング補正
- `mcflirt`: 動き補正（6自由度剛体変換）
- `topup` + `applytopup`: 位相エンコーディング歪み補正
- `flirt` + `fnirt`: MNI152標準空間への線形・非線形正規化
- `fslmaths`: 帯域通過フィルタリング

### 2.4 機能的コネクティビティ

| 手法 | 式 | 用途 |
|------|-----|------|
| ピアソン相関 | FC_ij = corr(x_i, x_j) | 静的FC（主解析） |
| 偏相関 | PC_ij = -Ω_ij / √(Ω_ii·Ω_jj) | 直接接続推定 |
| 動的FC | dFC_var_ij = std_k[FC_ij^(k)] | 時間的変動性 |

動的FC: ウィンドウ幅W = 40 TR（80秒）、ステップ幅10 TR

### 2.5 グラフ理論指標

```python
密度20%でコスト閾値処理 → NetworkXグラフ
→ 平均クラスタリング係数 CC
→ 平均経路長 L
→ スモールワールド指数 σ = (CC/CC_rand) / (L/L_rand)
→ モジュール性 Q（Louvainアルゴリズム）
→ ハブスコア（次数中心性80パーセンタイル以上）
```

### 2.6 分類（疾患バイオマーカー）

- **分類器**: SVM（RBFカーネル、C=1.0、γ='scale'）
- **特徴量セット**:
  1. グラフ特徴量（9次元）: [CC, L, σ, Q, hub_score, SC_CC, SC_σ, dFC_mean, dFC_std]
  2. FC行列特徴量（2,278次元）: 上三角行列
- **評価**: 5分割層化交差検証
- **指標**: AUC（AUROC）、正解率（ACC）、F1スコア（標準偏差付き）

### 2.7 テスト-リテスト信頼性

```
ICC(2,1) = (MS_B - MS_W) / (MS_B + MS_W)
```
HC 40名の再スキャンシミュレーション（σ_noise = 15%·σ_metric）

## 4. 考察と今後の展望

### 4.1 合成データの前提条件への依存

本実験の最大の限界は、**すべてのデータが事前に定義された疾患差異を持つ合成データ**から生成されている点である：

- HC_vs_AD のAUC = 1.000は、ADデータが「FC全体を60%に低減」というルールで生成されているためであり、実データでの疾患効果量（d ≈ 0.3–0.6）とは大きくかけ離れている
- ICC ≈ 0.99は再スキャンノイズを15%に設定したためであり、実際のHCP test-retestデータのICC（0.60–0.85）より過度に楽観的

### 4.2 実世界への一般化可能性

| 課題 | 合成データ | 実データへの影響 |
|------|----------|----------------|
| サンプルサイズ | n=30–40 / group | 高次元FC行列では過学習必至 |
| 多施設データ | 均質 | スキャナー差異の除去が必要（ComBat等） |
| 年齢・性別 | 統制 | 疾患コホートでの非均等性 |
| 薬剤効果 | なし | SZでの抗精神病薬FCへの影響 |
| 診断純粋性 | 完全 | 実際の診断は異質 |

### 4.3 パイプライン設計上の推奨事項（実実装向け）

1. **前処理**:
   - HP filter = 0.01 Hz（標準値）
   - FD閾値 = 0.5 mm for scrubbing
   - 最小有効スキャン時間: 10分（scrubbing後）
   - ICA-AROMAによる自動ノイズ成分除去

2. **SC推定（FSL BEDPOSTX）**:
   - 繊維集団数: 2–3
   - サンプル数: 5,000 seeds/voxel
   - ACT（解剖学的制約トラクトグラフィー）使用

3. **FC解析**:
   - 小標本（n < 100）ではFC行列より低次元グラフ特徴量を推奨
   - 動的FCには最低T = 600 TR（20分）が必要

4. **分類**:
   - p >> n環境でのFC行列分類にはL1正則化またはPCA前処理が必須
   - 独立したテストセット（外部検証コホート）でのAUC報告が必要

### 4.4 今後の展望

1. **グラフニューラルネットワーク（GNN）の活用**: BrainGB [Cui et al., 2022] のフレームワークを使用し、FCとSCを同時に学習するマルチグラフアーキテクチャ
2. **ノルマティブモデリング**: グループ比較ではなく個人レベルの偏差推定
3. **縦断的コネクトーム追跡**: 疾患進行に伴うネットワーク変化のモニタリング
4. **大規模公開データセットでの検証**: HCP、ABIDE（ASD）、ADNI（AD）、OpenNeuro

## 6. 先行研究の課題・限界と本研究の位置づけ

| 先行研究の課題 | 本パイプラインの対応 |
|--------------|-------------------|
| 前処理パラメータの非標準化 | HPフィルタカットオフの系統的比較を実施 |
| 動的FCの信頼性が不明確 | ICC評価を動的FC指標に適用 |
| 過度に楽観的な分類結果（AUC inflate） | 5分割CVを実施し自己批判的に限界を記述 |
| SC-FC統合の欠如 | グラフ特徴量にSC由来指標を含める |
| サンプルサイズ過小 | 合成データで定量的評価を実施し現実との乖離を明示 |
