# 脳オルガノイド大量培養のためのバイオリアクター設計と最適化
## 実験レポート

---

## 1. 実験目的と背景

### 1.1 研究背景

ヒトiPS細胞由来の脳オルガノイドは、神経発達・疾患モデル・創薬スクリーニングに革命をもたらす可能性があるが、大量製造に向けた以下の3つの根本的な課題が未解決である：

1. **酸素・栄養素の拡散限界**：直径400〜500 μmを超えるオルガノイドに壊死コアが形成される
2. **流体力学的不均一性**：スピナーフラスコ等の既存バイオリアクターにおけるせん断応力の不均一分布
3. **スケーラビリティの欠如**：バッチから連続培養への移行時に品質を維持しながら製造スケールを拡大する定量的フレームワークが存在しない

### 1.2 研究目的

本研究では、これらの課題に対処するための**統合計算フレームワーク**を開発し、以下の6つのコンポーネントを実装・評価する：

1. 灌流型バイオリアクターの流体力学シミュレーション（CFD相当）
2. 酸素・栄養素輸送の反応-拡散モデリング
3. せん断応力と組織成熟の関係モデリング
4. 培地組成の時間プログラム最適化
5. スケーラビリティ設計（バッチ→灌流→連続）
6. 成熟度評価のためのバイオマーカーモニタリング戦略

### 2.2 先行研究の課題・限界

1. **CFD研究**：大部分が2D/簡略化モデルであり、3D的な流れ場やオルガノイド間干渉を捉えていない
2. **反応-拡散モデル**：代謝パラメータの個体差・分化段階依存性が考慮されていない
3. **せん断応力研究**：脳組織特異的な二相性応答の定量的モデルが不足
4. **スケールアップ**：研究規模（0.001〜0.1 L）から製造規模（1〜10 L）への設計指針が欠如
5. **品質管理**：リアルタイム非侵襲モニタリングの実用的実装が限定的

## 3. 使用した手法・アルゴリズムの概要

### 3.1 CFD シミュレーション（Stokes流れ）

**数学モデル:**
```
∇p = μ∇²u   (Stokes方程式)
∇·u = 0      (非圧縮条件)
```

**実装:**
- グリッド: 40×20節点 (正規化領域 [0,1]×[0,0.5])
- 入口: 放物型プロファイル（ポアズイユ流）
- オルガノイド: 4個の球形障害物（ポテンシャル流れ偏向近似）
- せん断応力: τ = μ |∂u/∂y|

### 3.2 反応-拡散モデル（O₂輸送）

**球座標での定常方程式:**
```
D/r² · d/dr(r² · dC/dr) = Vmax·C/(Km + C)
```

**パラメータ（文献値）:**
| パラメータ | 値 | 単位 | 出典 |
|-----------|-----|------|------|
| D_O₂ | 2.0×10⁻⁹ | m²/s | 神経組織の実測値 |
| Vmax | 0.14 | mol/m³/s | 皮質神経細胞37°C |
| Km | 0.5 | mol/m³ | 哺乳類細胞の典型値 |
| C_surface | 0.21 | mol/m³ | 21%O₂/ヘンリー則 |

**数値解法:** 球座標中心差分FD法 (N=300節点)、ニュートン線形化、収束判定 10⁻⁹

**ダムケラー数:** Da = Vmax·R² / (D·Cs) → R=1mm: Da = 3,333 (反応支配)

### 3.3 せん断応力-成熟度モデル

```
S_mat(τ) = [τ/(τ_half + τ)] × exp(-(max(τ-τ_opt,0))² / (2σ_damage²))
```

パラメータ: τ_half=0.02 mPa, τ_opt=0.05 mPa, σ_damage=0.15 mPa

### 3.4 培地最適化ODEモデル

4状態変数ODE系 (V:体積, M:成熟度, N:壊死率, Glc:グルコース濃度):
```
dV/dt = kg·V^(2/3)·L_nutrient·(1-N)·(1-V/Vmax)
dM/dt = km·L_nutrient·(1-M)
dN/dt = kn·H(O2)·(1-N)
d[Glc]/dt = -kglc·V·(1-N)
```

**比較プロトコル:**
- バッチ培養: 培地交換なし（60日間）
- 半灌流: 7日ごとに50%交換
- 連続灌流: 3日ごとに80%交換

### 3.5 スケーラビリティ解析

3つの培養モード（バッチ/灌流/連続）について、0.01〜10 Lの範囲でオルガノイド収量・均一性・生存率をスケール則に基づいて投影。

### 3.6 バイオマーカーモニタリング

6種の神経成熟マーカー（SOX2, TUJ1, NeuN, MAP2, GFAP, CTIP2）のシグモイド型時間軌跡モデル（ガウスノイズ σ=5% 重畳）。予測モデル: 5種類のアルゴリズムを5分割交差検証で評価。

## 5. 考察と今後の展望

### 5.1 CFD結果の解釈

灌流型バイオリアクターでは、ポアズイユ流による入口設計とオルガノイド配置の最適化により、目標せん断応力範囲（0.01〜0.10 mPa）の達成が可能である。オルガノイド表面の局所最大せん断（~0.10 mPa）は損傷閾値（0.3 mPa）を下回るが、後流域の停滞（< 0.001 mPa）は栄養素供給の不均一性を引き起こす可能性がある。

**限界**: 本CFDモデルはStokes流れ近似の2Dモデルであり、3D的な流れの渦構造、オルガノイドの変形・凝集、複数オルガノイド間の流体力学的相互作用を捉えていない。OpenFOAM/COMSOLによる完全3D Navier-Stokes解析が次のステップとして必要である。

### 5.2 酸素輸送モデルの評価

Da = 302〜4,832という高ダムケラー数は、脳オルガノイドにおいて拡散が律速段階であることを定量的に確認する。R < 0.3 mmでは壊死なしに維持できるが、R = 1.0 mmでは体積の16.3%が壊死する。これはPantulaら（2025）[5]の実験的観察と定性的に一致する。

**限界**: Vmax値（0.14 mol/m³/s）は文献の中間値であるが、分化段階・細胞密度によって1〜2桁の変動がある。真の臨界半径は0.04〜0.4 mmの範囲にある可能性がある。

### 5.3 せん断応力モデルの評価

二相性モデルは最適せん断（0.05 mPa）で最大成熟度、過剰せん断（0.5 mPa）で急激な低下を示し、NeuN/MAP2の実験的発現プロファイルと定性的に一致する。しかし、モデルパラメータは実験データへのフィッティングではなく文献整合性に基づいており、定量的な予測精度には限界がある。

### 5.4 合成データへの依存性と実世界への一般化

本研究の全結果は**計算シミュレーションに基づく合成データ**から得られている。実験データへの適用に際しては以下を考慮する必要がある：

1. **バイオリアクター収量の過大評価**: 投影値（10 L: 100,000個）は現実の報告値（2 L: 500〜5,000個）を3〜10倍上回る可能性がある
2. **予測モデルの性能低下**: 実験データでの期待AUROC: 0.75〜0.85（合成データ比較比-0.05〜-0.15）
3. **モデルパラメータの不確実性**: 生物学的パラメータの変動範囲が各予測に大きく影響する

### 5.5 OpenFOAM/COMSOL連携設計

本研究のPythonベース計算フレームワークは、以下のOpenFOAM/COMSOLワークフローへの直接移行が可能：

**OpenFOAM設計:**
```
# simpleFoam (定常Stokes流れ)
U_inlet: 1e-3 m/s (Poiseuille profile)
p: zeroGradient (outlet)
turbulenceModel: laminar
solver: PCG (pressure), smoothSolver (velocity)
mesh: blockMesh (0.01 L chamber), snappyHexMesh (organoid STL)
```

**COMSOL Multiphysics設計:**
```
Module 1: Laminar Flow (cfg: Stokes, Re < 1)
Module 2: Transport of Diluted Species (O2, glucose, lactate)
  - Coupled Navier-Stokes + diffusion-reaction
  - MM kinetics: Vmax=0.14, Km=0.5 mol/m³
Module 3: Structural Mechanics (organoid deformation under shear)
Parametric sweep: flow rate [1e-5 to 1e-3 m³/s], organoid size [0.1-1.2 mm]
```
