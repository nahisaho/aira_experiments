# 食品テクスチャ予測モデリングフレームワーク — 実験レポート

**実験日**: 2026-05-29  
**テーマ**: 組成と加工条件からの食品テクスチャ予測：粘弾性モデル・乳化系・TPA予測・口腔内プロセシング・3Dフードプリンティング・植物性代替肉ケーススタディ  
**使用ツール**: Python 3.11 (NumPy, SciPy, scikit-learn, Matplotlib), Crossref API, NatureLM MCP, ToolUniverse MCP

---

## 1. 実験目的と背景

### 目的
食品の「テクスチャ（食感）」は消費者の受容性・栄養学的有効性・嚥下安全性に直結する重要な品質指標である。本実験では、食品組成（タンパク質・脂質・多糖類・水分含量等）および加工条件（温度・時間・pH）を入力として、テクスチャプロファイル分析（TPA）パラメータをはじめとする多様な食品テクスチャ特性を定量的に予測する**統合計算モデリングフレームワーク**を設計・実装した。

### 背景とモチベーション
1. **植物性代替肉の急成長**: 消費者の動物性食品代替需要に応えるためには、植物タンパク質を用いて牛肉・鶏肉に近いテクスチャを再現する定量的設計指針が必要。
2. **嚥下障害（Dysphagia）対応食品**: 高齢者の15%が嚥下困難を抱え、IDDSI基準に適合した食品設計にはゲルの凝集性・ボーラス形成速度の予測が不可欠。
3. **3Dフードプリンティング**: 食品インクのレオロジー特性（降伏応力・貯蔵弾性率・損失正接）から印刷性を事前予測できれば、試行錯誤コストを大幅削減できる。

## 2. 使用した手法・アルゴリズムの概要

### モジュール構成

| モジュール | 手法 | 主要モデル/アルゴリズム |
|---|---|---|
| M1: 多糖類ゲル粘弾性 | 連続体力学 | Maxwell / Kelvin-Voigt / 一般化Maxwell(Prony級数) |
| M2: 乳化系レオロジー | 流体力学 | Krieger-Dougherty / Herschel-Bulkley / Princen-Kiss |
| M3: TPA予測 | 機械学習 | Gradient Boosting / Random Forest / Ridge Regression (5-fold CV) |

## 4. 考察と今後の展望

### 4.1 主要な発見事項の解釈

**粘弾性モデル**: ゲル強度の階層 (アガー > κ-カラギーナン > ゼラチン > ペクチン > メチルセルロース > キサンタン) は基盤となるネットワーク構造を反映する。アガーは二重螺旋ジャンクションゾーン（永久ネットワーク）を形成し、ゼラチンは水素結合による三重螺旋（熱可逆）、キサンタンは真の架橋なしの液晶状絡み合いネットワークを形成する。

**乳化系レオロジー**: 液滴径の縮小は多糖類増粘剤の代替として機能しうる。d₃₂を10 μm → 1 μmに縮小することでG′を10倍増加させられるという予測は、ナノエマルション技術による質感設計の可能性を示唆する。

**植物性代替肉**: 最適配合は牛肉TPA参照値に対して全指標で6%以内の誤差を達成した。小麦グルテン (21.4%) と大豆タンパク質 (17.7%) の組み合わせは、市販植物性牛肉の典型的な配合（総タンパク質18–25%）と一致する。

### 4.2 自己批判的評価

#### 合成データへの依存
本フレームワークのML予測は**合成的に生成されたデータセット**で学習・評価されており、以下の重大な限界がある：
- 生成関数は平滑なガウスノイズのみを含み、実際の食品系の非ガウス変動・非線形相互作用を反映しない
- 実験データにおけるR²の現実的な期待値は **0.60–0.80**（原材料のロット間変動を考慮）
- 過学習リスク評価: 5分割CVの標準偏差（±0.007–0.025）は合成データの低ノイズを反映

#### 口腔内プロセシングモデルの簡略化
- 歯の形態・咬合力の個人差（3–5倍の変動）を無視
- 唾液α-アミラーゼによるデンプン消化（生物学的軟化）を未考慮
- 粘液素タンパクによる潤滑効果を未モデル化

#### CG-MDのアフィンネットワーク近似
- ゲルポイント近傍での非アフィン変形を無視
- ダングリングチェーン末端（弾性率に不寄与）の効果を未考慮
- 水素結合・疎水性相互作用などの動的架橋（寿命 < 1 ms）の時間依存効果を無視

### 4.3 実世界への一般化可能性

本フレームワークを実際の食品開発に展開するためには以下が必要：
1. **モジュールごとの実験的検証**: 特性評価された食品系との定量比較
2. **実験データによるファインチューニング**: N=50–100の実測TPAデータによる転移学習
3. **不確実性定量化**: ベイズニューラルネット/ガウス過程による予測不確実性評価
4. **感覚評価との相関**: 訓練されたパネルの官能評価とのキャリブレーション

### 4.4 今後の展望

| 優先度 | 課題 | 期待インパクト |
|---|---|---|
| 高 | 実験データセット構築（N≥200の実測TPA） | 現実的な予測性能評価 |

### B. 印刷性スコア計算式

$$P = 0.40 \times S_{retention} + 0.35 \times S_{extrudability} + 0.25 \times S_{geometry}$$

$$S_{retention} = \text{clip}\left(\frac{G' - 100}{600 - 100}, 0, 1\right)$$

$$S_{extrudability} = \text{clip}\left(1 - \frac{\tau_y}{450}, 0, 1\right) \times \text{clip}\left(\frac{P_{ext}}{200}, 0, 1\right)$$
