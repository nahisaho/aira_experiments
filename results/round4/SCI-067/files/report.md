# 実験レポート：AIによるライフサイクルアセスメント（LCA）自動化パイプライン
## EVバッテリー製造ケーススタディ（75 kWh NMC811）

---

## 1. 実験目的と背景

### 目的

本実験の目的は、製品・サービスのライフサイクルアセスメント（LCA）を自動化するAIパイプライン（**AutoLCA**）を設計・実装・検証することである。特に以下の技術課題に取り組む：

1. **NLPベースのプロセスツリー自動構築**：部品表（BOM）テキストからEcoinvent類似データベースへの自動マッチング
2. **Ecoinventデータベースとの自動マッチング**：TF-IDF余弦類似度によるプロセス名対応付け
3. **不確実性伝播**：Monte Carlo法（n=10,000）および一次テイラー展開法の両手法実装と比較
4. **ホットスポット分析**：GWP寄与度のパレート分析による主要排出源特定
5. **Scope 3排出量の効率的推定**：キーワードベースの自動スコープ分類
6. **シナリオ比較の自動生成**：電力グリッド強度・リサイクル率・輸送効率の5シナリオ分析

ケーススタディとして **EV用75 kWh NMC811電池パック**の製造段階LCAを実施した。

### 背景

LCAはISO 14040/14044に準拠した環境影響評価の標準手法であり、製品の炭素フットプリント定量化、エコデザイン意思決定、EU製品環境フットプリント（PEF）規制対応などに不可欠である。しかし従来手法では専門家による数週間の手作業が必要であり、サプライチェーンの複雑化・炭素会計義務化の進展に対応しきれない。

特にEVバッテリー製造はLCAが最も活発に研究される分野の一つであり、Yang et al. (2022)・Koroma et al. (2022)らの先行研究により、75 kWh NMC系電池パックの製造段階GWPは**9,000〜12,500 kg CO₂eq**（中国グリッド条件）と報告されている。本実験ではこの文献値を検証基準とし、自動化パイプラインの定量的妥当性を評価する。

### 先行研究の課題・限界

1. **手動データ収集の依存性**：すべての先行研究においてインベントリデータは専門家が手動収集
2. **再現性の低さ**：BOM→プロセスマッチングの判断基準が非明示的
3. **不確実性の過少報告**：標準偏差なしの点推定のみ報告が多い（Heijungs 2019が批判）
4. **Scope 3の粗い扱い**：上流Scope 3を単一集計値として処理し、内訳が不明
5. **シナリオ探索の限定性**：2〜3シナリオのみで感度空間の網羅が不十分

## 4. 使用手法・アルゴリズム概要

### 4.1 NLP自動マッチング

```
入力テキスト → TF-IDF変換 → 余弦類似度計算 → Top-K候補返却
sim(q, d) = (v(q)·v(d)) / (|v(q)|·|v(d)|)
```

5分割交差検証で精度評価（15個のground-truthペア使用）。

### 4.2 モンテカルロ不確実性伝播

```
各プロセスg_i ~ LogNormal(μ_i, σ_i²)
σ_i = √ln(1 + c_i²), μ_i = ln(|g_i|) - σ_i²/2
G^(k) = Σ_i g_i^(k), k=1,...,10000
```

### 4.3 一次テイラー展開

```
Var(G) ≈ Σ_i (∂G/∂g_i)² · Var(g_i) = Σ_i (g_i · c_i)²
```

### 4.4 ホットスポット分析

```
H_i = g_i / Σ_j g_j × 100%  [パレート寄与率]
```

### 4.5 スコープ分類

プロセス名のキーワードマッチングによる自動分類：
- Scope 1: "heat", "combustion", "natural gas"
- Scope 2: "electricity"
- Scope 3上流: "production", "separator", "binder", "electrolyte"
- Scope 3輸送: "transport"
- Scope 3 EOL: "recycling"

### 5.3 不確実性伝播結果

| 手法 | 平均 (kg CO₂eq) | 標準偏差 | P5 | P95 | CV |
|------|----------------|---------|-----|-----|-----|
| **Monte Carlo (n=10,000)** | **7,552.8** | **604.7** | 6,604 | 8,576 | 0.080 |
| Taylor展開 (1次) | 7,551.8 | 604.0 | 6,558 | 8,545 | 0.080 |
| 相対差異 | < 0.01% | < 0.12% | — | — | — |

両手法の一致度が極めて高い（平均偏差 < 0.01%）。線形集計系ではTaylor展開がMCの効率的代替となることを確認。90%信頼区間は[6,604, 8,576] kg CO₂eqで、変動係数CV = 0.08（±8%）。

![Figure 2: 不確実性伝播分析](figures/fig2_uncertainty.png)

Monte Carlo分布（Figure 2左）は右裾が厚く、対数正規分布の特性を反映。P5〜P95の区間幅は約1,972 kg CO₂eq（平均の±13%）。

## 6. 考察と今後の展望

### 6.1 文献値との比較検証

ベースラインGWP **9,880 kg CO₂eq（132 kg CO₂eq/kWh）**は、Yang et al. (2022)が報告するNMC811系電池の文献値レンジ（100〜167 kg CO₂eq/kWh）内に収まる。これは自動化パイプラインがNLPマッチング経由であっても物理的に整合した結果を生成できることを示す。

### 6.2 不確実性の評価

Monte Carlo CVは0.08（±8%）と比較的低い。これはLCA pedigree行列に基づくCV設定（0.08〜0.30）が適切にモデル化されているためである。Heijungs (2019)の警告（過剰なMC実行による偽精度）に従い、10,000回という実行数はテストケース数（15件）の667倍であり、入力分布の統計的信頼性が十分でない場合は結果の過信を戒める必要がある。

### 6.3 主要知見のまとめ

1. **最大排出源**: 硫酸ニッケル製造（28.9%）— NMC811の高ニッケル配合に起因
2. **最大レバー**: 製造電力の脱炭素化（グリッド強度の低減で最大20%削減）
3. **リサイクルの重要性**: 65%リサイクル率で約14%のGWP削減（−1,430 kg CO₂eq）
4. **Scope 3優位性**: 71.7%がScope 3 —工場ゲート対策だけでは不十分
5. **パイプライン妥当性**: NLP精度93.3%、MC/TE一致度99.99%以上で技術的信頼性を確認

### 6.4 AutoLCAの限界と課題

| 限界 | 影響 | 優先度 |
|------|------|--------|
| 簡易データベース（24プロセスのみ） | 未対応材料でマッチング失敗リスク | 高 |
| TF-IDFの語彙的限界 | 専門新材料の誤マッチング | 高 |
| 不確実性相関の無視 | Var(G)の過小/過大評価 | 中 |
| クレードル・トゥ・ゲートのみ | 使用段階・EOL完全評価不可 | 中 |
| 地理的解像度（国平均） | 地域間変動の見落とし（±15%） | 低 |

### 6.5 今後の技術ロードマップ

```
Phase 1 (〜6ヶ月): Brightway2完全統合、Ecoinvent 3.10 API接続
Phase 2 (〜12ヶ月): Sentence-BERTベース埋め込みマッチング導入
Phase 3 (〜18ヶ月): プロスペクティブLCA（将来グリッドシナリオ）自動化
Phase 4 (〜24ヶ月): ISO 14040準拠自動レポート生成、GHGプロトコル連携
```
