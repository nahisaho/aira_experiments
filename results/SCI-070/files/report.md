# 生態系サービスの経済的価値評価のための統合フレームワーク — 実験レポート

## 1. 実験目的と背景

本研究では、生態系サービス（Ecosystem Services: ES）の経済的価値を包括的に評価するための統合フレームワークを設計・実装した。従来の生態系サービス評価は、個別のサービスを独立に評価する手法が主流であり、空間的異質性、非市場価値、世代間公平性、国際統計基準との整合性が十分に考慮されてこなかった。

本フレームワークは以下の6つの要素を統合する：
1. 生態系サービス分類（供給・調整・文化的）の定量指標設計
2. InVESTモデルによる空間的サービス定量化
3. 支払意思額（WTP）推定のための選択実験設計
4. 割引率と世代間公平性の取り扱い
5. 自然資本会計（SEEA-EA）との連携
6. 里山生態系のサービス評価ケーススタディ

## 2. 使用した手法・アルゴリズムの概要

### 2.1 生態系サービス分類体系
CICES（Common International Classification of Ecosystem Services）に基づき、供給サービス（4項目）、調整サービス（5項目）、文化的サービス（4項目）の計13項目の定量指標を設計した。

### 2.2 InVESTモデルシミュレーション
Stanford大学Natural Capital Projectが開発したInVEST（Integrated Valuation of Ecosystem Services and Tradeoffs）モデルの以下のモジュールをシミュレーションした：
- **Carbon Storage**: 土地利用別の炭素貯留量（tC/ha）
- **Annual Water Yield**: 降水量・蒸発散に基づく水供給量（mm/yr）
- **Habitat Quality**: 都市域からの距離減衰を考慮した生息地質指数
- **Sediment Delivery Ratio (SDR)**: 侵食量・堆積物輸送（ton/ha/yr）
- **Crop Pollination**: 土地利用別の送粉サービス指数

空間解像度50×50グリッド（各セル4ha）、5種の土地利用（都市・農地・森林・湿地・里山）で実施した。

### 2.3 選択実験（Discrete Choice Experiment）
条件付きロジットモデル（Conditional Logit Model）を用いたWTP推定：
- **回答者数**: 500人（個人異質性を含むシミュレーション）
- **選択セット数**: 12セット/人、各3択（2代替案＋現状維持）
- **属性**: 生物多様性（4水準）、水質（3水準）、景観美（3水準）、レクリエーション（2水準）、費用（5水準：0〜5,000円/年）
- **推定手法**: 最尤法（Nelder-Mead最適化）

### 2.4 割引率分析
6つの割引率シナリオで100年間のNPV（正味現在価値）を比較：
- 市場利子率（5%）、社会的割引率（3%）、Stern Review（1.4%）
- Ramsey最適割引率（2.5%）、双曲割引（Weitzman型）、ゼロ割引

### 2.5 SEEA-EA自然資本会計
国連統計基準SEEA-EA（2021年採択）に準拠した以下の勘定を作成：
- **Ecosystem Extent Account**（生態系面積勘定）
- **Ecosystem Condition Account**（生態系状態勘定）
- **Monetary Supply-Use Account**（貨幣的供給使用勘定）

### 2.6 里山ケーススタディ
里山生態系について、シナリオ分析（5シナリオ）とTEV（Total Economic Value）分析を実施した。

- 生物多様性に対するWTPが最も高く（¥1,552/世帯/年）、文化的サービスへの社会的選好を反映している

### 3.4 割引率分析

![Figure 4: Discount Rate Analysis](figures/discount_analysis.png)

**100年間NPV比較（年間ES価値100万円/haの場合）：**
| 割引率シナリオ | NPV (百万円) |
|---------------|-------------|
| 市場利子率 (5%) | 20.8 |
| 社会的割引率 (3%) | 32.6 |
| Ramsey最適 (2.5%) | 37.6 |
| 双曲割引 (Weitzman型) | 29.4 |
| Stern Review (1.4%) | 54.6 |
| ゼロ割引 | 101.0 |

- 割引率の選択がNPVに約5倍の差をもたらす（20.8M vs 101.0M）
- 世代間公平性を重視するStern型（1.4%）では、市場利子率の2.6倍のNPVとなる
- 双曲割引は短期では市場利子率に近く、長期ではより低い実効割引率を示す

### 3.6 里山ケーススタディ

![Figure 6: Satoyama Case Study](figures/satoyama_case_study.png)

**里山の生態系サービス基準値：** ¥726,200/ha/年

**シナリオ分析結果：**
| シナリオ | ES価値 (千円/ha/年) | 変化率 |
|---------|-------------------|--------|
| 現状維持（里山管理継続） | 726.2 | 基準 |
| 農地への部分転換（50%） | 467.2 | -35.7% |
| 農地への全面転換 | 208.2 | -71.3% |
| 里山拡大（+25%） | 907.8 | +25.0% |
| 管理強化による再生 | 835.2 | +15.0% |

- 里山の農地転換は最大71.3%のES価値損失をもたらす
- 管理強化シナリオでは15%の価値向上が期待できる
- 文化的WTP（景観+レクリエーション）: ¥1,706/世帯/年

### 3.7 統合フレームワーク分析

![Figure 7: Integrated Framework Analysis](figures/integrated_framework.png)

- レーダーチャートにより、里山の多機能性が視覚化された（送粉・景観で最高値）
- トルネード感度分析では、割引率と土地利用変化がES総価値への影響が最大
- トレードオフ分析では、里山が食料生産と炭素吸収のバランス点に位置する
- 時系列予測では、積極的管理により2050年までにES価値が24%増加する見込み

## 4. 考察と今後の展望

### 4.1 主要な知見
- 本統合フレームワークは、InVESTの空間モデリング、選択実験による非市場価値評価、SEEA-EA会計基準を首尾一貫して連携させることに成功した
- 里山生態系は、個別サービスでは森林や湿地に劣るものの、多機能性の観点で最も高いバランスを示した
- 割引率の選択は長期的なES価値評価に根本的な影響を与え、政策決定において明示的な議論が不可欠である

### 4.2 限界と今後の課題
- 本実験はシミュレーションデータに基づいており、実測データによる検証が必要
- ARIES（人工知能ベース）モデルとの完全な統合は今後の課題
- 生態系サービス間の相互依存性・非線形性のより精緻なモデリング
- 気候変動シナリオ（RCP/SSP）との連携による動的評価
- 受益者分析（beneficiary analysis）と空間的サービスフローの明示化
