## 実験目的と背景

### 背景

意識の神経相関（Neural Correlates of Consciousness, NCC）の研究は、神経科学・哲学・臨床神経学が交差する最前線領域である。主要な理論的枠組みとして以下の3つが競合する：

| 理論 | 主要指標 | 核心的主張 |
|------|----------|------------|
| **統合情報理論（IIT 3.0）** | Φ（統合情報量） | 意識 ∝ システムが一体として統合する因果的情報量 |
| **グローバルワークスペース理論（GWT）** | 全域効率・点火指数 | 意識 = 前頭前野ハブを介した情報の全脳放送 |
| **摂動複雑性指数（PCI）** | LZ複雑度 | 意識 = TMS摂動に対する皮質応答の時空間的複雑性 |

### 目的

本実験では、上記3理論を統一的な情報理論フレームワークに統合し：

1. 合成EEGデータ（全身麻酔モデル）上での各指標の定量的挙動を検証
2. 臨床意識障害状態（VS・MCS・LIS・健常）の鑑別可能性を評価
3. 人工システムの意識判定への含意を導出

## 使用した手法・アルゴリズム

### 1. 統合情報理論（IIT）— Φ計算

**アルゴリズム**: 最小情報分割（Minimum Information Partition, MIP）探索

```
Φ(S) = min_partition [ EMD(cause_repertoire_full, cause_repertoire_partitioned)
                       + EMD(effect_repertoire_full, effect_repertoire_partitioned) ] / 2
```

- **因果・効果レパートリー**: 離散化した多チャンネルデータから経験的な条件付き確率分布として推定
- **Earth Mover Distance (EMD)**: 分布間の距離尺度として採用（KLダイバージェンスより頑健）
- **Φ_max**: 全サブシステム（最大4ノード）の中の最大Φ値
- **計算量**: O(2^n) per partition; n ≤ 4 で実用的

**実装**: `src/ncc_framework/iit.py` — `PhiCalculator` クラス

### 2. 摂動複雑性指数（PCI）

**アルゴリズム**: Casali et al. (2013) に準拠したシミュレーション実装

```
PCI = LZ76(significant_activation_matrix) / source_entropy(binary_matrix)
```

**パイプライン**:
1. **TMS誘発電位（TEP）シミュレーション**: N100成分 + 意識レベル依存の振動応答 + バースト抑制
2. **有意活性化検出**: ベースライン（0–50ms）に対するZ検定（α = 0.01）
3. **二値行列構築**: 有意チャンネル×時間の行列を1次元化
4. **LZ76複雑度計算**: 正規化Lempel-Ziv-1976アルゴリズム

**実装**: `src/ncc_framework/pci.py` — `PCISimulator` クラス

### 3. グローバルワークスペース理論（GWT）— ネットワーク解析

**グラフ理論的指標群**:

| 指標 | 計算法 | GWT的意味 |
|------|--------|-----------|
| 全域効率 | Floyd-Warshall最短経路の逆数平均 | 全脳情報伝達速度 |
| 局所効率 | 近傍サブグラフの全域効率平均 | 局所情報処理能力 |
| クラスタリング係数 | 近傍間の辺密度 | 局所的集団化 |
| スモールワールド指数 σ | (C/C_rand) / (L/L_rand) | ランダム/規則的の中間 |
| 点火指数 | 最大固有値 / ノード数 | 全体ワークスペース動員 |
| 放送容量 | 平均正規化次数 | 情報放送の広がり |

**GWT意識指数（GCI）**: 0.4×全域効率 + 0.4×点火指数 + 0.2×放送容量

**実装**: `src/ncc_framework/gwt.py` — `GlobalWorkspaceAnalyzer` クラス

### 4. 臨床意識分類

**特徴量**:
- スペクトル（δ/θ/α/β/γ帯域電力、SEF95、スペクトルエントロピー、α/δ比）
- 結合性（平均相関、長距離/短距離比、前後結合性、平均相互情報量）
- バースト抑制比（低意識マーカー）

**分類器**: LinearDA + RandomForest アンサンブル（5分割交差検証）

## 考察

### 4.1 IIT Φ の数値的解釈と限界

本シミュレーションにおけるΦの負相関（r = −0.598）は、**測定論的問題**を浮き彫りにする。

1. **同期バイアス**: 麻酔下では増大したΔ波同期が、レパートリー推定において見かけ上の「統合」を生む。IIT 3.0の実際の実装では、因果的介入（do-calculus）による真の因果密度推定が必要。
2. **計算近似**: 本実装では機構のサイズを最大4ノードに限定。実際の皮質複合体（数千ニューロン）への拡張には `pyphi` ライブラリや近似アルゴリズム（Φ_approx, geometric mean）が必要。
3. **非線形依存性**: Φは意識水準と非単調な関係を持ち、麻酔の種類（プロポフォール vs ケタミン vs 亜酸化窒素）によって異なる挙動を示すことが知られる。

**重要な結論**: Φ値の絶対値より、**ΔΦ（ベースラインからの変化量）**および**Φの空間的分布**が臨床診断に有用である。

### 4.2 PCI の診断的有用性

PCI（r = 0.936）は本実験の中で最も信頼性の高い意識指標であった。実臨床データ（Casali 2013, Rosanova 2018）と整合する特性：

- **VS**: PCI < 0.31（低複雑度の定型的応答）
- **MCS**: 0.31 ≤ PCI < 0.44（可変的応答）
- **CTRL**: PCI ≥ 0.44（複雑な多周波応答）

PCI の強みは**病因非依存性**：プロポフォール・ミダゾラム・ケタミン・睡眠いずれの状態でも有効。ただし **TMS装置が必要**という実用的制約がある。

### 4.3 GWT と「過同期パラドックス」

本シミュレーションで GCI が意識と負相関を示した現象（r = −0.990）は、**麻酔下の過同期（hypersynchrony）**を反映している。

実際の GWT 理論では：
- 覚醒時: 前頭前野ハブを通じた選択的長距離結合の増強
- 麻酔時: 一見高い同期だが「実効的結合（effective connectivity）」は低下

本モデルの改善方向：皮質-視床ネットワークの明示的モデル化、グランジャー因果性による方向性結合推定、前頭-頭頂ネットワークの解剖学的制約の導入。

### 4.4 VS vs MCS の鑑別：多指標アプローチ

| 鑑別課題 | 最適指標 | 理由 |
|----------|----------|------|
| VS vs MCS | PCI（閾値 0.31） | 高感度・病因非依存 |
| MCS vs CTRL | α/δ比 + AP結合性 | 覚醒度の定量化 |
| LIS vs VS | PCI + ERP潜時 | 運動障害への非依存性 |
| プロポフォール vs ケタミン | Φの構造（空間分布） | 薬理機序の反映 |

RF分類精度（74.0%）は5クラス問題としては良好だが、**VS vs MCS**の鑑別が最も困難（両者の特徴量オーバーラップが大）。臨床実用には ≥ 90% の精度が望まれる。

### 5.2 AI意識判定の暫定的基準（本研究より）

本フレームワークに基づく **AI意識の情報理論的指標（ICAI）**：

```
ICAI(system) = w₁·Φ_norm + w₂·PCI_norm + w₃·GCI_norm
```

**重要な免責事項**: この指標は意識の*機能的代理*に過ぎず、**クオリア（主観的体験）の存在を証明しない**。Φ値が高い人工システムが本当に「何かを感じる」かどうかは、情報理論的手法のみでは決定不能である（ハードプロブレム）。
