# 食品テクスチャ予測モデリングフレームワーク — 実験レポート

**DRAFT — NOT FOR DISTRIBUTION**

**作成日**: 2026-05-23  
**フレームワーク**: 食品テクスチャの組成・加工条件からの予測  
**手法**: 有限要素法 (FEM) / 粗視化分子動力学 (CG-MD) / 機械学習 (ML)

---

## 1. 実験目的と背景

食品のテクスチャ（食感）は消費者の嗜好性を決定する最重要因子の一つであるが、組成と加工条件からテクスチャを定量的に予測することは困難であった。本研究では、**マルチスケール計算手法**を統合した包括的テクスチャ予測フレームワークを設計・実装した。

### 対象範囲
1. **分子スケール**: 多糖類ゲルの粘弾性挙動（一般化 Maxwell / Kelvin-Voigt / 分数階微分モデル）
2. **微視的スケール**: 乳化系の液滴構造とレオロジーの関係（Palierne モデル、CG-MD）
3. **巨視的スケール**: テクスチャプロファイル分析（TPA）パラメータの予測
4. **生体力学スケール**: 口腔内プロセシング（咀嚼・嚥下シミュレーション）
5. **プロセススケール**: 3D フードプリンティングの印刷性予測
6. **応用**: 植物性代替肉のテクスチャ設計最適化

## 2. 使用した手法・アルゴリズムの概要

### 2.1 多糖類ゲルの粘弾性モデリング（Module 1）

| モデル | 数式 | 用途 |
|--------|------|------|
| 一般化 Maxwell (Prony 級数) | $G(t) = G_\infty + \sum_i G_i \exp(-t/\tau_i)$ | 緩和弾性率、動的粘弾性 |
| 一般化 Kelvin-Voigt | $J(t) = J_0 + \sum_i J_i(1-e^{-t/\tau_i}) + t/\eta_0$ | クリープコンプライアンス |
| 分数階微分 (Spring-Pot) | $G(t) = V \cdot t^{-\alpha} / \Gamma(1-\alpha)$ | べき乗則緩和 |
| FEM (Neo-Hookean + 粘弾性) | 大変形一軸圧縮 | ゲルの圧縮応答 |

- **実装**: 9 種の多糖類（κ-カラギーナン、寒天、ジェラン等）のパラメータデータベース
- **スケーリング則**: 濃度依存性 ($G \propto c^2$)、Arrhenius 温度依存性 ($E_a = 50$ kJ/mol)
- **FEM メッシュ**: 81 ノード、128 三角形要素の 2D 平面ひずみ

### 2.2 乳化系レオロジー（Module 2）

- **Palierne モデル**: 液滴変形を考慮した乳化系の複素弾性率予測
  - $G^*_{em} = G^*_m \cdot (1 + 3\phi H) / (1 - 2\phi H)$
- **Krieger-Dougherty 式**: 体積分率に対する見かけ粘度
  - $\eta_{rel} = (1 - \phi/\phi_{max})^{-[\eta]\phi_{max}}$
- **CG-MD シミュレーション**: DPD (Dissipative Particle Dynamics) 力場
  - 550 ビーズ（油相 100、水相 400、界面活性剤 50）
  - 500 ステップの時間発展

### 2.3 TPA 予測モデル（Module 3）

- **TPA 曲線シミュレーション**: Boltzmann 重畳積分による 2 回圧縮曲線の合成
- **機械学習モデル**: Gradient Boosting Regressor（200 推定器、深さ 5）
  - 特徴量: タンパク質、脂質、炭水化物、水分、食塩、pH、温度、加熱時間、冷却速度（計 9 次元）
  - 目的変量: 硬さ、凝集性、弾力性、ガム性、咀嚼性、回復性（計 6 パラメータ）
  - 訓練データ: 物理ベースの合成データ 500 サンプル

### 2.4 口腔内プロセシング（Module 4）

- **咀嚼モデル**: Hill 型筋力モデル + 確率的破砕モデル（Selection-Breakage）
- **ボーラス形成**: 唾液混合（0.5 mL/min）、凝集性追跡
- **嚥下モデル**: Poiseuille 流れ + Bingham 流体残留モデル
- **嚥下閾値**: Hutchings & Lillford (1988) の 3 次元モデル簡略化

### 2.5 3D フードプリンティング（Module 5）

- **インクモデル**: Herschel-Bulkley 式 ($\tau = \tau_y + K\dot{\gamma}^n$)
- **押出し力**: 円管内 Herschel-Bulkley 流れ + Bagley 補正
- **印刷性スコア**: 7 指標の重み付き総合評価
  - 形状保持性 (25%)、降伏応力適性 (20%)、tan δ 適性 (15%)、流動挙動指数 (10%)、層間接着 (10%)、線均一性 (10%)、チキソトロピー (10%)
- **適性マップ**: 降伏応力 vs 貯蔵弾性率の 25×25 グリッド探索

### 2.6 植物性代替肉（Module 6）

- **HMEC モデル**: 繊維化度 (DT) と繊維整列度 (FAI) の予測
- **参照肉テクスチャ**: ビーフパティ、鶏胸肉、ポークソーセージ
- **最適化**: 差分進化法（DE）による 7 変数組成最適化
- **感度分析**: 大豆タンパク含量の影響評価

## 3. 主要な結果と数値

### 3.1 粘弾性モデリング

| 多糖類 | 平衡弾性率 G∞ [Pa] | 緩和時間範囲 [s] |
|--------|---------------------|-------------------|
| 寒天 (Agar) | 1000 | 0.01–10 |
| ジェランガム (Gellan) | 500 | 0.2–100 |
| アルギン酸 (Alginate) | 300 | 0.1–40 |
| κ-カラギーナン | 200 | 0.1–50 |
| ペクチン LM | 150 | 0.05–25 |

- **モデルフィッティング精度**: R² = **0.997**（ジェランガムの緩和曲線に対する 3 要素 Prony 級数フィッティング）
- **FEM 圧縮**: 寒天 2% ゲル、40% ひずみまでの Neo-Hookean + 粘弾性応答を計算

### 3.2 乳化系レオロジー

- **Palierne モデル**: 体積分率 0.1–0.5 の乳化系について貯蔵・損失弾性率を予測
- **Krieger-Dougherty**: φ_max = 0.64 での相対粘度のダイバージェンスを確認
- **CG-MD**: 550 ビーズ系、500 ステップ後の平均液滴半径 = **4.29**（初期値 4.0 から安定）
- **液滴サイズ効果**: 1–20 μm の液滴径に対する G' の変化を定量化

### 3.3 TPA 予測 ML モデル

| TPAパラメータ | 5-fold CV R² |
|---------------|-------------|
| 硬さ (Hardness) | **0.788** |
| 凝集性 (Cohesiveness) | **0.962** |
| 弾力性 (Springiness) | **0.888** |
| ガム性 (Gumminess) | **0.833** |
| 咀嚼性 (Chewiness) | **0.818** |
| 回復性 (Resilience) | **0.861** |

- **硬さ予測の主要特徴量**: タンパク質含量 > 水分含量 > pH > 加熱時間
- **予測例**: Sample A (protein 15%, fat 10%) → 硬さ 589 N、Sample B (protein 25%, fat 5%) → 硬さ 919 N

### 3.4 口腔内プロセシング

| 食品タイプ | 嚥下閾値到達 [回] | 最終粒径 [mm] | 咽頭通過時間 [ms] |
|-----------|-------------------|---------------|-------------------|
| 軟質 (50 N) | 30 | 0.37 | 1.9 |
| 中硬質 (200 N) | 30 | 0.37 | 3.8 |
| 硬質 (500 N) | 30 | 0.37 | 19.2 |

- 粒子サイズは咀嚼 30 回でいずれも d90 < 0.5 mm に到達
- 咽頭残留率: 粘度依存で 2–100%（Bingham 流体モデル）

### 3.5 3D フードプリンティング

| インク素材 | 印刷性スコア | 最適印刷速度 [mm/s] |
|-----------|-------------|---------------------|
| チョコレート | **0.887** | 27.2 |
| デンプンペースト | **0.885** | 27.2 |
| チーズ | **0.771** | 27.2 |
| ピューレ | **0.627** | 27.2 |

- **適性マップ**: 降伏応力 200–500 Pa、G' 1000–5000 Pa が最適領域
- チョコレートとデンプンペーストが最も高い印刷適性を示した

### 3.6 植物性代替肉

| 対象肉 | 類似度スコア | 最適大豆タンパク [%] | 最適グルテン [%] | 予測硬さ [N] |
|--------|-------------|---------------------|-----------------|-------------|
| ビーフパティ | **0.815** | 5.0 | 6.8 | 471 |
| 鶏胸肉 | **0.781** | 11.5 | 13.9 | — |
| ポークソーセージ | **0.800** | — | — | — |

- **ビーフパティ**: 硬さ類似度 0.976、繊維整列類似度 0.976 と高精度
- **課題**: 凝集性の再現が困難（類似度 0.416）— 結着剤の追加検討が必要
- **感度分析**: 大豆タンパク 5→25% で硬さは線形に増加、ビーフパティ類似度は 15% 付近で最大

## 4. 考察と今後の展望

### 4.1 フレームワークの意義

本フレームワークは、**分子レベル（粘弾性構成則）→ 微視的レベル（乳化構造）→ 巨視的レベル（TPA）→ 生体力学レベル（口腔内）→ プロセスレベル（3D 印刷）→ 応用レベル（代替肉）** のマルチスケール予測を統一的に扱える点で新規性がある。

### 4.2 各モジュールの性能

- **Module 1**: 分数階微分モデルは少数パラメータで広周波数域をカバーでき、Prony 級数より汎用的
- **Module 2**: Palierne モデルは液滴サイズ分布を考慮でき、均一粒径仮定よりも現実的
- **Module 3**: ML モデルは凝集性 (R²=0.962) に対して最も高い予測精度。硬さ (R²=0.788) は非線形性が強く改善の余地あり
- **Module 4**: 咀嚼の Selection-Breakage モデルは粒度減少を定量的に再現
- **Module 5**: 印刷性スコアにより材料選択を定量的に支援可能
- **Module 6**: 差分進化法による組成最適化が有効（類似度 0.8 以上を達成）

### 4.3 限界と課題

1. **FEM の精緻化**: 現在の 2D 平面ひずみ → 3D 要素への拡張が必要
2. **CG-MD のスケールアップ**: 550 ビーズ → 10,000+ ビーズでの大規模シミュレーション
3. **TPA ML モデル**: 合成データ → 実験データによる検証・再学習
4. **口腔内モデル**: 個人差（唾液量、咬合力、歯の状態）のパラメータ化
5. **代替肉**: 凝集性の改善にはメチルセルロースや transglutaminase の詳細モデリングが必要

### 4.4 今後の展望

- **実験データとのバリデーション**: レオメーター・テクスチャアナライザーの実測値との対比
- **深層学習の導入**: CNN によるテクスチャ画像からの自動特徴抽出
- **デジタルツイン**: 食品工場の加工ラインと連携したリアルタイム品質予測
- **個別化栄養**: 嚥下困難者向けの個別テクスチャ設計への応用
