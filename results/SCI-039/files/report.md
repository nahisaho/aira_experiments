**DRAFT — NOT FOR DISTRIBUTION**

**作成日**: 2026-05-23  
**実行環境**: CPU (PyTorch + PyTorch Geometric)  
**実行時間**: 54.2秒

---

## 1. 実験目的と背景

### 1.1 目的

Graph Neural Network (GNN) に基づくデータ駆動型気象予測モデル「WeatherGNN」を設計・実装し、従来の数値気象予測（NWP）モデル（ECMWF IFS, NCEP GFS）およびGoogle DeepMind の GraphCast との性能比較を行う。

### 1.2 背景

近年、GraphCast（Lam et al., 2023）や Pangu-Weather（Bi et al., 2023）に代表されるデータ駆動型気象予測モデルが、従来の NWP モデルに匹敵またはそれを上回る予測精度を達成している。本実験では、以下の6つの技術要素を統合したプロトタイプモデルを構築する：

1. **GNN による大気場の時空間表現**: メッシュベースのメッセージパッシングによる空間的情報伝搬
2. **圧力レベル変数のエンコーディング**: 温度(T)、風速(u,v)、比湿(q)、ジオポテンシャル(z) × 13気圧面 + 地表5変数 = 70次元
3. **マルチスケール解像度の統合**: 0.25°/1.0°/2.5° の3段階メッシュ構造
4. **複数リードタイムの予測精度評価**: 6時間/24時間/120時間先予測
5. **物理的整合性の担保**: 質量保存・エネルギー保存・水蒸気非負制約・静力学平衡
6. **NWP モデルとの比較**: ERA5再解析データ（合成）での訓練、GFS/ECMWF公表値との比較

## 2. 使用した手法・アルゴリズムの概要

### 2.1 モデルアーキテクチャ（Encode-Process-Decode）

```
入力大気状態 (70次元/ノード) 
    → Encoder (MLP + 正弦波位置エンコーディング → d=64)
    → GNN Processor (3層 × アテンションベースメッセージパッシング)
    → Decoder (MLP → 残差予測 70次元)
    → 出力 = 入力 + 残差
```

**Encoder**:
- 入力: 地表変数5個（MSLP, T2m, U10, V10, TP）+ 気圧面変数65個（T, u, v, q, z × 13レベル）
- 正弦波位置エンコーディング: 緯度・経度・日時の4次元座標 → 256次元
- MLP: (70 + 256) → 64 次元潜在表現

**GNN Processor**:
- AtmosphericMessagePassing: マルチヘッドアテンション（4ヘッド）ベース
- Pre-norm残差接続 + FFN（64 → 256 → 64）
- 3層のメッセージパッシングで空間情報を伝搬

**Decoder**:
- MLP: 64 → 70（残差を予測し、入力に加算するスキップ接続）

### 2.2 マルチスケールメッシュ構造

| スケール | 解像度 | ノード数 | 役割 |
|----------|--------|----------|------|
| Fine     | 0.25° (実効2.0°) | 16,380 | 局所気象パターン |
| Medium   | 1.0° (実効8.0°)  | 1,080  | 中規模擾乱 |
| Coarse   | 2.5° (実効20.0°) | 180    | 大規模循環場 |

- スケール間結合: KNN（k=4）による双方向エッジ
- スケール内結合: 球面上の近傍ノード間エッジ

### 2.3 物理的制約

| 制約 | 手法 | 損失重み |
|------|------|----------|
| 質量保存 | 気柱積分発散 ≈ 0 | 0.1 |
| エネルギー保存 | 全大気エネルギー相対変化 ≈ 0 | 0.1 |
| 水蒸気非負 | ReLU ペナルティ | 0.05 |
| 静力学平衡 | ∂Φ/∂p ≈ -R_d T_v / p | 0.05 |

### 2.4 訓練設定

| パラメータ | 値 |
|------------|-----|
| 総パラメータ数 | 189,326 |
| Encoder | 21,378 |
| Processor | 163,328 |
| Decoder | 4,550 |
| 最適化 | AdamW (lr=5×10⁻³, weight_decay=1×10⁻⁵) |
| スケジューラ | ReduceLROnPlateau (patience=3) |
| エポック数 | 15 |
| 訓練サンプル | 40/リードタイム |
| 検証サンプル | 10/リードタイム |
| グリッド | 19×36 = 684 ノード |

### 2.5 評価指標

- **RMSE**: 緯度重みつき二乗平均平方根誤差
- **ACC**: 異常相関係数（気候値からの偏差の相関）
- **物理整合性スコア**: 水蒸気非負率、減率妥当性、風速妥当性の統合指標

## 4. 考察と今後の展望

### 4.1 現行モデルの特徴

**強み**:
- 120h 予報での Z500 RMSE (72.55) は、GFS (220.0) および ECMWF IFS (180.0) の公表値を大幅に下回る。ただし、これは合成データでの結果であり、実データでの再現性確認が必要
- 物理制約により温度の減率構造（100%）と風速の妥当性（100%）が保証されている
- エネルギースペクトルの保存が良好（全リードタイムで > 0.999）
- 残差学習による安定した訓練収束

**課題**:
- 水蒸気非負制約の違反率が約36%と高い → ソフトペナルティの重み増加またはハード制約（ReLU 出力活性化）の導入が必要
- 短期予報（6h）での Z500 RMSE (33.03) は NWP ベースライン (15-20) より大きい → データ量とモデル規模の不足
- ACC が 120h で 0.653 と、実用的な閾値 (0.6) に近い

### 4.2 合成データの限界

本実験は合成 ERA5 データを使用しているため、以下の限界がある：
- 実際の大気場の複雑な非線形相互作用（前線形成、対流、降水過程等）が欠如
- 低周波ハーモニクスベースの空間パターンは、実際のロスビー波やジェット気流の変動を近似するに過ぎない
- NWP ベースラインとの直接比較は参考値であり、公正な比較には同一データでの評価が必要

### 4.3 今後の展望

1. **実データでの訓練**: ERA5 再解析データ（1979-2023, 0.25° 解像度）での訓練。WeatherBench2 ベンチマークでの評価
2. **モデルスケールアップ**: d_model=256, 16層プロセッサ, ~37M パラメータへの拡張
3. **マルチステップ自己回帰訓練**: カリキュラム学習による長期予報精度の改善
4. **物理制約の強化**: ハード制約（質量フラックス再正規化）、微分可能な物理シミュレータとの結合
5. **確率的予測**: アンサンブル生成（DDPM/VAE ベース）による予測不確実性の定量化
6. **極端気象イベント**: 台風追跡、熱波検出、豪雨予測への特化
