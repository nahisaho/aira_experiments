## 1. 実験目的と背景

### 1.1 目的

衛星・ドローン画像、気象データ、土壌センサーデータを統合したマルチモーダル解析パイプラインを設計・実装し、日本の水稲栽培における以下の課題に対応する：

1. リモートセンシングによる作物生育モニタリングの自動化
2. プロセスベース作物モデルと機械学習の融合による収量推定の高精度化
3. 可変施肥（VRA）処方マップの自動生成による精密農業の実現

### 1.2 背景

日本の水稲栽培は高齢化・担い手不足に直面しており、ICT・AI技術を活用したスマート農業が求められている。特に新潟県は日本有数の米産地であり、コシヒカリの品質管理においてリモートセンシングと作物モデルの活用が注目されている。本研究では、Sentinel-2衛星画像（10m解像度）、気象観測データ、圃場内土壌センサーネットワークを組み合わせ、CNN-LSTMアーキテクチャによる収量マッピングと最適施肥設計を行うシステムを構築した。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 植生指数計算（Module 1）

衛星/ドローンのマルチスペクトル画像（NIR, Red, Blue, Green, Red Edge の5バンド）から以下の植生指数を算出した：

| 指数 | 算出式 | 用途 |
|------|--------|------|
| NDVI | (NIR - Red) / (NIR + Red) | 植生活性の基本指標 |
| EVI  | 2.5 × (NIR - Red) / (NIR + 6×Red - 7.5×Blue + 1) | 高密度植生での飽和回避 |
| SAVI | (1+L)(NIR - Red) / (NIR + Red + L), L=0.5 | 土壌背景の影響補正 |
| NDRE | (NIR - RedEdge) / (NIR + RedEdge) | 窒素状態の推定 |
| GNDVI | (NIR - Green) / (NIR + Green) | クロロフィル含量推定 |
| LAI  | 0.57 × exp(2.33 × NDVI) | 葉面積指数（経験式） |

シミュレーションでは、水稲の生育パターン（二重シグモイド曲線）を反映した200ピクセル×18時期のマルチスペクトル時系列データを生成した。

### 2.2 気象データ・作物モデル連携（Module 2）

**気象データ**: 新潟県（37.9°N, 139.0°E）の気候を模したデータを生成。梅雨期（6-7月）と台風期（8-9月）の降水パターン、日射量の季節変動を含む。

**作物モデル**: DSSAT/APSIMに準拠した簡易モデルを実装し、以下の要素を組み込んだ：

- **積算温度（GDD）**: 基準温度10°C、最適温度28°Cの温度応答関数
- **生育ステージ**: 移植(0)→分げつ(300GDD)→幼穂分化(900GDD)→出穂(1400GDD)→登熟(1700GDD)→成熟(2200GDD)
- **光合成モデル**: Beer則によるPAR吸収 + 放射利用効率（RUE = 1.0-1.3 g/MJ）
- **水ストレス**: 累積降水量/蒸発散量比に基づくストレス係数

### 2.3 土壌センサーデータの空間補間（Module 3）

30点の土壌センサーネットワークから、Ordinary Kriging法により圃場全体（500m×500m）を5m解像度で補間した。

測定項目：
- **体積含水率（VWC）**: 平均 0.353 m³/m³, SD 0.055
- **電気伝導度（EC）**: 平均 0.745 dS/m, SD 0.176
- **pH**: 平均 5.875, SD 0.364

バリオグラム解析により空間相関構造を推定し、指数型バリオグラムモデルを適合した。クリギング推定の不確実性（標準偏差）マップも同時に生成した。

### 2.4 深層学習による収量マッピング（Module 4）

**CNN-LSTMアーキテクチャ**:

```
Input Layer
├── CNN Feature Extractor (per timestep)
│   ├── Conv2D(5→32, 3×3) + BN + ReLU + MaxPool
│   ├── Conv2D(32→64, 3×3) + BN + ReLU + AdaptiveAvgPool
│   └── FC(64→64) → spatial feature vector
│
├── Weather Features (T_avg, Precip, SRad) [normalized]
├── Soil Features (VWC, EC, pH) [static, broadcast across time]
│
├── LSTM(131→128, 2 layers, dropout=0.2)
│   └── Temporal sequence modeling
│
└── Regressor
    ├── FC(128→64) + ReLU + Dropout(0.3)
    └── FC(64→1) → Yield (t/ha)
```

- **モデルパラメータ数**: 267,137
- **学習データ**: 500サンプル（train/val/test = 320/80/100）
- **最適化**: Adam (lr=0.001, weight_decay=1e-4), ReduceLROnPlateau

### 2.5 可変施肥マップ（Module 5）

二次プラトーモデルに基づく窒素応答関数を構築し、以下の要素を組み込んだ：

- **NDVI**: 植生活力指標（窒素需要の推定）
- **pH**: 窒素可給性への影響係数
- **EC**: 塩類ストレス係数
- **経済最適化**: 収益（収量×米価格）からN施肥コストを差し引いた利益を最大化

圃場を50×50グリッドに分割し、各グリッドセルで最適N施肥量をL-BFGS-B法で求解した。

### 2.6 GEE/GeoPandas解析パイプライン（Module 6）

Google Earth Engineを用いた以下のパイプラインを設計した：

1. **Sentinel-2 SR Harmonized**: 雲マスク処理 → 植生指数計算 → 月別コンポジット
2. **Sentinel-1 SAR**: 水田の湛水検知（VV/VH偏波）
3. **ERA5 Land Daily**: 気温・降水・日射の取得
4. **Random Forest**: 水田分類（作物判別）
5. **Export**: Google Driveへの時系列NDVI出力

GeoPandasによる圃場管理データベースでは、20圃場の属性情報（品種、面積、施肥量、収量）をGeoJSON形式で管理した。

## 4. 考察と今後の展望

### 4.1 成果

1. **統合パイプライン**: 衛星画像・気象・土壌の3種のデータソースを統合した解析フレームワークを構築できた。GEE/GeoPandasベースのアーキテクチャにより、クラウドスケールの処理と圃場単位の精密管理の両方に対応可能である。

2. **植生指数モニタリング**: 水稲の典型的な生育曲線（移植→分げつ→出穂→登熟）をNDVI/EVI時系列から適切に捉えた。NDREは窒素状態の診断指標として有望である。

3. **作物モデル**: 簡易モデルでも生育ステージの推移やバイオマス蓄積の傾向を再現できた。実運用ではDSSAT/APSIMの完全版との連携が望ましい。

4. **VRA最適化**: クリギング補間と経済最適化の組み合わせにより、環境負荷低減と経済性を両立する施肥処方が可能となった。

### 4.2 課題と限界

1. **深層学習モデルの精度**: 合成データ500サンプルでは不十分であり、実データでの検証が必要。R²が負値となっており、モデル構造の改善（Attention機構の導入、Transfer Learning等）やデータ拡張が必要。

2. **作物モデルの単純化**: 収穫指数の計算に課題があり（GDD 2200到達前に生育期間が終了）、成熟期の到達条件やcalibrationsの精緻化が必要。

3. **空間解像度のギャップ**: 衛星画像（10m）と土壌センサー（ポイント）の空間スケールの不一致を解消するために、ドローン画像（cm級）の活用が有効。

### 4.3 今後の展望

1. **実データの適用**: 新潟県の実圃場データ（Sentinel-2時系列、気象アメダスデータ、圃場収量データ）を用いた検証
2. **Transformer ベースモデル**: CNN-LSTM に代わる Vision Transformer + Temporal Attention の導入
3. **データ同化**: リモートセンシング由来のLAIを作物モデルに同化（EnKF等）し、予測精度を向上
4. **リアルタイムダッシュボード**: StreamlitベースのWebアプリとしてパイプラインをデプロイし、生産者への可視化・意思決定支援を提供
5. **環境影響評価**: 窒素溶脱シミュレーションとの連携による水質への影響評価
