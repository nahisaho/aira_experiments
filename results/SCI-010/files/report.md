# ADC Payload-Linker Optimization Computational Platform — Experiment Report

## 実験目的と背景

抗体薬物複合体（Antibody-Drug Conjugate, ADC）は、モノクローナル抗体の標的特異性と低分子薬物の細胞毒性を組み合わせた次世代がん治療薬である。本研究では、ADCのペイロード・リンカー最適化のための統合的計算プラットフォームを構築し、以下の6つのモジュールを実装・評価した：

1. **DAR分布と治療域の関係モデリング** — Drug-to-Antibody Ratio（DAR）の不均一性が薬効・毒性に与える影響を定量化
2. **リンカー切断メカニズムのシミュレーション** — 酸感受性、酵素切断、還元型リンカーの切断速度論
3. **バイスタンダー効果の数理モデル** — 腫瘍組織内での遊離薬物の反応拡散方程式
4. **血漿中安定性と腫瘍内放出速度のバランス最適化** — パラメータ空間探索
5. **薬物動態（PK）モデルとの統合** — 二室モデル + TMDD（標的介在性薬物動態）
6. **HER2標的ADC（T-DXd類似体）のケーススタディ** — Monte Carloシミュレーションによる集団薬効評価

## 使用した手法・アルゴリズムの概要

### 数理モデリング
- **DAR分布**: 切断ガウス分布モデル（DAR 0–8）、DAR依存性クリアランスモデル
- **リンカー切断**: Hill方程式（pH依存性）、Michaelis-Menten速度論（酵素切断）、シグモイド関数（GSH依存性還元）
- **バイスタンダー効果**: 2次元反応拡散方程式の有限差分法による数値解法
- **PK統合**: 二室薬物動態モデル + 標的介在性薬物動態（TMDD）、SciPy `solve_ivp` (LSODA法)
- **最適化**: グリッドサーチによるパラメータ最適化

### Monte Carloシミュレーション
- 患者集団（N=500）の薬物応答をシミュレーション
- HER2発現量、腫瘍体積、体重、DAR、クリアランスの変動を確率分布でモデル化
- RECIST基準に基づく腫瘍縮小評価

### 実装
- Python 3 (NumPy, SciPy, Matplotlib, Seaborn)
- 微分方程式ベースのPK/PDモデル
- 確率的Monte Carloシミュレーション

## 主要な結果と数値

### 1. DAR分布と治療域

DAR 4を中心としたガウス分布を仮定し、各DAR種のクリアランスと治療指数を評価した。治療指数（TI = efficacy/toxicity）は低DARほど高く、DAR ≈ 1.3で最大となった。一方、十分な薬効を確保するにはDAR 3–5が必要であり、DAR 4前後が実用的な最適値と考えられる。

![DAR Distribution and Therapeutic Window](figures/dar_distribution.png)

**主要数値:**
- DAR分布: DAR4が最大比率（32.2%）、DAR3（23.3%）、DAR5（23.2%）
- DAR依存性クリアランス: DAR0で0.30 L/day、DAR8で0.70 L/day

### 2. リンカー切断メカニズム

3種類のリンカー（酸感受性ヒドラゾン、酵素切断Val-Cit、還元型ジスルフィド）の切断動態を、血漿→エンドソーム→リソソームの微小環境遷移下でシミュレーションした。

![Linker Cleavage Mechanisms](figures/linker_cleavage.png)

**主要数値:**
- 酸感受性リンカー半減期: **4.0時間**（内在化後）
- 酵素切断リンカー半減期: **7.9時間**
- 還元型リンカー半減期: **8.2時間**
- 酸感受性リンカーが最速の切断を示し、エンドソーム酸性化に対する感受性が高い

### 3. バイスタンダー効果

抗原陽性（Ag+）細胞60%、抗原陰性（Ag-）細胞40%の不均一腫瘍モデルで、遊離薬物の拡散によるバイスタンダー殺細胞効果を24時間シミュレーションした。

![Bystander Effect Model](figures/bystander_effect.png)

**主要数値:**
- 総腫瘍細胞数: 7,668
- 全体殺細胞率: **99.9%**
- Ag+細胞殺細胞率: **100%**
- Ag-細胞殺細胞率（バイスタンダー効果）: **99.7%**
- 拡散係数 D = 1×10⁻⁷ cm²/s で強力なバイスタンダー効果を確認

### 4. 血漿中安定性と腫瘍内放出速度のバランス

血漿中脱共役速度（α）と腫瘍内放出速度（β）の2パラメータ空間を網羅的に探索し、治療スコアを最大化する条件を同定した。

![Stability-Release Optimization](figures/stability_release.png)

**主要数値:**
- 最適血漿脱共役速度: α = **0.005 h⁻¹**（半減期 ≈ 139時間）
- 最適腫瘍内放出速度: β = **1.0 h⁻¹**（半減期 ≈ 0.7時間）
- 高い血漿安定性と迅速な腫瘍内放出の組み合わせが最適

### 5. 統合PKモデル

T-DXd類似体の二室PKモデル（TMDD付き）で、5.4 mg/kg Q3W投与の6サイクルをシミュレーションした。

![Integrated PK Model](figures/pk_model.png)

**主要数値:**
- Cmax: **1,024 nM**
- AUC₀₋₂₁: **3,584 nM·day**
- Ctrough（Day 21）: **57.0 nM**
- 最大遊離ペイロード濃度: **0.125 nM**
- 最大腫瘍内ADC濃度: **553 nM**

### 6. HER2標的ADCケーススタディ（Monte Carlo）

500人の仮想患者集団でT-DXd類似体の臨床効果をMonte Carloシミュレーションした。

![HER2-Targeted ADC Case Study](figures/case_study_tdxd.png)

**主要数値:**
- 奏効率（ORR）: **79.0%**
- 病勢コントロール率（DCR）: **100%**
- 無増悪生存期間中央値（mPFS）: **8.8ヶ月**
- Grade 3以上有害事象: **25.0%**
- 平均腫瘍縮小率: **46.8%**
- 完全奏効（CR）: 0例、部分奏効（PR）: 395例、安定（SD）: 105例

### 7. DAR最適化Monte Carlo

10,000回のMonte Carloシミュレーションで、DARと治療指数の関係を確率的に評価した。

![DAR Optimization Monte Carlo](figures/dar_optimization_mc.png)

**主要数値:**
- 治療指数最大DAR: **1.0**（TI = 3.97）
- 実用的最適DAR範囲: **3–5**（十分な薬効と許容可能な毒性のバランス）

## 考察と今後の展望

### 主要な知見

1. **DAR最適化のトレードオフ**: 治療指数は低DARで最大化されるが、臨床的に意味のある薬効を得るにはDAR 3–5が必要。T-DXdのDAR ≈ 8は高い薬効をもたらすが、毒性管理が重要。

2. **リンカー選択の重要性**: 酸感受性リンカーは最速の切断を示すが、血漿中安定性に課題がある。酵素切断型（Val-Cit等）は血漿安定性と腫瘍選択的放出のバランスに優れる。

3. **バイスタンダー効果**: 膜透過性の高いペイロード（DXd等）は、抗原陰性細胞への強力なバイスタンダー効果を示す。これはHER2低発現腫瘍への有効性を説明する。

4. **PKモデル**: T-DXd類似体のPKプロファイルは臨床報告値と概ね一致。遊離ペイロード濃度は低く維持され、全身毒性の制御に寄与。

### 限界と将来の方向性

- **モデルの簡略化**: 腫瘍微小環境の不均一性、免疫応答、代謝経路の詳細は省略されている
- **パラメータの不確実性**: 臨床データによるキャリブレーションが必要
- **拡張可能性**: 免疫チェックポイント阻害剤との併用療法モデル、AIベースのリンカー設計への統合
- **バリデーション**: in vitro/in vivoデータとの照合による予測精度の検証
