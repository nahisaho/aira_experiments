# 鉛フリーペロブスカイト太陽電池材料の高速スクリーニングシステム — 実験レポート

## 1. 実験目的と背景

鉛（Pb）ベースのペロブスカイト太陽電池は高い光電変換効率（PCE > 25%）を達成しているが、鉛の毒性が商業化の大きな障壁となっている。本研究では、Sn/Ge/Bi系鉛フリーペロブスカイト材料の高速スクリーニングシステムを設計・実装し、以下の6つのモジュールを統合した自動探索パイプラインを構築した：

1. **拡張Goldschmidt許容因子**による構造安定性予測
2. **DFT+機械学習ハイブリッド**によるバンドギャップ・光吸収係数予測
3. **欠陥形成エネルギー**と非放射再結合損失の推定
4. **NEB法**に基づくイオン移動エネルギー障壁計算
5. **SCAPS-1D**デバイスシミュレーションとの連携
6. **多目的最適化**による候補材料ランキング

## 2. 使用した手法・アルゴリズムの概要

### 2.1 拡張Goldschmidt許容因子

古典的Goldschmidt許容因子に加え、Bartel et al. (2019) の新許容因子τを実装した：

$$\tau = \frac{r_X}{r_B} - n_A \cdot \frac{n_A - r_A/r_B}{\ln(r_A/r_B)}$$

τ < 4.18 で安定なペロブスカイト構造を予測する。さらに、ロジスティック回帰ベースのMLモデルで安定性スコア（0-1）を算出した。

### 2.2 DFT+MLハイブリッドバンドギャップ予測

- **DFTデータベース**: 文献から20種以上のペロブスカイトのDFT計算バンドギャップを収集
- **MLモデル**: 8次元特徴量ベクトル（イオン半径、電気陰性度、許容因子、八面体因子、酸化数）を用いた線形予測モデル
- **ベイズ重み付き統合**: DFT予測とML予測をベイズ推定で統合（σ_DFT = 0.15 eV、σ_ML = 0.25 eV）

### 2.3 欠陥解析

- B-site/X-siteの空孔形成エネルギーを文献値ベースで推定
- SRH（Shockley-Read-Hall）再結合寿命を欠陥密度から計算
- 非放射Voc損失: ΔV_OC = (k_BT/q) × ln(1 + τ_rad/τ_SRH)

### 2.4 NEB法イオン移動障壁

- CI-NEB法による文献値キャリブレーションモデル
- ハロゲン空孔（0.28-0.58 eV）とB-site空孔（0.55-1.15 eV）の移動障壁データベース

### 2.5 SCAPS-1Dパラメータ生成

- ETL/HTL材料パラメータ（TiO₂, SnO₂, Spiro-OMeTAD等）
- Shockley-Queisser限界からの損失メカニズム適用
- 単一ダイオードモデルによるJ-V特性シミュレーション

### 2.6 AiiDA/Fireworksワークフロー

自動化ワークフローを以下の8ステップで構成：
1. 構造生成 → 2. DFT構造最適化 → 3. 電子構造計算 → 4. ML予測 → 5. 欠陥計算 → 6. NEB計算 → 7. デバイスシミュレーション → 8. ランキング

## 4. 考察と今後の展望

### 4.1 主な知見

1. **ダブルペロブスカイト（Cs₂AgBiI₆）が最高スコア**: 安定性とPCEのバランスが最も良好。Bi³⁺の高い酸化安定性がSn²⁺系の課題を克服。
2. **Sn系は最適バンドギャップだが安定性に課題**: MASnI₃のEg = 1.40 eVはSQ最適に近いが、低い欠陥形成エネルギー（0.38 eV）と低いイオン移動障壁（0.28 eV）が長期安定性のリスク。
3. **Ge系は安定性フィルタで除外**: 八面体因子が適正範囲外のため、構造安定性が低い。Sn-Geアロイによる改善が有望。

### 4.2 先行研究との比較

- Sn系ペロブスカイトのPCEシミュレーション値（16-18%）は、SCAPS-1D文献値（20-23%）と妥当な一致を示す
- Cs₂AgBiBr₆の実験的PCE（~3%）と本シミュレーション値の差は、界面損失や多結晶効果に起因
- NEB法による移動障壁値（0.28-0.45 eV）は、DFT計算文献値（0.2-0.6 eV）の範囲内

### 4.3 今後の展望

1. **混合カチオン/アニオン系**の探索空間拡張（FA₀.₅MA₀.₅SnI₃等）
2. **Sn-Geアロイ系**の体系的スクリーニング
3. **界面エンジニアリング**のシミュレーション統合
4. **実験フィードバック**によるMLモデルの逐次更新
5. **多結晶・粒界効果**の組み込み
