# 実験レポート: 手術ロボットの半自律縫合動作の学習・制御システム

## 1. 実験目的と背景

本実験では、手術ロボット（da Vinci Research Kit: dVRK）における半自律縫合動作のための統合学習・制御フレームワークを設計・実装・検証した。具体的には以下の6つのモジュールを統合したシステムを構築した：

1. **デモンストレーションからの学習（LfD）**: Dynamic Movement Primitives（DMP）による軌道エンコーディング
2. **組織変形モデリング**: Mass-Springモデルによるリアルタイム組織変形シミュレーション
3. **力センシングとコンプライアンス制御**: インピーダンスベースの力制御
4. **視覚サーボ**: 3D再構成とニードル追跡
5. **安全制約**: 力リミット・作業空間制限・速度制限の保証
6. **dVRKシミュレーション検証**: 複数試行による統計的評価

### 背景

ロボット支援手術（RAS）における自動縫合は、外科医の疲労軽減と手術精度の向上に大きく貢献する技術である。しかし、軟組織の変形、力覚フィードバックの欠如、安全性保証の課題が、完全自動化の実現を妨げている。先行研究（Schwaner et al., 2021; Zhou et al., 2024; Xu et al., 2021）は個別のモジュールについて大きな進展を示しているが、これらを統合した包括的なフレームワークの設計・評価は十分に行われていない。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 Dynamic Movement Primitives (DMP)

DMPは、非線形力学系として軌道を表現する手法である。学習された基底関数の重みを調整することで、新しいゴール位置への軌道の汎化が可能である。

- **基底関数数**: 30
- **パラメータ**: α_z = 25.0, β_z = 6.25, α_x = 1.0
- **学習手法**: 最小二乗法による重みフィッティング

### 2.2 Mass-Spring 組織モデル

12×12のグリッドノードから構成される質量-ばねモデルを使用し、構造ばね（k=50 N/m）と剪断ばね（k=20 N/m）により組織の弾性応答をモデル化した。

### 2.3 インピーダンス制御

仮想慣性M=0.5 kg、仮想減衰B=10 Ns/m、仮想剛性K=100 N/mによるインピーダンスモデルを実装し、力リミット5.0Nによる安全制限を組み込んだ。

### 2.4 視覚サーボ

500×500のカメラ内部行列を用いた3D→2D投影と、ガウスノイズ付加によるノイズロバスト性評価を実施した。

### 2.5 安全モニター

力制限（5.0N）、作業空間制限（X: -50~100mm, Y: -50~50mm, Z: -10~50mm）、速度制限（50mm/s）の三重安全機構を実装した。

## 4. 考察と今後の展望

### 4.1 考察

- **DMP学習**: 1mm程度の再現精度は臨床的に許容範囲内であり、先行研究（Schwaner et al., 2021）の結果と整合する
- **組織変形**: Mass-Springモデルは計算効率が高い一方、FEMと比較して精度に制限がある。深層学習によるFEM加速（Hu et al., 2025）との統合が今後の方向性として有望
- **安全制約**: 速度制限の厳格な設定は安全性を優先した結果であり、臨床適用時にはタスクフェーズに応じた適応的制限が必要
- **視覚サーボ**: 2ピクセル以下の追跡精度は、Lin et al.（2022）が報告した1.76mmの3D誤差と整合的

### 4.2 今後の展望

1. **Sim-to-Real Transfer**: SurRoLシミュレーション（Xu et al., 2021）からdVRK実機への方策転移
2. **深層学習統合**: Action Chunking with Transformers（ACT）によるend-to-end学習
3. **非線形FEM**: 計算コスト削減のためのニューラルネットワーク補助FEM
4. **不完全デモンストレーション**: 人間の失敗デモからのロバスト学習
5. **多目的安全最適化**: パレートフロント上での安全性-性能トレードオフの最適化
