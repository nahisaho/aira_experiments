## 1. 実験目的と背景

### 1.1 目的

GelSight/DIGIT型高解像度触覚センサーを用いて、ロボットマニピュレータが未知物体を安全に認識・把持・操作するための統合的なシステムを設計する。本システムは以下の6つの機能モジュールから構成される：

1. **接触形状・力分布推定** — 触覚画像から3D接触幾何と6軸レンチを推定
2. **テクスチャ分類** — 深層学習による表面テクスチャの識別
3. **触覚-視覚マルチモーダル融合** — Cross-Attention Transformerによる統合認識
4. **把持安定性評価** — 時系列触覚データからのリアルタイム安定性予測
5. **すべり検出・力制御** — オプティカルフロー+インピーダンス制御
6. **探索的把持戦略** — ベイズ最適化による未知物体の安全な把持

### 1.2 背景

触覚センシングは、視覚だけでは困難な物体特性（硬さ、表面粗さ、すべりやすさ等）の認識に不可欠である。GelSightセンサーは弾性体ゲルの変形をカメラで撮影することで、高解像度な接触情報を取得できる。本研究では、この触覚情報を深層学習で処理し、ロボット操作の全工程に統合するフレームワークを構築する。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 Module 1: ContactNet（接触形状・力分布推定）

| 項目 | 値 |
|---|---|
| パラメータ数 | 16,819,732 |
| バックボーン | ResNet-18 |
| 入力 | RGB触覚画像 (3, H, W) |
| 出力 | 深度マップ (1, 64, 64), 法線マップ (3, 64, 64), レンチ (6) |

**アルゴリズム:**
- **物理ベース分岐**: 微分可能フォトメトリックステレオ層で表面法線を推定し、ポアソンソルバー（DCT近似）で深度を再構成
- **学習ベース分岐**: ResNet-18エンコーダ + 転置畳み込みデコーダで深度・法線を直接回帰
- **ゲート融合**: 学習可能なゲーティング機構で物理ベースと学習ベースの出力を適応的に融合
- **力推定**: グローバル平均プーリング + MLP で6軸レンチを推定
- **損失関数**: L1深度損失 + 勾配整合損失 + コサイン法線損失 + MSE力損失（方向アライメント付き）

### 2.2 Module 2: TextureCNN（テクスチャ分類）

| 項目 | 値 |
|---|---|
| パラメータ数 | 6,180,192 |
| バックボーン | EfficientNet-B0 |
| 入力 | RGB触覚画像 (3, 224, 224) |
| 出力 | クラスロジット (20), 確率 (20), 特徴量 (1408) |

**アルゴリズム:**
- **Gaborフィルタバンク**: 8方位 × 4周波数 = 32個の固定Gaborフィルタで初期テクスチャ特徴を抽出
- **マルチスケール特徴抽出**: カーネルサイズ3/5/7の並列畳み込みで異なるスケールの特徴を取得
- **チャネル＋空間アテンション**: SE-Net風のチャネルアテンションとCBAM風の空間アテンション
- **EfficientNetバックボーン**: 高レベル意味的特徴の抽出
- **温度スケーリング**: 確率のキャリブレーションのための学習可能温度パラメータ
- **損失関数**: ラベルスムージングCE損失 + 教師あり対照損失

### 2.3 Module 3: CrossModalTransformer（マルチモーダル融合）

| 項目 | 値 |
|---|---|
| パラメータ数 | 41,828,551 |
| 融合次元 | 256 |
| Transformerレイヤ数 | 4 |
| アテンションヘッド数 | 8 |
| 入力 | 触覚画像 (3, 224, 224) + 視覚画像 (3, 224, 224) |
| 出力 | 物体ロジット (50), 材質ロジット (20), 把持品質スコア (1) |

**アルゴリズム:**
- **モダリティ別エンコーダ**: 触覚(ResNet-18) + 視覚(ResNet-34)
- **パッチトークン化**: 特徴マップを2x2パッチに分割しトークン列に変換
- **双方向クロスアテンション**: 触覚→視覚、視覚→触覚の交互アテンション（4層）
- **正弦波位置符号化** + **学習可能なモダリティトークン**
- **InfoNCE対照損失**: モダリティ間の特徴空間アライメント
- **マルチタスクヘッド**: 物体分類 / 材質分類 / 把持品質回帰

### 2.4 Module 4: GraspStabilityNet（把持安定性評価）

| 項目 | 値 |
|---|---|
| パラメータ数 | 1,011,068 |
| 時間窓 | 10フレーム |
| LSTM隠れ次元 | 128 |
| 入力 | 触覚画像列 (T, 3, H, W) + レンチ列 (T, 6) |
| 出力 | 安定性スコア (1), 安定性クラス (3), 故障予測時間 (1), 矯正アクション (4) |

**アルゴリズム:**
- **接触特徴抽出**: 接触面積、圧力中心(CoP)、法線力比率、トルク大きさの計算
- **フレーム融合**: 画像特徴 + 接触特徴 + レンチをフレーム毎にMLPで融合
- **双方向LSTM + 時間アテンション**: 把持状態の時間的変化をエンコード
- **デルタ特徴**: フレーム間差分で変化量を明示的にモデル化
- **不確実性ベースのマルチタスク損失**: 各タスクの重みを自動調整

### 2.5 Module 5: SlipDetector（すべり検出・力制御）

| 項目 | 値 |
|---|---|
| パラメータ数 | 1,715,760 |
| 制御レート | 100 Hz |
| すべり分類 | 4クラス（なし/微小/並進/回転） |
| 入力 | 触覚画像列 (T, 3, H, W) + 現在力 (3) + 目標力 (3) |
| 出力 | すべりクラス (4), すべり量 (1), 方向 (2), 力指令 (3) |

**アルゴリズム:**
- **オプティカルフロー推定**: FlowNetS風の軽量CNNでフレーム間光学フローを推定
- **マーカートラッキング**: ゲル表面マーカーの変位を追跡（補助信号）
- **すべり分類器**: フロー統計量 + GRU時系列モデルで4クラス分類
- **インピーダンス力制御**: PID制御 + 学習残差による反応的力調整
- **すべり反応ゲイン**: すべり検出時に自動的に把持力を増加

### 2.6 Module 6: ExploratoryGraspingPolicy（探索的把持戦略）

| 項目 | 値 |
|---|---|
| パラメータ数 | 953,235 |
| 候補把持数 | 50 |
| 改良ステップ | 5 |
| 探索バジェット | 20回 |
| 入力 | 視覚画像 (3, H, W) |
| 出力 | 最適把持パラメータ (7), GP予測 (K), 安全性スコア (K) |

**アルゴリズム:**
- **視覚ベース把持候補生成**: CNNで視覚画像から把持候補（位置3D + 四元数4D）を生成
- **ガウス過程代理モデル**: MCドロップアウトで近似した不確実性推定付きGP
- **獲得関数**: Expected Improvement / UCB / Thompson Sampling
- **安全性制約**: 力上限、接近速度制限、緊急退避閾値
- **把持改良ネットワーク**: 反復的な把持パラメータの微調整
- **オンライン学習**: GRUベースの観測履歴エンコーダで試行から学習

## 3. シミュレーション環境

### 3.1 Isaac Sim統合

| 項目 | 設定値 |
|---|---|
| シミュレーション時間ステップ | 0.001 s |
| レンダリング間隔 | 4ステップ |
| ロボット | Franka Panda (7-DOF) |
| 触覚センサー数 | 2（グリッパー各指） |
| 弾性体モデル | Neo-Hookean |
| 物体データセット | YCB (50 training / 20 test) |
| 並列環境数 | 64 |

### 3.2 ゲル変形モデル

弾性半空間のBoussinesq解に基づく解析的な変形計算を実装。点荷重に対する垂直変位を計算し、勾配から表面法線を導出する。

### 3.3 触覚画像レンダリング

3色LED（R/G/B、120°間隔配置、仰角30°）によるフォトメトリックステレオを模擬。Lambertian拡散反射モデル + ガンマ補正 + センサーノイズを適用。

### 3.4 ドメインランダマイゼーション

Sim-to-Real転移を促進するために以下を実装：
- **物体プロパティ**: 質量 (0.01–2.0 kg)、摩擦係数 (0.3–1.2)、反発係数 (0.0–0.5)
- **照明条件**: 強度スケール (0.7–1.3)、色シフト、環境光
- **センサーパラメータ**: ノイズ標準偏差、弾性率、摩擦係数
- **画像拡張**: 明度/コントラスト変動、色ジッター、ガウスぼかし

### 4.3 設計上の特性

- **物理-学習ハイブリッド**: ContactNetは微分可能フォトメトリックステレオ（物理）と深層学習を融合
- **階層的安全機構**: 力上限、すべり検出、緊急退避の3段階安全制御
- **不確実性考慮**: GP代理モデルとMCドロップアウトによる把持品質の不確実性推定
- **End-to-End学習可能**: 全モジュールがPyTorchで実装され、微分可能

## 5. 考察と今後の展望

### 5.1 設計の利点

1. **モジュラー設計**: 各モジュールが独立してテスト・改良可能
2. **物理整合性**: ContactNetの物理ベース分岐により、少量データでも妥当な接触推定が可能
3. **Sim-to-Real**: ドメインランダマイゼーションにより、シミュレーションで学習したモデルの実機転移を促進
4. **リアルタイム性**: 軽量アーキテクチャ（特にModule 4-6）により30Hz以上の制御ループが実現可能

### 5.2 制限事項

1. **シミュレーション忠実度**: Boussinesq解は点荷重近似であり、実際の面接触の精密なモデリングには有限要素法(FEM)が必要
2. **CrossModalTransformerの計算コスト**: 41.8Mパラメータはリアルタイムシステムには大きい。知識蒸留による軽量化が望ましい
3. **実データ未検証**: 本設計はシミュレーション環境での検証のみであり、実センサーデータでの性能評価が必要

### 5.3 今後の展望

1. **FEMベースのゲル変形シミュレーション**: TACTO/TAXIMなどのFEMソルバー統合
2. **強化学習との統合**: Isaac Gymでの大規模並列RLによる操作スキル獲得
3. **触覚SLAM**: 触覚情報を用いた物体形状の逐次再構成
4. **マルチフィンガー拡張**: 3指以上のデクスタラスハンドへの対応
5. **Foundation Model活用**: 大規模触覚データセットでの事前学習モデル
6. **リアルタイム最適化**: TensorRT/ONNXによるモデル最適化とエッジデプロイ
