# 実験レポート：AIシステム倫理評価フレームワーク（FEPR-E）
## 医療AI診断システムの倫理監査ケーススタディ

---

## 1. 実験目的と背景

### 1.1 目的

本実験は、AIシステムの倫理的側面を多次元的かつ定量的に評価するフレームワーク「**FEPR-E**（Fairness–Explainability–Privacy–Robustness–Environment）」を設計・実装し、医療AI診断システムに適用することを目的とする。

評価対象の5次元：
1. **公平性（Fairness）**：Statistical Parity / Equalized Odds / Calibration
2. **説明可能性（Explainability）**：SHAP一貫性・特徴量安定性
3. **プライバシー（Privacy）**：メンバーシップ推論攻撃（MIA）耐性
4. **ロバスト性（Robustness）**：敵対的摂動・分布シフト
5. **環境負荷（Environment）**：CO₂排出量推定

### 1.2 背景と研究動機

- Obermeyer et al. (2019, *Science*) が指摘した米国医療アルゴリズムの人種的偏り（黒人患者の疾患重症度を26.3%過小評価）
- EU AI法（2024年施行）における高リスクAIシステムへの監査義務
- 個別ツール（Fairlearn, AIF360, SHAP）は存在するが、統合的スコアリングは未整備
- 大規模モデルの環境コスト問題の高まり（GPT-4: 約500tCO₂e）

## 2. 使用した手法・アルゴリズム

### 2.1 合成医療データセット生成

```
N = 2,000 患者
特徴量: Age, Gender, Race, Biomarker1-5, HealthcareAccess (計9次元)
正例率: ~5.5%（疾患診断タスク）
内蔵バイアス: 黒人患者のHealthcareAccess -1.5σ, Biomarker2 -3単位
```

真ラベルの生成ロジット:
```
logit(p) = -3.0 + 0.4*(BM1-5) + 0.015*(BM2-100) + 0.5*(BM3-2.5) 
           + 0.02*(Age-55) - 0.3*I[Female]
```

### 2.2 評価モデル

| モデル | パラメータ | 特徴 |
|--------|-----------|------|
| Logistic Regression | C=1.0, max_iter=1000 | 線形・解釈容易 |
| Random Forest | n=100, depth=6 | アンサンブル |
| **Gradient Boosting** | n=100, depth=4 | 主評価モデル |

### 2.3 評価パイプライン

```
データ生成 → 標準化 → 5折CV → GBモデル訓練 
→ 公平性評価 → SHAP解析 → MIA模擬 → ロバスト性評価
→ CO₂推定 → スコア集約 → 可視化
```

## 4. 考察と今後の展望

### 4.1 主要発見事項

1. **FEPR-Eは多次元的な不整合を露見させる**: SPDはパスするがEODが失敗—単一指標では不十分
2. **過学習はロバスト性と公平性の両方を損なう**: CV AUCの低さとMIA AUCの低さが相関
3. **低炭素モデルの競争力**: LRはGBとAUC差0.007でCO₂450倍の差→環境コストは合理的選択基準
4. **SHAP安定性は高い**: GBTのSHAP一貫性0.93は信頼できる説明を提供
5. **プライバシーと性能のトレードオフ**: 中程度の性能モデルは暗黙的プライバシー保護を示す

### 4.2 臨床導入への提言

```
【必須（Before deployment）】
  □ 正則化強化・ドロップアウトによる過学習解消（目標: 訓練-CV AUC差 < 0.05）
  □ クラス不均衡対処（SMOTE / 閾値最適化）でF1改善
  □ EOD-TPR改善: 黒人患者の感度向上（目標: EOD < 0.10）

【推奨（Conditional improvement）】
  □ 差分プライバシー訓練（ε=1.0〜5.0）の検討
  □ LRへの切り替えによるCO₂削減（性能許容範囲内）
  □ SHAP説明の臨床医向けインターフェース開発
```

### 4.3 NatureLM統合の評価

NatureLM MCPツールは以下の面で有用であった：
- **科学的根拠の迅速取得**: 公平性閾値（SPD 0.15-0.20）は文献レビューと一致
- **定量的キャリブレーション**: MIA AUCベンチマーク（ε=0.10: 0.47）は我々の実験結果（0.501）を解釈する基準点を提供
- **限界**: 応答が簡潔で詳細な文献引用がない場合がある

### 4.4 限界

- 合成データの単純さ（実臨床データは欠損値・縦断的相関・専門家ノイズを含む）
- MIA攻撃モデルの簡易さ（実際のブラックボックス攻撃はより高AUCを達成）
- FEPR-E重みは主観的（ドメイン専門家によるキャリブレーションが必要）
- Semantic Scholar APIが429エラーを返した（レート制限）→OpenAlexで代替

### 4.5 今後の展望

1. **AIF360連携**: 再重み付け・敵対的デバイアス手法の統合
2. **実データ検証**: MIMIC-III, ADNI, NHANESでの外部検証
3. **動的監査**: 本番環境でのリアルタイム公平性ドリフト検知
4. **LLMへの拡張**: 大規模言語モデルの偏り評価（毒性・ステレオタイプ）
5. **規制対応**: EU AI法 Article 10要件へのFEPR-Eマッピング

## 付録：先行研究課題の整理

| 課題カテゴリ | 先行研究での限界 | 本研究での対応 |
|------------|---------------|-------------|
| 単一次元評価 | Fairlearn: 公平性のみ | 5次元統合スコア |
| 閾値の恣意性 | 多くが「0.1以下が望ましい」等の曖昧基準 | NatureLM + 文献根拠の閾値 |
| 環境コスト無視 | 全先行研究で考慮なし | CO₂推定の統合 |
| 医療AI特化の欠如 | 一般的機械学習設定 | 医療特有の偏り（構造的差別）の明示的組み込み |
| 再現性の課題 | ツール間の非互換 | 単一Pythonパイプライン・シード固定 |
