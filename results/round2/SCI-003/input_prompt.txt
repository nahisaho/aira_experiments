以下の研究テーマについて、次のステップで進めてください：

**ステップ1: 先行研究調査（ToolUniverse MCP 使用）**
- ToolUniverse MCP の学術検索ツール（Semantic Scholar / PubMed / Crossref 等）を使って、この研究テーマに関連する先行研究を調査する
- 検索キーワードを複数設定し、関連する最新論文（特に2020年以降）を少なくとも5件特定する
- 各論文のタイトル、著者、年、DOI、主要な知見・手法をまとめる
- 先行研究の課題・限界を整理する

**ステップ2: 実験計画 + NatureLM 科学的検証**
- 先行研究の知見を踏まえて実験計画を立てる
- NatureLM MCP を以下のように活用すること：
  - `ask_naturelm`: 対象の生物学的メカニズムに関する定量的パラメータ（結合自由エネルギー、反応速度定数、相関係数等）を取得する
  - 取得した定量的知見をシミュレーション仮定やデータ生成の制約条件として組み込む
- NatureLM の予測結果はResultsセクションに定量的に記載すること
- ⚠️ NatureLM MCP ツールへの接続に失敗した場合は、（1）試行したツール名、（2）エラー内容、（3）代替手段をMethodsセクションに記録すること。ツール接続の成否にかかわらず、試行の記録は科学的透明性として重要である

**ステップ3: 実験実施**
- 先行研究調査とNatureLM予測の結果を踏まえて実験を実施する
- 実験中もNatureLM MCPツールを適宜活用して仮説検証・データ補完を行う
- ⚠️ **現実的な結果を報告すること**: AUC/AUROC/F1等が1.000（完璧）になった場合は、過学習・データリーク・評価の不備を疑い、交差検証の標準偏差付きで報告する。合成データであっても現実的なノイズを含めること

**ステップ4: 成果物作成（必須 — この手順を省略しないこと）**
以下の2ファイルは**必ず**作成すること。**他のすべてのステップより優先度が高い**。
実験の実施に時間がかかっても、必ずこのステップを実行すること。

📄 **paper.md** — 以下のセクション構成に従う学術論文：
  - **Abstract**: 200語以上。研究目的・手法・主要結果・意義を含む
  - **Introduction**: 先行研究の位置づけと研究の新規性を明記
  - **Methods**: 使用した手法、パラメータ、NatureLM MCPツールの使用/試行状況を記載
  - **Results**: 定量的な実験結果を表形式で提示。交差検証の標準偏差を含む。NatureLM予測結果も含める
  - **Discussion**: 結果の解釈、限界、先行研究との比較
  - **Conclusion**: 主要な知見と今後の課題
  - **References**: 先行研究調査で発見した文献をDOI付きで5件以上含める

📄 **report.md** — 実験の全結果・手法・考察をまとめたレポート

   - 1. Introduction（研究背景・目的・貢献）
   - 2. Related Work（関連研究のレビュー）
