# 実験レポート：高エントロピー合金（HEA）組成最適化のための機械学習フレームワーク

---

## 1. 実験目的と背景

### 1.1 研究目的

本実験は、CrMnFeCoNi系高エントロピー合金（HEA）の組成最適化を目的とした機械学習フレームワークの設計・実装・評価を行う。具体的には以下の6つのサブタスクを統合的に実施した：

1. CALPHAD法に基づく熱力学記述子の設計とデータベース構築
2. 組成-構造-特性関係の記述子エンジニアリング
3. ベイズ最適化（BO）による多目的組成探索（強度・延性・耐食性）
4. 第一原理計算（DFT）相当のデータ生成と検証（物理モデルベース）
5. 能動学習（AL）ループによる実験提案の効率化
6. CrMnFeCoNi系超耐熱HEA設計ケーススタディ

### 1.2 高エントロピー合金とは

高エントロピー合金は、5種類以上の主要元素を近等モル比（5〜35 at.%）で含む固溶体合金として2004年にCantor等とYeh等によって独立に提案された。典型的な組成であるCrMnFeCoNiカンター合金は：
- 優れた低温破壊靭性（>200 MPa·m^0.5）
- 高い延性（室温で~45–60%）
- 強い放射線損傷耐性

を示す一方、高温（>800°C）での相安定性・クリープ抵抗が課題となっている。

### 1.3 課題設定

高エントロピー合金の組成空間は元素周期表の64元素から5元素を選ぶと~7×10⁸通りの5元合金が存在し、試行錯誤的な実験では探索が不可能である。機械学習と最適化アルゴリズムを組み合わせることで、この巨大な組成空間を効率的に探索することを目指す。

### 2.3 先行研究の課題・限界

1. **単目的最適化**: 多くの研究が硬度単体の最適化に集中し、強度・延性・耐食性の同時最適化を行っていない
2. **小規模データ**: 実験データが200〜1200件と少なく、過学習リスクが高い
3. **能動学習の不足**: 実験効率化のための能動学習を組み込んだ研究が少ない
4. **解釈可能性**: ブラックボックスモデルが多く、材料科学的知見との接続が弱い
5. **高温特性の欠如**: 室温特性に集中し、クリープ・酸化など高温特性の予測が少ない

### 3.2 評価

NatureLMは分子化学（SMILES記法ベース）向けに設計されており、金属合金の物性予測には現時点で対応していないと判断される。`predict_property`が対応する物性は有機分子のlogP・分子量などに限定される。本研究では物理情報組み込みMLフレームワークを代替手段として全定量予測を実施した。

## 4. 使用した手法・アルゴリズム

### 4.1 熱力学記述子（10特徴量）

| 記述子 | 数式 | 物理的意味 |
|-------|------|----------|
| ΔS_mix | -R Σ xᵢ ln xᵢ | 理想混合エントロピー（J/mol·K） |
| ΔH_mix | Σᵢ≠ⱼ xᵢxⱼΩᵢⱼ | 混合エンタルピー（kJ/mol） |
| δ_r | √(Σ xᵢ(1-rᵢ/r̄)²)×100 | 原子半径差（%） |
| VEC | Σ xᵢ VECᵢ | 価電子濃度 |
| δ_χ | √(Σ xᵢ(χᵢ-χ̄)²) | 電気陰性度差 |
| T_melt | Σ xᵢ Tᵢ | 加重平均融点（K） |
| Ω | ΔS_mix·T_m / \|ΔH_mix\| | 熱力学安定性パラメータ |
| φ | ΔS_mix / (R·ln N) | エントロピー形成効率 |
| N | - | 元素数 |
| mass | Σ xᵢ mᵢ | 加重平均原子量 |

### 4.2 機械学習モデル

**Random Forest (RF)**
- 200本の決定木、ジニ不純度基準
- OOB誤差による暗黙の交差検証

**Gradient Boosting (GB)**
- 200エスティメータ、学習率0.05、最大深度3
- 逐次的弱学習器の結合

**Multi-layer Perceptron (MLP)**
- アーキテクチャ：128→64→32（ReLU活性化）
- Adamオプティマイザ、最大1000エポック

### 4.3 多目的ベイズ最適化

**期待改善量（EI）獲得関数**：
```
EI(x) = (μ(x) - f* - ξ)·Φ(z) + σ(x)·φ(z)
where z = (μ(x) - f* - ξ) / σ(x)
```

**多目的結合獲得関数**：
```
ACQ_combined = EI_YS/max(EI_YS) + EI_El/max(EI_El) + EI_Corr/max(EI_Corr)
```

初期サンプル30件、50イテレーション実行。RFアンサンブルの木間標準偏差をGP事後分散の近似として使用。

### 4.4 能動学習

**不確実性サンプリング**: RFアンサンブルの予測標準偏差が最大の候補を次の実験点として選択
**ランダムサンプリング**: プール全体から一様ランダムに選択
→ 50サンプル初期セット＋40ステップの逐次追加

### 4.5 パレートフロント解析

非劣解（どの目的でも他の解より悪くない解）の集合をパレートフロントとして特定。3目的（YS最大化、延性最大化、耐食性最大化）のパレート最適解を抽出。

## 6. 考察と今後の展望

### 6.1 記述子の有効性

Ωパラメータが最重要特徴量（重要度0.21）であることは、エントロピー安定化メカニズムの中心的役割を確認する。VECの重要度（0.18）はFCC/BCC構造分岐（VEC>8→FCC、<6.5→BCC）の周知の経験則と一致する。T_meltの高い重要度（0.16）は、融点が固溶体強化のスケールファクターとして機能することを示す。

### 6.2 耐食性予測の限界

耐食性スコアのR²≈0.49は、本フレームワークの最大の弱点である。耐食性はCr含有量（Cr>12 at.%で不動態皮膜形成）、Al添加による酸化物形成エネルギー（DFT計算値）、表面偏析傾向など、本記述子セットでは捕捉できない要素に強く依存する。今後の課題として以下を挙げる：
- Cr/Al/Mo各元素の実際の含有量を個別特徴量として追加
- DFT計算による酸化形成エネルギーをMaterials Project APIから取得

### 6.3 BO候補合金の材料科学的解釈

**CrFeCoNiV10（BO-2）の優位性**: Vは原子半径134 pm（CrMnFeCoNiの平均~126 pmより大）でFCC格子の格子定数を拡大し、適度な格子歪みエネルギーを生成。VEC=7.80は依然FCC安定域（>7.5）に位置する。Ω=13.90は固体溶液安定性が高いことを示す。

**Al添加系（BO-1、BO-5）の問題**: Al添加はVECを低下させBCC転移を促進し（Al>8 at.%でBCC生成）、H_mixを正側に押し上げる。BO-5（Al10Ti5）でH_mix=20.08 kJ/mol、Ω=1.34となり、固体溶液安定性の低下が延性の著しい低下（10.5%）をもたらした。

**Mo/W添加系（BO-4）**: Mo/W添加は耐高温性・クリープ強度を向上させるが（T_melt増加）、δ_r=4.25%と大きく、延性が19.7%に低下。高温用途向けには適するが室温延性のトレードオフに注意。

### 6.4 カンター合金との比較

| 特性 | カンター合金（実験値） | カンター合金（本ML予測） | BO-2（CrFeCoNiV10） |
|-----|-------------------|---------------------|-------------------|
| 降伏強度 (MPa) | ~200–600（多結晶） | 869.4 | 898.1（+3.3%） |
| 伸び (%) | ~45–60 | 37.6 | 31.6 |
| 耐食性 | 良（定性） | 69.1/100 | 67.2/100 |

本フレームワークの絶対値予測は実験値より高い（869.4 vs 200–600 MPa）。これはモデルが微細粒多結晶合金（粒径~50 μm）の固溶強化成分を反映していることに起因する。**相対的な順序付けと組成トレンドの予測は信頼性が高い**。

### 6.5 今後の展望

1. **AFLOW/Materials Project APIとの統合**: 実DFT計算データ（混合エンタルピー、SFE、弾性定数）を直接利用してモデルを再訓練
2. **グラフニューラルネットワーク（GNN）**: 結晶構造グラフを入力とするEnd-to-Endモデル
3. **高温クリープ・酸化予測**: 第一原理MD計算データと連携した高温特性の予測モデル追加
4. **難熔HEA系への拡張**: NbMoTaW系（>1000°C用途）への本フレームワーク適用
5. **実験的検証**: BO-2（CrFeCoNiV10）組成のアーク溶解・特性評価
