# Active Debris Removal (ADR) Mission Optimal Trajectory Design System — Report

## 1. 実験目的と背景

宇宙デブリの増加は、低軌道（LEO）における運用衛星への衝突リスクを著しく高めている。アクティブデブリ除去（ADR: Active Debris Removal）は、高リスクデブリを能動的に軌道離脱させる手法として国際的に注目されている。本研究では、ADRミッションの包括的な最適軌道設計システムを開発し、以下の6つのモジュールを統合的にシミュレーションした：

1. **デブリカタログからのターゲット選定**（衝突リスク×除去効果スコアリング）
2. **マルチターゲット除去の最適軌道遷移計画**（遺伝的アルゴリズムによる低推力軌道）
3. **ランデブー・近接運動シミュレーション**（Hill/Clohessy-Wiltshire方程式）
4. **姿勢不安定デブリの回転運動推定**（オイラー方程式＋移動平均フィルタ）
5. **捕獲機構の動力学**（ロボットアーム/ネット/ハープーン）
6. **ミッションシーケンスのコスト最小化**（全順列探索＋コストモデル）

## 2. 使用した手法・アルゴリズムの概要

### 2.1 デブリスコアリング
衝突確率、デブリ質量、断面積、軌道高度に基づく滞留寿命ファクターを組み合わせた複合スコア：
$$\text{Score} = P_{\text{collision}} \times e^{(h-600)/200} \times \frac{m \times A}{1000}$$

### 2.2 遺伝的アルゴリズム（GA）による巡回順序最適化
- 母集団サイズ: 100、世代数: 200
- 順序交叉（Order Crossover）＋突然変異率 30%
- 適応度関数: ΔV + 0.001 × 遷移時間（日）

### 2.3 Hill/CW方程式によるRPO
Clohessy-Wiltshire状態遷移行列を用いた2インパルスランデブー計画。

### 2.4 オイラー方程式＋クォータニオン動力学
非対称剛体のトルクフリー回転を数値積分し、ノイズ付き観測からの移動平均フィルタによる角速度推定。

### 2.5 捕獲機構
- **ロボットアーム**: 3リンク平面マニピュレータ、ダンプ最小二乗法による逆運動学
- **ネット**: テザード展開ネットの質点モデル
- **ハープーン**: 射出・貫通・テザー張力動力学

### 2.6 コスト最適化
ツィオルコフスキーの式に基づく燃料消費量、運用コスト、打上げコストの統合モデル。Isp=3000s（電気推進）。

## 4. 考察と今後の展望

### 4.1 考察
- スコアリングシステムにより、高高度・大質量・高衝突確率のデブリが優先的に選定された。これはESAの環境インデックスに基づく先行研究の知見と整合する。
- GAによる巡回順序最適化は200世代で良好な収束を示し、全順列探索の最適解と一致した。5ターゲットでは全探索が可能だが、10以上のターゲットではGAや強化学習ベースの手法が不可欠。
- Hill方程式によるRPOは、総ΔV 0.833 m/sで510mからの精密ランデブーを実現。実運用ではセンサノイズや摂動の影響を考慮した誘導則が必要。
- タンブリング推定の移動平均フィルタは平均誤差0.5 deg/sを達成したが、拡張カルマンフィルタ（EKF）やUKFの適用により精度向上が期待される。
- 3種類の捕獲機構すべてが成功を示したが、実際のミッションではデブリ形状・回転状態に応じた機構選択が重要。

### 4.2 今後の展望
- GMAT/Orekitとの連携による高精度軌道伝播の導入
- 強化学習（PPO/A2C）ベースのスケーラブルなシーケンス最適化
- 6自由度連成（軌道＋姿勢）シミュレーション
- 実デブリカタログ（TLE/DISCOS）との統合
- モンテカルロ分析による不確実性評価
