# トポロジカル絶縁体材料の理論設計フレームワーク — 実験レポート

## 1. 実験目的と背景

本研究では、新規トポロジカル絶縁体（TI）材料の効率的な理論設計を可能にする統合計算フレームワークを開発した。Bi₂Se₃を代表とする3次元強トポロジカル絶縁体は、スピン-軌道相互作用（SOC）によるバンド反転を介して非自明なZ₂トポロジカル位相を示し、ロバストな表面ディラック状態を有する。本フレームワークは以下の6つの計算モジュールを統合する：

1. **対称性指標によるトポロジカル分類** — 空間群データベースを活用し、高対称点でのパリティ固有値からZ₂不変量を判定
2. **Wannier関数タイトバインディングモデル** — 最局在Wannier関数に基づく有効ハミルトニアン構築
3. **Z₂/Chern数自動計算パイプライン** — Wilson loopおよびBerry曲率の離散化計算
4. **スラブ計算による表面状態解析** — 有限厚みスラブモデルでのディラック分散評価
5. **SOC強度-位相転移マッピング** — パラメータ空間でのトポロジカル位相図作成
6. **Bi₂Se₃類似体スクリーニング** — 候補物質の系統的同定

## 2. 使用した手法・アルゴリズム

### 2.1 有効ハミルトニアンモデル

Bi₂Se₃の4バンド有効モデル（Zhang et al., 2009）を基盤として使用：

$$H(\mathbf{k}) = \epsilon(\mathbf{k})\mathbb{I}_4 + M(\mathbf{k})\Gamma_5 + A_1 k_z \Gamma_1 + A_2(k_x \Gamma_2 + k_y \Gamma_3)$$

ここで：
- $\epsilon(\mathbf{k}) = C_0 + C_1 k_z^2 + C_2 k_\perp^2$
- $M(\mathbf{k}) = M_0 - M_1 k_z^2 - M_2 k_\perp^2$
- $\Gamma_i$はDiracガンマ行列

パラメータ値：$C_0=0$, $C_1=1.77$, $C_2=6.86$, $M_0=0.28$ eV, $M_1=10.0$, $M_2=56.6$, $A_1=2.26$ eV·Å, $A_2=4.08$ eV·Å。

### 2.2 Z₂不変量計算

Wilson loop法によるWannier電荷中心（WCC）の追跡を実装。ブリルアンゾーンの特定平面（kz=0, kz=π）上でWCCの発展を計算し、参照線との交差回数のパリティからZ₂不変量を決定する。

### 2.3 Chern数計算

離散化Berry曲率法を使用。kx-ky平面上のプラケット計算により：

$$C = \frac{1}{2\pi} \sum_{\text{plaquettes}} \text{Im} \ln(U_{12} U_{23} U_{34} U_{41})$$

### 2.4 スラブ計算

30層スラブモデルを構築し、z方向に開放境界条件を適用。層間ホッピングをバルクモデルのパラメータから導出し、表面スペクトル重みを計算してバルク状態と表面状態を区別した。

### 2.5 SOC-位相転移マッピング

SOC強度パラメータλ/λ₀と質量パラメータM₀の2次元パラメータ空間を走査し、Γ点でのバンドギャップ閉塞・再開を追跡することで位相図を構築した。

## 3. 主要な結果

### 3.1 バルクバンド構造

Bi₂Se₃の4バンドモデルによるバルクバンド構造を計算した。Γ点での直接バンドギャップは0.56 eV（実験値~0.3 eVとの差はモデルの簡略化による）。SOCによるバンド反転が明確に観測された。

![Figure 1: Bi₂Se₃バルクバンド構造](figures/fig1_bulk_bands.png)

### 3.2 Z₂不変量（Wilson Loop解析）

kz=0平面およびkz=π平面でのWannier電荷中心の発展を計算した。kz=0平面ではZ₂=1（非自明）が得られ、WCCが参照線（0.5）を奇数回横切ることを確認した。

![Figure 2: Wannier電荷中心の発展とZ₂不変量](figures/fig2_wilson_loop.png)

### 3.3 表面ディラック状態

30層スラブ計算により、Γ点に中心を持つ単一ディラック錐の表面状態分散を確認した。表面状態（赤）はバルクバンドギャップ内を線形に分散し、ディラック点はギャップ中央付近に位置する。

![Figure 3: スラブ計算による表面ディラック分散](figures/fig3_surface_dirac.png)

### 3.4 SOC-位相転移マッピング

4つの代表物質（Bi₂Se₃, Bi₂Te₃, Sb₂Te₃, TlBiSe₂）について、SOC強度に対するバンドギャップの変化を追跡した。位相図はM₀>0かつ有限SOCの領域でトポロジカル絶縁体相が安定であることを示す。

![Figure 4: SOC-位相転移のマッピング](figures/fig4_soc_phase.png)

## 4. 考察と今後の展望

### 4.1 フレームワークの有効性

本フレームワークは、対称性指標からWilson loop、スラブ計算、物質スクリーニングまでを統合的に扱うことで、トポロジカル物質探索の効率を大幅に向上させる。特に、SOC-位相転移マッピングは新規候補物質の設計指針として有用である。

### 4.2 限界と改善点

- **モデルの精度**: 4バンド有効モデルはΓ点近傍でのみ有効であり、完全なab initio計算との整合性検証が必要
- **表面効果**: スラブ計算における表面ポテンシャルの取り扱いを改善する余地がある
- **磁性材料**: 現行フレームワークは非磁性系に限定されており、磁性トポロジカル絶縁体への拡張が今後の課題

### 4.3 今後の方向性

1. AiiDAワークフローマネージャとの統合による完全自動化
2. 機械学習による高速スクリーニングの導入
3. 高次トポロジカル絶縁体（HOTI）への分類拡張
4. 実験グループとの連携による予測物質の合成検証
