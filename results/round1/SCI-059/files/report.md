# 疾病リスクの空間パターン解析と予測のためのジオスタティスティカルフレームワーク — 実験レポート

## 1. 実験目的と背景

本実験は、疾病リスクの空間的・時空間的パターンを解析・予測するための統合的なジオスタティスティカルフレームワークを構築することを目的とする。具体的には以下の6つの要素を統合的に実装・評価した：

1. **Log-Gaussian Cox Process (LGCP)**: 空間点過程モデルによる疾病発生の空間強度推定
2. **ベイズ空間モデル (INLA/SPDEアプローチ)**: ガウス過程回帰によるリスク面の推定と不確実性定量化
3. **空間的自己相関の検定**: Moran's I統計量およびバリオグラム解析
4. **生態学的交絡バイアス対策**: 空間調整による交絡制御
5. **時空間knot-basedスプラインモデル**: RBFベースの時空間予測
6. **マラリア・デング熱リスクマッピング**: 実践的ケーススタディ

## 2. 使用した手法・アルゴリズムの概要

### 2.1 Log-Gaussian Cox Process (LGCP)

LGCPは空間点過程の一種で、強度関数 λ(s) をガウス確率場 S(s) を用いて以下のようにモデル化する：

```
λ(s) = exp(μ + S(s))
```

ここで S(s) はMatérnカーネル（ν=1.5）を持つガウス過程であり、Cholesky分解により空間的相関構造を持つ乱数場を生成した。

### 2.2 ベイズ空間モデル（GP-SPDEアプローチ）

R-INLAのSPDEアプローチをPythonで近似実装した。Matérnカーネルを用いたガウス過程回帰（GPR）により、共変量（気温、降水量、標高、都市化率）と空間座標を入力として log(SIR) を予測する。5分割交差検証により汎化性能を評価した。

### 2.3 空間的自己相関

- **Global Moran's I**: k近傍（k=8）に基づく逆距離重み付き空間重み行列を構築し、空間的自己相関の有無と強度を検定
- **Variogram**: 経験的セミバリオグラムを計算し、球状・指数・ガウスモデルをフィッティング

### 2.4 生態学的交絡バイアス対策

- Naive OLS（環境共変量のみ）とSpatial OLS（空間座標の多項式項を追加）を比較し、空間的交絡の影響を定量化
- AIC・R²による比較およびcoefficient changeの分析

### 2.5 時空間knot-basedスプラインモデル

- 空間RBFカーネルと時間RBFカーネルの組み合わせにより時空間基底関数を構築
- Ridge正則化による回帰でスプラインモデルを学習
- 時間分割（月1–10:訓練, 月11–12:テスト）によるforecast評価

### 2.6 疾病リスクマッピング

マラリアとデング熱の合成データを用いてGPRによるリスク面推定、不確実性マッピング、超過確率マップを生成した。

## 3. 主要な結果と数値

### 3.1 Log-Gaussian Cox Process

30×30グリッド（σ²=1.5, κ=1.2, μ=-1.5）でLGCPをシミュレーションし、115個の空間点を生成した。

![LGCP Simulation](figures/lgcp_simulation.png)

左から順に：対数強度面 S(x)、強度面 λ(x)=exp(μ+S(x))、生成された点パターンを示す。空間的にクラスター化した点パターンが正しく再現されている。

### 3.2 ベイズ空間モデル（GP-SPDE）

- **交差検証 R²**: 0.979 ± 0.008
- **最適化カーネル**: Matérn(length_scale=6.33, ν=1.5) + WhiteKernel(noise_level=1e-05)
- **対数周辺尤度**: 22.03

![Bayesian Spatial Model](figures/bayesian_spatial_model.png)

真のリスク面（左上）、予測平均（右上）、事後不確実性（左下）、観測値 vs 予測値（右下）を示す。GPモデルは非常に高い精度でリスク面を再現している。

### 3.3 SPDEメッシュ

![SPDE Mesh](figures/spde_mesh.png)

Delaunay三角形分割によるSPDEメッシュ（200ノット）と、単一頂点の基底関数の可視化。

### 3.4 空間的自己相関

- **Global Moran's I**: 0.9527 (Z=16.384, p<0.0001)
- **最適バリオグラムモデル**: ガウス型 (nugget=0.000, sill=306.818, range=3.291)

![Spatial Autocorrelation](figures/spatial_autocorrelation.png)

左：Moran散布図（強い正の空間的自己相関を確認）、中央：経験的・理論的バリオグラム、右：SIRの空間分布。

### 3.5 生態学的交絡バイアス分析

| モデル | R² | AIC |
|--------|-----|-----|
| Naive OLS | 0.866 | 110.7 |
| Spatial OLS | 0.904 | 80.2 |

主要な共変量係数の変化：
- 気温: 0.155 → 0.059 (**−62.0%**)
- 降水量: 0.0024 → 0.0026 (+8.9%)
- 標高: 0.0004 → −0.0024 (**−652.6%**)
- 都市化率: 3.123 → 2.120 (**−32.1%**)

![Ecological Bias Analysis](figures/ecological_bias_analysis.png)

空間調整後に気温と都市化率の係数が大幅に減少しており、空間的交絡の存在を示唆する。

## 4. 考察と今後の展望

### 考察

1. **GPベイズ空間モデル**は最も高い予測精度（CV R²=0.979）を達成し、INLA/SPDEアプローチの有効性を確認した
2. **強い空間的自己相関**（Moran's I=0.953）がSIRに存在し、空間モデルの必要性を裏付けた
3. **生態学的交絡**: 空間調整により気温係数が62%減少し、空間的交絡の深刻さが示された
4. **時空間スプラインモデル**のテスト性能は限定的（R²=-0.051）であり、基底関数の選択やノット配置の改善が必要
5. **疾病ケーススタディ**では超過確率マップが公衆衛生的介入の優先地域特定に有用であることを示した

### 今後の展望

- R-INLAのSPDEアプローチの完全な実装（確率的偏微分方程式に基づくメッシュ）
- MCMCベースのベイズ推論との比較
- 実データ（DHS/MIS調査データ等）への適用
- 深層学習ベースの空間モデル（GNN等）との統合
- 時変共変量の組み込みと動的リスク予測
