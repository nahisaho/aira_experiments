# 火山性地殻変動データからのマグマ供給系3D構造インバージョン — 実験レポート

## 1. 実験目的と背景

本実験では、火山性地殻変動データからマグマ供給系の3次元構造を推定するベイズインバージョンフレームワークを設計・実装した。具体的には以下の6つの課題に取り組んだ：

1. **点圧力源（Mogi）/回転楕円体/有限要素モデルの比較** — 各モデルの変位場特性を定量比較
2. **ベイズインバージョン（MCMC法）による不確実性定量化** — emcee を用いたアンサンブルサンプラーでパラメータの事後分布を推定
3. **GNSS+InSAR+重力データの統合インバージョン** — 3種の測地データを同時に逆解析
4. **時間変化するソースのカルマンフィルタ推定** — 拡張カルマンフィルタによる体積変化の逐次推定
5. **粘弾性地殻応答の効果補正** — Maxwell 粘弾性モデルによる緩和効果の評価
6. **桜島/阿蘇のケーススタディ** — 合成データによる検証

## 2. 使用した手法・アルゴリズム

### 2.1 順問題モデル

- **Mogi モデル**: 弾性半空間中の点圧力源。パラメータ: 位置 (xs, ys)、深さ d、体積変化 dV
- **回転楕円体モデル**: Yang et al. (1988) 近似。パラメータ: 位置、深さ、半長軸 a、半短軸 b、圧力変化 dP
- **FEM+粘弾性モデル**: Mogi 弾性解に Maxwell 粘弾性緩和カーネルを適用

### 2.2 ベイズ MCMC インバージョン

- **サンプラー**: emcee アンサンブルサンプラー (Foreman-Mackey et al., 2013)
- **ウォーカー数**: 32、ステップ数: 2000（バーンイン: 500）
- **事前分布**: ソース位置に正規分布、深さに一様分布、体積変化に正規分布
- **尤度関数**: GNSS 3成分 + InSAR LOS + 重力変化のガウス尤度

### 2.3 カルマンフィルタ

- 拡張カルマンフィルタ (EKF) で状態ベクトル [xs, ys, d, dV] を逐次推定
- 数値ヤコビアンによる観測行列 H の計算
- プロセスノイズ Q と観測ノイズ R の調整

### 2.4 粘弾性補正

- Maxwell 粘弾性体の緩和時間 τ = η/μ
- 変位増幅係数: 1 + 1/(2(1-ν)) × (1 - exp(-t/τ))

## 3. 主要な結果

### 3.1 順問題モデル比較

![Forward Model Comparison](figures/model_comparison.png)

| モデル | 最大鉛直変位 (mm) | 最大重力変化 (µGal) |
|--------|-------------------|---------------------|
| Mogi | 45.35 | 35413.2 |
| Spheroid | 25.05 | 13183.1 |
| FEM+Viscoelastic | 48.08 | 35412.3 |

- Mogi モデルは点源として最大の変位を示す
- 回転楕円体モデルは形状効果により変位振幅が約55%に低下
- 粘弾性補正 (η=10¹⁹ Pa·s, t=1年) により変位は約6%増幅

## 4. 考察と今後の展望

### 考察

1. **モデル選択**: Mogi モデルは計算効率が高く合成データでは十分だが、実データでは回転楕円体や FEM モデルがより現実的な結果を与える可能性がある
2. **統合インバージョン**: GNSS+InSAR+重力の統合により、パラメータ間のトレードオフが大幅に減少し、特に深さと体積変化の分離が改善された
3. **カルマンフィルタ**: 初期収束後の追跡性能は良好だが、急激な変化への追従にはプロセスノイズの適応的調整が必要
4. **粘弾性効果**: 低粘性率の火山地域では無視できず、長期モニタリングでの補正が不可欠

### 今後の展望

- FEniCS による完全な 3D 有限要素順問題との結合
- 実データ（桜島 GNSS / ALOS-2 InSAR）への適用
- 複数ソースの同時推定（trans-dimensional MCMC）
- GPU 加速による大規模 InSAR データの高速処理
