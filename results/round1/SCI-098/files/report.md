# 暗黒物質直接検出実験の次世代戦略シミュレーション — 実験レポート

## 1. 実験目的と背景

本研究は、暗黒物質（Dark Matter, DM）の直接検出実験における次世代戦略を設計・評価するためのモンテカルロシミュレーションフレームワークを開発し、以下の6つの課題を体系的に分析することを目的とする。

1. **WIMP以外の暗黒物質候補**（アクシオン、暗黒光子、プリモーディアルブラックホール）の検出可能性評価
2. **方向感度検出器**（CYGNUS/MIMAC型ガスTPC）の感度計算
3. **ニュートリノフロア**（coherent elastic neutrino-nucleus scattering, CEνNS）への到達予測
4. **バックグラウンド低減戦略**の体系的評価
5. **多ターゲット戦略**（Xe/Ar/Ge/NaI）の相補性分析
6. **年周変動シグナル**の統計的検出力評価

### 研究背景

現在、LZ、XENONnT、PandaX-4T等の第2世代暗黒物質直接検出実験が世界最高感度でWIMP探索を行っている。LZ実験は417 live daysのデータ解析で、3–9 GeV/c²の質量領域でWIMPシグナルの証拠を見出していない（Aalbers et al., 2023）。一方、これらの実験はニュートリノフロアに到達しつつあり、太陽ニュートリノからのCEνNSによる核反跳を初めて測定した（XENONnT, 2024）。

O'Hare (2021) はニュートリノフロアの新定義を提案し、ニュートリノフラックスの系統的不確かさのみに依存する統計的に厳密なフロアを計算した。Vahsen et al. (2020) はCYGNUS方向感度検出器のフィージビリティスタディを発表し、1000 m³のガスTPCでニュートリノフロア以下の探索が可能であることを示した。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 シミュレーションフレームワーク構成

GEANT4/ROOT のワークフローに着想を得た Python ベースのモンテカルロシミュレーションフレームワークを開発した。フレームワークは以下の8モジュールから構成される：

| モジュール | 機能 |
|---|---|
| `DMHalo` | Standard Halo Model（SHM）に基づく暗黒物質速度分布 |
| `WIMPDetector` | WIMP-核子散乱率計算（Helm 形状因子、コヒーレント増強） |
| `AxionDetector` | アクシオ電気効果による感度計算 |
| `DarkPhotonDetector` | 暗黒光子吸収感度 |
| `PBHDetector` | プリモーディアルBHの制約 |
| `DirectionalDetector` | CYGNUS型方向感度検出器のシミュレーション |
| `NeutrinoFloor` | CEνNSに基づくニュートリノフロア計算 |
| `BackgroundModel` | バックグラウンド源と低減戦略の評価 |
| `MultiTargetAnalysis` | 多ターゲット相補性解析 |
| `AnnualModulation` | 年周変動シグナルの統計的検出力 |

### 2.2 物理モデル

**速度分布**: 脱出速度 v_esc = 544 km/s で切断された Maxwell-Boltzmann 分布（SHM）。v₀ = 220 km/s、v_Earth = 232 km/s。

**微分散乱率**:
```
dR/dE_R = N_T × (ρ_χ/m_χ) × c × σ_A × F²(E_R) × m_A/(2μ_A²) × η(v_min) × 変換係数
```

**Helm 形状因子**: Lewin & Smith (1996) のパラメタリゼーション。

**ニュートリノフロア**: 8B、hep、大気ニュートリノからのCEνNS反跳率を計算し、ニュートリノフラックス不確かさ（~5%）に基づくフロアを導出。

## 3. 主要な結果と数値

### 3.1 排他曲線（WIMP-核子断面積上限）

各ターゲット材料の90% CL排他限界を計算した。

| DM質量 [GeV] | Xe (1000 kg·yr) | Ar (3000 kg·yr) | Ge (100 kg·yr) | Combined |
|---|---|---|---|---|
| 10 | 1.90×10⁻⁴⁷ | 5.16×10⁻⁴⁶ | 2.14×10⁻⁴⁶ | 1.90×10⁻⁴⁷ |
| 50 | 6.83×10⁻⁴⁸ | 1.83×10⁻⁴⁷ | 1.26×10⁻⁴⁶ | 6.83×10⁻⁴⁸ |
| 100 | 9.89×10⁻⁴⁸ | 2.19×10⁻⁴⁷ | 1.71×10⁻⁴⁶ | 9.89×10⁻⁴⁸ |
| 500 | 4.14×10⁻⁴⁷ | 7.55×10⁻⁴⁷ | 6.50×10⁻⁴⁶ | 4.14×10⁻⁴⁷ |

![排他曲線：多ターゲット比較](figures/exclusion_limits.png)

### 3.2 反跳エネルギースペクトル

異なるWIMP質量およびターゲット材料について微分反跳率を計算した。重いターゲット（Xe）は高質量WIMPに、軽いターゲット（Ar, Ge）は低質量WIMPに相対的に高い感度を持つ。

![反跳エネルギースペクトル](figures/recoil_spectra.png)

### 3.3 方向感度検出器

CYGNUS型ガスTPC検出器の性能を3つの体積スケール（10, 100, 1000 m³）で評価した。

- 反跳方向分布は明瞭なダイポール非等方性を示し、WIMP風の方向（Cygnus座方向）に集中する
- 1000 m³検出器は3年の観測で、低質量（< 10 GeV）領域でニュートリノフロア近傍まで到達可能

![方向感度検出器の性能](figures/directional_sensitivity.png)

### 3.4 ニュートリノフロア

4種のターゲット材料（Xe, Ar, Ge, He）についてニュートリノフロアを計算した。

- Xeターゲット: m_χ ~ 6 GeV で最深のフロア（~10⁻⁴⁹ cm²）
- Heターゲット: 低質量域で異なるフロア構造（CEνNSの質量依存性による）
- フロアの位置はターゲット核の質量数に強く依存

![ニュートリノフロア比較](figures/neutrino_floor.png)

### 3.5 バックグラウンド低減戦略

5つの低減戦略を1000 kg·yr露出で評価した。

| 戦略 | 総バックグラウンド [counts] | 低減率 |
|---|---|---|
| baseline | 18.60 | 1.0× |
| distillation | 3.71 | 5.0× |
| fiducialization | 2.57 | 7.2× |
| active_veto | 0.82 | 22.7× |
| combined | 0.57 | 32.6× |

combined戦略（蒸留 + active veto + fiducialization）により、ラドン・クリプトン由来バックグラウンドを3桁以上低減可能。残留バックグラウンドはCEνNS（0.50 counts）が支配的。

![バックグラウンド低減戦略](figures/background_strategies.png)

### 3.6 多ターゲット相補性

Xe/Ar/Ge/NaI の4ターゲット結合解析の結果：

- 低質量域（< 20 GeV）: Xe が最高感度
- 中質量域（20–200 GeV）: Xe が支配的だが Ar が補完
- 高質量域（> 200 GeV）: Xe と Ar が同程度の感度
- 結合排他限界は全質量域で単一ターゲットを上回る
- 質量再構成テスト：50 GeV WIMP の質量を Xe が最も精度よく再構成

![多ターゲット相補性](figures/multi_target.png)

### 3.7 非WIMP暗黒物質候補

アクシオン、暗黒光子、プリモーディアルBHの検出感度を評価した。

- **アクシオン**: Xe 1 t·yr で g_ae ~ 10⁻¹³ まで到達可能（0.1–100 eV 質量範囲）
- **暗黒光子**: 動的混合パラメータ κ ~ 10⁻¹⁶ まで探索可能
- **PBH**: 10⁻¹⁶–10⁰ M☉ の質量範囲で暗黒物質全量を占める可能性を制約

![非WIMP候補の検出感度](figures/non_wimp_candidates.png)

### 3.8 年周変動シグナル

NaI（250 kg）ターゲットでの年周変動検出力を評価した。

- σ_SI = 10⁻⁴² cm² でも5年の観測で有意な変調検出は困難
- 検出力はクロスセクションと観測期間に強く依存
- DAMA/LIBRA が報告する変調振幅は現在の感度で検証可能な領域にあるが、独立実験（ANAIS-112, COSINE-100）との結合解析で4.7σで否定されている

![年周変動解析](figures/annual_modulation.png)

## 4. 考察と今後の展望

### 4.1 主要な知見

1. **多ターゲット戦略の有効性**: 結合解析により全質量域で感度が向上し、特に系統誤差の低減に寄与する
2. **方向感度の重要性**: ニュートリノフロア突破には方向感度が不可欠。CYGNUS 1000 m³ が現実的な次世代候補
3. **バックグラウンド低減の限界**: combined戦略でもCEνNSが残留し、これが究極的な感度限界を規定
4. **非WIMP探索**: 同一実験装置でアクシオン・暗黒光子探索が可能であり、暗黒物質の本質に制約を与える

### 4.2 先行研究との比較

本フレームワークの排他限界はLZ (2023) やXENONnT (2024) の実測値と整合的であり、ニュートリノフロアの位置もO'Hare (2021) の解析的計算と一致する。方向感度検出器の到達感度はVahsen et al. (2020) のCYGNUSフィージビリティスタディと定性的に整合する。

### 4.3 今後の展望

- GEANT4 との完全統合によるより精密な検出器応答シミュレーション
- ROOT ベースの統計解析フレームワーク（RooStats/HistFactory）との連携
- DARWIN/XLZD の設計最適化への応用
- 超伝導ナノワイヤ検出器等の新技術の感度予測
