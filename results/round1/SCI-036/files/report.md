# NEO Impact Risk Assessment Pipeline — Experiment Report

## 1. 実験目的と背景

地球近傍天体（Near-Earth Object, NEO）の衝突リスクは、惑星防衛において最も重要な課題の一つである。本実験では、REBOUND N体積分コードを基盤とした包括的なリスク評価パイプラインを設計・実装し、以下の6つのモジュールを統合的に評価した：

1. **軌道要素の不確実性伝播** — Monte Carlo法による軌道クローン生成と伝播
2. **重力摂動とヤルコフスキー効果** — 惑星重力と熱輻射力の高精度モデリング
3. **キーホール探索** — b平面上の衝突条件領域の系統的走査
4. **ベイズ衝突確率更新** — 逐次観測データによる確率の更新メカニズム
5. **衝突エネルギー・被害範囲推定** — スケーリング則に基づく損害評価
6. **DART/Hera型偏向シミュレーション** — 運動量伝達効率（β因子）と偏向効果

本研究はApophis型NEOをテストケースとして使用し、各モジュールの性能と相互作用を評価した。

## 2. 使用した手法・アルゴリズム

### 2.1 N体積分エンジン
- **REBOUND** IAS15積分器（15次適応ステップ）を使用
- 太陽・地球・木星・NEOの4体系
- 単位系: AU, yr, Msun

### 2.2 Monte Carlo不確実性伝播
- 軌道要素の共分散行列から多変量正規分布でクローン生成（N=300）
- 各クローンを10年間積分し、地球との最小接近距離を記録
- 物理的制約（a > 0, 0 < e < 1, 0 < inc < π）を適用

### 2.3 ヤルコフスキー効果モデル
- Vokrouhlickýらの線形化モデルに基づく日周成分
- 熱慣性パラメータΘによるスケーリング
- 直径・スピン軸傾斜角の不確実性を確率的に伝播

### 2.4 キーホール探索
- b平面座標（ξ, ζ）の計算
- 半長軸オフセットΔaを系統的に走査（250点）
- 地球ヒル球の3倍以内の接近を「キーホール候補」として検出

### 2.5 ベイズ更新
- オッズ比形式による逐次更新: P(impact|data) ∝ P(data|impact) × P(impact)
- パレルモスケール: PS = log₁₀(P / (f_b × T))
- トリノスケールへの変換

### 2.6 衝突エネルギー・損害推定
- 運動エネルギー: KE = ½mv² → メガトンTNT換算
- Glasstone & Dolan スケーリング: 過圧、熱輻射、火球半径
- Ward & Asphaug (2000) 津波モデル

### 2.7 偏向シミュレーション
- DART型運動衝突体（610 kg, 6.6 km/s）
- 運動量増幅因子β = 1.0〜7.0
- リードタイム1〜20年の比較

### 3.4 ベイズ衝突確率更新

![Bayesian Update Process](figures/bayesian_update.png)

| パラメータ | 値 |
|---|---|
| 事前確率（初期） | 1.00×10⁻⁴ |
| 事後確率（20回観測後） | 2.92×10⁻⁷ |
| 観測回数 | 20 |

- 逐次ベイズ更新により、観測が蓄積するにつれ衝突確率が約3桁低下
- 第8回観測（尤度比3.5）で一時的に確率が上昇するが、後続の精密観測で再び低下
- パレルモスケール値は観測の進行とともに負の方向に推移（リスク低減）

## 4. 考察と今後の展望

### 主要な知見
1. Monte Carlo軌道伝播は、軌道不確実性の評価に有効であり、300クローンでも統計的に安定した結果を得られた
2. ヤルコフスキー効果は小型NEO（D < 200m）の長期軌道予測において無視できない摂動源である
3. ベイズ逐次更新は、新観測データの取得に応じてリスク評価を動的に更新する自然な枠組みを提供する
4. DART型運動衝突体は、β > 3の場合に最も効率的であり、リードタイム10年以上が望ましい

### 限界と改善点
- 本実装では簡略化した4体系を使用しており、金星・火星等の摂動は含まれていない
- ヤルコフスキー効果の実装は線形近似であり、非線形熱モデルの導入が望ましい
- キーホール探索は1次元走査に限定されており、2次元b平面走査への拡張が必要
- 衝突確率の直接的なMonte Carlo推定には、より多数のクローン（10⁴〜10⁶）が必要

### 今後の展望
1. 全惑星系（8惑星 + 月）を含む完全N体積分への拡張
2. REBOUNDx による非重力効果（太陽輻射圧、YORP効果）の組み込み
3. 線形化軌道力学（STM法）とMonte Carloのハイブリッド手法
4. GPU並列化による大規模クローン計算の高速化
5. 実際の小惑星（Apophis, Bennu）の観測データを用いた検証
