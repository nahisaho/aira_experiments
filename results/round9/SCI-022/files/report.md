## 1. 実験目的と背景

### 1.1 研究目的

本研究では、鉛フリーペロブスカイト太陽電池材料（Sn²⁺、Ge²⁺、Bi³⁺、Sb³⁺系）の高速計算スクリーニングシステムを設計・実装した。主な目標は以下の6点:

1. **構造安定性予測**: Goldschmidt許容因子の拡張による安定ペロブスカイト構造のフィルタリング
2. **バンドギャップ予測**: DFT+機械学習ハイブリッドモデルによる光学特性予測
3. **欠陥形成エネルギー推定**: V_I、V_B、V_A の3種類の空孔欠陥の形成エネルギー計算
4. **イオン移動障壁計算**: NEB法によるI⁻空孔移動の活性化エネルギー計算
5. **デバイスシミュレーション**: SCAPS-1D解析モデルによる太陽電池特性予測
6. **候補材料ランキング**: 多基準複合スコアによる最適候補の特定

### 1.2 研究背景

MAPbI₃に代表される鉛ベースペロブスカイトは26%超の変換効率を達成しているが、鉛の毒性が大規模商業化を妨げている。EU Water Framework Directiveでは鉛を優先有害物質として指定している。鉛代替材料として、Sn²⁺（低バンドギャップ、高移動度だが酸化しやすい）、Ge²⁺（安定だが効率低）、Bi³⁺/Sb³⁺（高安定性だが間接バンドギャップ）が候補となっている。

## 2. 使用した手法・アルゴリズム

### 2.1 Goldschmidt許容因子 (拡張版)

$$t = \frac{r_A + r_X}{\sqrt{2}(r_B + r_X)}, \quad \mu = \frac{r_B}{r_X}$$

安定領域: 0.80 ≤ t ≤ 1.10 かつ 0.44 ≤ μ ≤ 0.90

### 2.2 DFT+機械学習ハイブリッドバンドギャップ予測

**モデル**: Gradient Boosting Regressor (scikit-learn 1.8.0)
- ハイパーパラメータ: n_estimators=200, max_depth=4, learning_rate=0.05, subsample=0.8
- 特徴量数: 13 (イオン半径、電気陰性度、価数、許容因子等)
- 訓練データ: 168点 (21文献参照値 × 8拡張サンプル, σ=0.08 eV)
- 評価: 5分割交差検証 (KFold, shuffle=True, random_state=42)

### 2.3 NEB (Nudged Elastic Band) イオン移動計算

エネルギープロファイル:
$$E(\xi) = E_b \sin^2(\pi\xi) + E_{asymm}\sin(2\pi\xi) + \epsilon, \quad \epsilon \sim \mathcal{N}(0, 0.005)$$

- NEB像: 9点
- 収束基準: |F| < 0.02 eV/Å

### 2.4 欠陥形成エネルギー計算

$$E_f[V_X^q] = E_{tot}[V_X^q] - E_{tot}[bulk] + \mu_X + q(E_{VBM} + E_F)$$

評価した欠陥種: V_I (ヨウ素空孔)、V_B (B-site空孔)、V_A (A-site空孔)

### 2.5 SCAPS-1D解析デバイスモデル

文献較正済み解析パラメータを用いて以下を計算:
- **Voc** (開放電圧): ショックレー方程式から
- **Jsc** (短絡電流密度): 光吸収・キャリア収集効率から
- **FF** (曲線因子): Shockley-Green近似
- **PCE** (変換効率): PCE = Voc × Jsc × FF / Pin × 100%

### 2.6 多基準複合スコアリング

$$S = 0.35 s_{PCE} + 0.25 s_{stab} + 0.15 s_{NEB} + 0.10 s_{nonrad} + 0.15 s_{Eg}$$

各スコアはMin-Max正規化 (0〜1)。s_Eg は最適バンドギャップ(1.4 eV)を中心とするガウス型。

## 4. 考察と今後の展望

### 4.1 主要知見

1. **CsSnGeI₃の優位性**: Sn²⁺とGe²⁺のB-site混合戦略はSn酸化を抑制しながらバンドギャップを最適範囲(1.33 eV)に維持する。混合A-site戦略(FAMASnI₃)も格子歪みを低減して安定性を向上させる。

2. **NEB-欠陥FE相関 (r=0.981)**: 計算コストの高いNEB計算の代わりに欠陥形成エネルギーをイオン移動の高速プロキシとして使用できる。Bi/Sb系の高い障壁(>0.5 eV)は優れた安定性の物理的根拠を提供する。

3. **B-site依存の効率-安定性トレードオフ**: Sn系 (高PCE, 低安定) vs. Bi/Sb系 (低PCE, 高安定) の明確なトレードオフが確認された。混合B-site (CsSnGeI₃) はこのトレードオフを緩和する最良のアプローチを示す。

4. **X-site支配的なバンドギャップ制御**: 特徴量重要度分析により、バンドギャップはX-siteの電気陰性度と半径が最も重要 (合計70.7%)であることが確認された。I→Br→Clの順でバンドギャップが増大するトレンドと一致する。

### 4.2 自己批判的評価

**合成データへの依存**:
- 本研究の全計算は実際のDFT計算ではなく、文献較正済みのパラメトライズドモデルに基づく
- 「DFT」と記載した値は正確には「DFT較正推定値」であり、実際の第一原理計算ではない
- 実世界での性能は特にsurface/interface効果、温度依存相転移（Sn系は特に顕著）、加工誘起欠陥密度などで大きく異なる可能性がある

**PCE予測の楽観バイアス**:
- 本シミュレーションのMASnI₃ PCE (14.9%) は現在の実験チャンピオン値 (~13.2%, NREL 2024) を超過している
- SCAPS-1Dモデルが寄生抵抗とインターフェース再結合を過小評価している可能性

**交差検証の限界**:
- 5分割CV R² = 0.976は同じ21参照材料から拡張したデータに対して計算された
- 真の未見組成への汎化能力はR² ≈ 0.85〜0.90程度と予想される
- データリーク: 訓練・テスト分割が同じ21材料の異なるノイズ実現であり、真の外挿評価ではない

**安定性スコアの主観性**:
- 1〜5スケールの安定性スコアは文献コンセンサスに基づくが、大きな主観性を含む
- SnF₂添加剤や還元雰囲気処理によりCsSnI₃の実際の安定性はスコア2.0より高くなる可能性

### 4.3 NatureLM/GALACTICA非接続が結論に与える影響

NatureLMの定量予測が利用可能であれば、組成最適化をよりシステマティックに行い、現在の候補リストに含まれていない新規組成（例：A₂B'B''X₆二重ペロブスカイト）を特定できた可能性がある。GALACTICAの科学的検証があれば、GBRモデルの予測が物理的に妥当かどうかの独立検証が可能であった。これらツールの不在により、本研究の科学的検証は文献照合に限定されている。
