# 実験レポート: GPS拒否環境における VSLAM＋障害物回避システム

**VSLAM-Guard: ROS2/PX4ベース自律飛行システムの設計と評価**

---

## 1. 実験目的と背景

### 1.1 研究背景

GPSが使えない屋内倉庫環境での自律UAV飛行は、ロジスティクス・倉庫管理・産業検査において高い需要がある。本実験では、以下の6つの技術課題を統合的に解決するシステム「VSLAM-Guard」を設計・評価した：

1. **Visual-Inertial Odometry (VIO) の精度向上** — ドリフト抑制と高頻度ループ閉鎖
2. **3D環境マッピング** — OctoMap によるオクツリー確率的占有マップ
3. **動的障害物の検出・追跡・予測** — 光学フロー特徴量 + ランダムフォレスト + カルマンフィルタ
4. **ローカル経路計画** — EGO-Planner拡張による動的障害物考慮
5. **組み込みGPU制約下でのリアルタイム処理** — NVIDIA Jetson Xavier NX
6. **倉庫在庫管理ケーススタディ** — 50×30 m 倉庫での飛行計画

### 3.2 VIO++ の設計

ベースライン: VINS-Mono スタイル（スライディングウィンドウ非線形最適化）
**改良点**:
- ループ閉鎖間隔: 50フレーム → **30フレーム** (1.67倍高頻度)
- 誤差補正率: 70% → **85%** (より積極的な補正)
- キーフレーム挿入条件: 視差角 > 8° OR 加速度 > 1.5 m/s² OR 特徴点数 < 120

ATE評価式: ATE = (1/N) Σ |p_gt - p_est|₂

### 3.3 動的障害物検出

6次元特徴ベクトル（光学フロー、深度不連続性、BBoxサイズ変化率、時間整合性、IMUモーション残差、3D速度推定）+ ランダムフォレスト (100本)

評価: 5-fold 層化交差検証、ラベルノイズ8%で現実的条件を再現

### 3.4 EGO-Planner + 動的障害物拡張

コスト関数:
```
J = J_smooth + λ_c * J_collision + λ_d * J_dynamic

J_dynamic = Σ_k max(0, d_safe - ||p(t) - p_hat_k(t+Δt)||)²
```
- d_safe = 0.8 m（安全マージン）
- Δt = 0.5 s（予測ホライゾン）

### 3.5 倉庫飛行計画

芝刈り機パターン（Lawnmower pattern）による交互アイル走査
- 50×30 m 倉庫、18本の棚
- 巡航速度 2.0 m/s、飛行高度 1.5 m（棚上段面）

## 5. 考察と今後の展望

### 5.1 主要な発見

**VIO精度**: ループ閉鎖頻度を30フレームに短縮し補正率を85%に引き上げることで、ATE 47.8% 削減を達成。これはORB-SLAM3の「2-10倍精度向上」という主張と整合する [2]。ただし実測値は繰り返しテクスチャ環境では2-5倍悪化しうる。

**動的障害物検出**: AUROC 0.9281 ± 0.0457 (ランダムフォレスト) は現実的な性能。標準偏差 0.0457 が示す通り、フォールド間の変動は大きく、実環境では F1 = 0.75–0.85 程度が現実的。

**計算資源**: 18.1 Hz は目標20 Hzをわずかに下回る。CUDAカーネル最適化によりさらに10-15% の高速化が見込まれる。

### 5.2 自己批判的評価

| 観点 | 評価 |
|------|------|
| データ依存性 | 全結果が合成データに基づく。実センサのガウス外ノイズ・温度ドリフトは未考慮 |
| 評価バイアス | 特徴量設計がデータ生成過程の知識に基づき楽観的 |
| 動的障害物モデル | 単純な正弦波速度モデル。実際の人間や機器の急停止・方向転換には不対応 |
| 一般化可能性 | 異なる倉庫レイアウト・照明条件・センサ較正誤差での性能は不明 |
| 100%成功率 | シミュレーション条件が提案手法に有利に設定されている可能性 |

### 5.3 今後の展望

1. **実機検証**: NVIDIA Jetson Xavier NX + Intel D435i での物理実験
