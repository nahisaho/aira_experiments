## 1. 実験目的と背景

### 目的
本実験では、超臨界Enhanced Geothermal System（EGS）を対象とした以下の6要素を統合する数値シミュレーションフレームワークを構築・実行した：
1. 亀裂ネットワークのDiscrete Fracture Network（DFN）モデリング
2. 熱水連成解析（THM：Thermo-Hydro-Mechanical coupling）
3. 超臨界水の状態方程式（IAPWS-IF97）と輸送特性
4. 誘発地震リスクのクーロン応力変化（ΔCS）モデリング
5. 長期（30年）熱回収率の予測
6. 最適坑井配置の検討（400–1,000 m）
7. 日本・葛根田地熱地帯ケーススタディ

### 研究背景
超臨界地熱システムは水の臨界点（T_c = 374°C, P_c = 22.064 MPa）を超える条件で運用され、比エンタルピーが亜臨界流体の約5倍（~3,400 kJ/kg vs ~700 kJ/kg）に達する。岩手県・葛根田地熱フィールドでは地下5km深度で450–500°Cの温度が確認されており、日本初の超臨界EGSフィールドとして期待されている。2024年には反射法地震探査により超臨界流体の上部境界を日本で初めて直接映像化した（DOI: 10.3124/segj.77.24）。

## 2. 使用した手法・アルゴリズム

### 2.1 DFNモデル
| パラメータ | 値 |
|----------|-----|
| ドメインサイズ | 2,000 × 2,000 m |
| 亀裂数 | 150 |
| 長さ分布 | べき乗則（截断Pareto分布、指数 α=2.5） |
| 長さ範囲 | 50–1,000 m |
| 方位 | 正規分布 N(70°, 25°)（東北地方に整合） |
| 開口幅 | 対数正規 b = 10^(-4.5 + 0.5 log L) mm |
| 透水量係数 | 立方則 T = b³/(12μ_sc) |

### 2.2 超臨界水EOS（IAPWS-IF97 パラメトリック近似）
$$\rho(T,P) = \rho_c \left[1 + 0.85\frac{P/P_c - 1}{\tau^{4.5}} - 0.3(\tau-1)\right]$$

### 2.3 THM連成モデル（半解析的）
- 熱的減衰モデル（Gringarten型）：$T_{prod}(t) = T_{init} - \Delta T_{max}(1 - e^{-t/\tau_T})$
- 圧力上昇（Theis対数近似）
- 電力変換効率 η = 20%（超臨界フラッシュサイクル）

### 2.4 クーロン応力変化モデル
$$\Delta CS(r,t) = \mu_f \cdot \Delta P_{max} \exp\left(-\frac{r^2}{4D_h t}\right)$$

### 2.5 速度・状態摩擦（Rate-and-State）地震発生率モデル
$$r(t) = r_0 \exp\left(\frac{\Delta CS}{A_s \sigma_n}\right)$$

## 5. 考察と今後の展望

### 5.1 結果の妥当性
本シミュレーション結果（平均熱出力 71.5 MW）は、実世界のデータと比較して合理的な範囲内にある：
- **IDDP-2（アイスランド）**: 440°C / 実測 50 MW → 本研究は450°C / 71.5 MW（温度差に整合）
- **Habanero EGS（オーストラリア）**: 242°C / 30 MW → 本研究は初期温度差に比例して妥当
- **文献範囲**: 超臨界EGSの予測値 50–120 MW → 71.5 MW は43パーセンタイル

### 5.2 重要な限界と自己批判

1. **半解析的THMモデルの限界**: 均質等価多孔媒体を仮定しているが、実際の葛根田花崗岩では亀裂を通じた集中流が卓越し、熱的サーマルブレークスルーが早期に発生する可能性がある。実際の熱的減衰は本シミュレーションより30–50%大きい可能性がある。

2. **DFN-THM非連成**: DFNと流体流れの完全連成（TOUGH2-EDFM, OpenGeoSys-LIEレベル）は実装していない。連続媒体近似を使用。

3. **地震リスクの過大評価と過小評価の混在**: 
   - Gutenberg-Richterによる N(Mw>3.5) = 3.2回/年は理論最大値で過大評価的
   - BruneモデルによるMw ≤ 1.0は破壊長さの過小評価の可能性あり（既存断層が存在する場合）

4. **一定注水速度の仮定**: 実運用では交通信号プロトコルによる注水速度の動的制御が必要

5. **葛根田固有条件への依存**: 本結果は葛根田の地質条件（T=450°C、花崗岩、東北extensional応力場）に特化しており、他フィールドへの直接適用は再キャリブレーションが必要

### 5.3 今後の展望

1. **TOUGH2-FDEM/EOS1による完全連成シミュレーション**: 反応性移流・シリカスケーリングを含む
2. **3D DFN + OpenGeoSys-LIE**: 亀裂個別の力学連成を含む
3. **適応的注水プロトコル（Mignan et al.）**: 誘発地震リスクを40–70%低減
4. **実際のKakkonda地震データによるモデルキャリブレーション**: 2023年連続地震モニタリング（DOI: 10.1038/s41598-023-35159-8）データの利用
5. **超臨界水の実験的物性データとの比較**: IDDP-2実測値との整合性確認
