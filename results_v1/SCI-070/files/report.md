## 1. 実験目的と背景

### 1.1 研究目的

本研究は、里山生態系が提供する生態系サービスの経済的価値を包括的に評価するための**統合フレームワーク**を設計・実装することを目的とする。具体的には以下の6つの課題に取り組んだ：

1. **定量指標設計**：CICES v5.1に準拠した供給・調整・文化的サービスの定量指標体系
2. **空間的定量化**：InVESTモデル群による生態系サービスの空間明示的な定量化
3. **選好評価**：選択実験（Choice Experiment）による非市場価値の支払意思額（WTP）推定
4. **時間的評価**：割引率と世代間公平性の取り扱いに関する理論的枠組み
5. **制度連携**：国連SEEA-EA（生態系勘定）との整合性確保
6. **実証**：能登半島里山を対象としたケーススタディ

### 1.2 背景

生態系サービスの経済的価値評価は、Millennium Ecosystem Assessment (2005) 以降、TEEB (2010)、IPBES (2019) を経て急速に発展してきた。しかし、以下の課題が残されている：

- **統合性の欠如**：生物物理的モデル（InVEST等）と経済評価手法（CVM, CE等）の乖離
- **空間的精度**：ランドスケープスケールでのサービス供給・需要の空間的不整合
- **時間的公平性**：割引率の選択が長期的自然資本の価値を大きく左右する問題
- **制度的課題**：SEEA-EA等の国際統計基準との整合が不十分
- **日本固有の課題**：里山のような人為的管理に依存する半自然生態系の評価困難性

本フレームワークは、これらの課題に対して InVEST/ARIES ベースの空間モデリング、選択実験による選好評価、逓減割引率による時間的公平性、SEEA-EA準拠の勘定体系を統合的に組み合わせるアプローチを提案する。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 生態系サービス分類と定量指標

空間解像度は30mグリッド（Sentinel-2/ALOS整合）、時間解像度は年次を基本とした。

### 2.2 InVESTモデルによる空間的定量化

以下の7つのInVESTモデルを統合パイプラインとして実装した：

#### (a) Carbon Storage and Sequestration Model
- **アルゴリズム**: 4プール炭素ストック推定（地上部バイオマス、地下部バイオマス、土壌有機炭素、枯死有機物）
- **入力**: 土地被覆図、炭素密度テーブル（文献値ベース）
- **里山パラメータ**: 混合林 215 tC/ha、水田 70 tC/ha、竹林 135 tC/ha 等

#### (b) Sediment Delivery Ratio (SDR) Model
- **アルゴリズム**: 修正USLE（Universal Soil Loss Equation）
  - `A = R × K × LS × C × P`
- **パラメータ**: R因子 = 5,500 MJ·mm/ha/h/yr（能登地域）、LS因子 = 2.5（中程度地形）
- **里山特性**: 棚田のP因子 = 0.10（畦畔効果）、混合林のC因子 = 0.003

#### (c) Annual Water Yield Model
- **アルゴリズム**: Budyko-Zhang水収支方程式
  - `AET/P = 1 + ω_x - (1 + ω_x^Z)^(1/Z)` ただし `ω_x = Kc × PET/P`
- **気候パラメータ**: 年降水量 2,100 mm、可能蒸発散量 800 mm、Z = 11

#### (d) Nutrient Delivery Ratio (NDR) Model
- **対象物質**: 窒素（T-N）およびリン（T-P）
- **アルゴリズム**: 負荷量×保持効率による流出・保持量推定
- **里山特性**: 水田からの高N負荷（35 kg/ha/yr）に対し、森林の高保持効率（90%）

#### (e) Habitat Quality Model
- **アルゴリズム**: 脅威源からの劣化スコア → 半飽和関数による品質補正
  - `Q = H × (1 - D^z / (D^z + k^z))`
- **脅威源**: 集落（最大距離5km, 重み1.0）、畑地（3km, 0.7）、水田（2km, 0.3）

#### (f) Crop Pollination Model
- **アルゴリズム**: 営巣適性 × 花資源量の幾何平均による花粉媒介者豊度指数

#### (g) Recreation Model
- **アルゴリズム**: 土地被覆別魅力度スコア × 基準訪問密度

#### ARIES k.LAB連携
- 洪水調節サービスおよび文化的サービスの一部について、ARIES（ARtificial Intelligence for Ecosystem Services）k.LABプラットフォームとの連携設計を行った
- k.LABのセマンティックモデリングにより、InVESTでは捕捉しきれない空間的相互作用を補完

### 2.3 選択実験（Choice Experiment）設計

#### 理論的基盤
- Lancaster (1966) の特性理論：財は属性の束として評価される
- McFadden (1974) のランダム効用モデル（RUM）

#### 実験デザイン
- **属性**: 生物多様性（3水準）、水質（3水準）、景観管理（3水準）、炭素吸収（3水準）、年間支払額（5水準: 0～10,000円）
- **全因子実験**: 3⁴ × 5 = 405プロファイル
- **効率的デザイン**: D-efficient design（Ngene/pyDCE）で12選択セットに縮減
- **ブロッキング**: 3ブロック × 4セット/ブロック（認知負荷軽減）
- **各選択セット**: 2案 + 現状維持（opt-out）= 3択

#### 推定モデル
- **主モデル**: Mixed Logit（Random Parameters Logit）
  - `V_j = ASC_j + β_bio × biodiversity + β_water × water_quality + β_landscape × landscape + β_carbon × carbon + β_cost × payment`
  - 選好パラメータは正規分布、費用係数は固定
- **副モデル**: 潜在クラスモデル（選好異質性の構造的把握）
- **WTP算出**: `WTP = -β_attribute / β_cost`（Krinsky-Robb法で95%信頼区間）

#### 標本設計
- 対象: 里山周辺住民、層化二段抽出（距離帯 × 年齢層）
- 目標n = 600（ブロックあたり200）
- 調査方式: Web + 郵送併用

### 2.4 割引率と世代間公平性

4つのアプローチを検討し、**逓減割引率（DDR）** を推奨手法とした：

| アプローチ | 割引率 | 根拠 |
|-----------|-------|------|
| 記述的（Nordhaus型） | 5.0% | 資本の限界生産性 |
| 規範的（Stern型） | 1.4% | 世代間公平性の倫理 |
| **逓減割引率（DDR）** | 3.5%→0.5% | 不確実性の反映 |
| 二重割引率 | 市場財5.0% / 環境財1.5% | 代替不可能性 |

**DDRスケジュール**（Weitzman 2001 ガンマ割引に基づく）:

| 期間 | 割引率 |
|------|--------|
| 0–30年 | 3.5% |
| 31–75年 | 2.5% |
| 76–125年 | 2.0% |
| 126–200年 | 1.5% |
| 201–300年 | 1.0% |
| 300年以上 | 0.5% |

**世代間公平性の制度設計**:
- Safe Minimum Standard (SMS): 不可逆的損失の閾値設定
- 自然資本ストックの非減少条件（Strong sustainability constraint）
- 将来世代委員会等の代理的意思決定制度

### 2.5 SEEA-EA（生態系勘定）連携

UN SEEA Ecosystem Accounting (2021) に準拠した4層の勘定体系を設計：

1. **範囲勘定（Extent Account）**: IUCN GET分類に対応した生態系タイプ別面積の経年変化
2. **状態勘定（Condition Account）**: 5指標（植生被度、種の豊富度、土壌有機炭素、水質、景観連結性）の複合指数
3. **サービスフロー勘定（Service Flow Account）**: InVEST出力の物理量をSNA供給使用表と接続
4. **貨幣資産勘定（Monetary Asset Account）**: NPVベースの資産価値算定

## 4. 考察と今後の展望

### 4.1 主要な知見

1. **水資源と土壌保全の支配的価値**: 年間総価値の97%を水資源供給（56%）と土壌浸食防止（41%）が占める。これは代替費用法を用いた場合の典型的なパターンであり、インフラ代替費用の高さを反映している。

2. **文化的サービスの過小評価リスク**: InVESTベースの定量化では文化的サービス（レクリエーション等）の価値は全体の0.2%に過ぎないが、選択実験では景観管理のWTPが最大（¥4,524/世帯/年）。市場価格法と表明選好法の組み合わせが必須。

3. **里山の管理依存性**: 管理放棄シナリオでは炭素貯留が6.5%減少。里山生態系は持続的な人為管理を前提とした「社会-生態システム」であり、自然放置では最適化されない。

4. **割引率の決定的影響**: 1%と7%の差で資産価値が2.7倍変動。DDRの採用は長期自然資本を過小評価しないための重要な制度的選択。

5. **SEEA-EA状態指数**: 複合状態指数0.696は「中程度」であり、水質（0.60）と種の豊富度（0.65）が改善の優先領域。

### 4.2 手法的限界

- **空間的単純化**: 本パイプラインはランドスケープ単位の集計値であり、30mグリッドでの空間明示的な結果ではない。実運用にはGISベースのInVEST実行が必要。
- **パラメータの不確実性**: 炭素密度、USLE因子等は文献値ベースであり、現地計測データによるキャリブレーションが必要。
- **WTPの仮想性**: 選択実験結果はシミュレーション値であり、実調査に基づく検証が不可欠。
- **サービス間相互作用**: 各サービスの独立推定であり、トレードオフ（例：森林拡大による水収支減少と炭素貯留増加）の系統的分析は今後の課題。
- **ARIES統合**: k.LABとの実統合は設計段階にとどまり、稼働実績はない。

### 4.3 今後の展望

1. **GISベースの全実装**: 30mグリッドでのInVEST全モデル実行と、ARIES k.LABとの実運用連携
2. **実地調査の実施**: 選択実験の実施（n=600）、炭素インベントリの現地計測
3. **動的モデリング**: 気候変動シナリオ（RCP/SSP）下での将来予測と適応策評価
4. **ステークホルダー連携**: GIAHS認定地域の管理組織・自治体との協働実装
5. **政策統合**: 生物多様性クレジット、J-Credit、PES（生態系サービスへの支払い）制度への接続
6. **TNFD/SBTN対応**: 自然関連財務情報開示タスクフォース（TNFD）の開示要件との整合

### 4.4 パイプライン全体構成

```

  ├── 土地被覆図（JAXA ALOS / 国土数値情報）
  ├── DEM（国土地理院基盤地図情報 5mメッシュ）
  ├── 気候データ（AMeDAS降水量・気温）
  ├── 土壌データ（土壌環境基礎調査）
  └── 生物多様性データ（モニタリングサイト1000）
        │
        ▼
```
