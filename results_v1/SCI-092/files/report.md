# 新興科学技術の社会受容性予測モデル — 統合分析レポート

**DRAFT — NOT FOR DISTRIBUTION**

**作成日**: 2026-05-23  
**分析システム**: NLP/構造方程式モデリング統合パイプライン  
**対象技術**: 遺伝子編集 / 人工知能(AI) / 核融合

---

## 1. 実験目的と背景

### 1.1 研究目的

本研究は、遺伝子編集・AI・核融合の3つの新興科学技術について、**社会受容性を多角的に予測するモデル**を設計・実装することを目的とする。具体的には以下の6つのコンポーネントを統合した分析システムを構築した：

1. 世論調査データのメタ解析フレームワーク
2. ソーシャルメディア感情分析（BERT/感情辞書ハイブリッド）
3. リスク認知の心理測定パラダイムモデル
4. フレーミング効果の計量的評価
5. 信頼度-受容度の因果モデル（SEMパス解析）
6. ゲノム編集食品の日本での受容性ケーススタディ

### 1.2 背景

新興技術の社会実装には、技術的成熟度だけでなく、社会的受容性（Social Acceptance）が不可欠である。先行研究では、リスク認知（Slovic, 1987）、制度的信頼（Siegrist, 2000）、メディアフレーミング（Cacciatore et al., 2016）が受容性の主要な決定因子とされてきた。しかし、これらの要因を統合的に分析し、NLPと構造方程式モデリング（SEM）を組み合わせたシステム的アプローチは十分に行われていない。

本研究では、シミュレーションデータを用いて統合分析パイプラインの設計・検証を行い、実データ適用への道筋を示す。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 メタ解析（Component 1）

- **手法**: DerSimonian-Laird法によるランダム効果メタ解析
- **異質性指標**: I²統計量、Cochran's Q検定
- **モデレータ分析**: 国別サブグループ解析、年次トレンドのメタ回帰
- **データ**: 6ヶ国 × 3技術、2015-2025年の合成調査データ（計72研究）

### 2.2 ソーシャルメディア感情分析（Component 2）

- **アーキテクチャ**: BERT/感情辞書ハイブリッドモデル
  - BERT出力（信頼度スコア）に重み0.6
  - 感情辞書スコア（日英対応）に重み0.4
- **評価指標**: ハイブリッドスコア（-1〜+1）、エンゲージメント加重感情スコア
- **プラットフォーム**: Twitter/X、Reddit、ニュースコメント、ブログ
- **合成投稿数**: 3,187件

### 2.3 心理測定パラダイムモデル（Component 3）

- **理論基盤**: Slovic (1987) の心理測定パラダイム
- **因子**: 恐怖因子（Dread Factor）7項目 + 未知因子（Unknown Factor）5項目
- **分析手法**: 因子分析（2因子モデル）、Pearson相関、一元配置分散分析
- **サンプル**: 各技術500名、計1,500名の合成回答データ

### 2.4 フレーミング効果（Component 4）

- **実験デザイン**: 3技術 × 5フレーミング条件の被験者間計画
  - 便益フレーム、リスクフレーム、バランスフレーム、科学フレーム、倫理フレーム
- **分析手法**: 一元配置ANOVA、η²効果量、対比較（Bonferroni補正）
- **サンプル**: 各条件120名、計1,800名

### 2.5 SEM パス解析（Component 5）

- **モデル仕様**（lavaan記法）:
  ```
  Literacy → Trust → Risk → Acceptance
  Literacy → Trust → Benefit → Acceptance
  Media → Risk / Benefit
  Trust → Acceptance（直接効果）
  ```
- **潜在変数**: 信頼（3項目）、リスク認知（3項目）、便益認知（3項目）、受容度（3項目）、科学リテラシー（2項目）、メディア接触（2項目）
- **推定法**: Maximum Likelihood（semopyライブラリ）
- **適合度指標**: CFI, RMSEA, GFI
- **サンプル**: 800名

### 2.6 日本ケーススタディ（Component 6）

- **対象**: ゲノム編集食品の受容性
- **日本固有変数**: 自然さ懸念（naturalness concern）、表示義務選好、GMOとの区別認識
- **地域**: 関東・関西・中部・東北北海道・九州沖縄・中国四国
- **分析手法**: 重回帰分析、人口統計学的差異のANOVA、相関行列
- **サンプル**: 600名

## 3. 主要な結果と数値

### 3.1 メタ解析結果

| 技術 | 統合受容率 | 95% CI | I² | Q (p値) |
|------|-----------|--------|-----|---------|
| 遺伝子編集 | **0.398** | [0.356, 0.440] | 98.0% | p<0.001 |
| AI | **0.568** | [0.535, 0.601] | 96.5% | p<0.001 |
| 核融合 | **0.513** | [0.483, 0.542] | 96.7% | p<0.001 |

- AIの受容率が最も高く（56.8%）、遺伝子編集が最も低い（39.8%）
- 全技術で高い異質性（I²>95%）を示し、国・年次による変動が大きい
- 年次トレンド：AIの受容率上昇が最も急速（年間+1.8%ポイント）

### 3.2 感情分析結果

| 技術 | 投稿数 | 平均ハイブリッドスコア | エンゲージメント加重スコア |
|------|--------|----------------------|-------------------------|
| 遺伝子編集 | 1,141 | **-0.079** | -0.073 |
| AI | 884 | **+0.098** | +0.106 |
| 核融合 | 1,162 | **+0.186** | +0.195 |

- 核融合が最もポジティブな感情を獲得（+0.186）
- 遺伝子編集は唯一ネガティブ領域（-0.079）
- エンゲージメント加重スコアでは、高関与投稿ほどやや極性が強まる傾向

### 3.3 心理測定パラダイム結果

| 技術 | 恐怖因子 | 未知因子 | リスク-受容度 r | 平均リスク認知 | 平均受容度 |
|------|---------|---------|----------------|------------|---------|
| 遺伝子編集 | +0.311 | +0.431 | **-0.599** | 4.19 | 3.83 |
| AI | -0.669 | -0.019 | **-0.605** | 3.67 | 4.29 |
| 核融合 | +0.358 | -0.412 | **-0.619** | 4.28 | 3.67 |

- リスク認知と受容度の間に中程度〜強い負の相関（r = -0.60〜-0.62）
- 遺伝子編集は「未知」因子が最高、核融合は「恐怖」因子が最高
- AIは恐怖因子が最も低く、相対的に受容されやすい位置づけ

### 3.4 フレーミング効果結果

| 技術 | F値 | p値 | η² | 効果量解釈 |
|------|-----|------|-----|----------|
| 遺伝子編集 | **19.36** | <0.0001 | 0.115 | 中 |
| AI | **15.83** | <0.0001 | 0.096 | 中 |
| 核融合 | **12.00** | <0.0001 | 0.075 | 中 |

- 全技術でフレーミング効果が統計的に有意（p<0.0001）
- 便益フレームとリスクフレームの差（Cohen's d）は0.4〜0.6の中程度の効果
- 遺伝子編集でフレーミング効果が最大（η²=0.115）

### 3.5 SEM パス解析結果

**構造パス（全パス p<0.001）**:

| パス | 標準化パス係数 β |
|------|-----------------|
| Literacy → Trust | **+0.489*** |
| Trust → Risk | **-0.357*** |
| Trust → Benefit | **+0.420*** |
| Media → Risk | **+0.298*** |
| Literacy → Benefit | **+0.242*** |
| Media → Benefit | **-0.152*** |
| Trust → Acceptance（直接） | **+0.282*** |
| Risk → Acceptance | **-0.325*** |
| Benefit → Acceptance | **+0.378*** |

**モデル適合度**: CFI=0.999（良好）、RMSEA=0.010（良好）

- 受容度への最大の影響：便益認知（β=+0.378）、次いでリスク認知（β=-0.325）
- 制度的信頼は受容度に直接効果（β=+0.282）と、リスク・便益を介した間接効果を持つ
- 科学リテラシーは信頼を経由して受容度に正の間接効果

### 3.6 日本ケーススタディ結果

**全体統計（n=600）**:

| 指標 | 値 |
|------|-----|
| 受容度平均 | **3.14** (SD=0.92) |
| 受容者割合（≥4） | **17.0%** |
| 拒否者割合（<3） | **44.0%** |
| 購入意向平均 | **2.84** |
| 表示義務選好 | **5.80** |
| 自然さ懸念 | **4.98** |

**重回帰分析（R²=0.343）— 受容度の予測因子**:

| 予測因子 | β係数 |
|---------|------|
| 便益認知 | **+0.248** |
| 信頼（複合） | **+0.171** |
| GMO区別認識 | **+0.068** |
| 科学リテラシー | +0.023 |
| メディア接触 | +0.013 |
| ゲノム編集知識 | -0.008 |
| 自然さ懸念 | **-0.115** |
| リスク認知 | **-0.147** |

**日本固有の知見**:
- 科学者への信頼（M=4.50）と政府への信頼（M=3.20）のギャップ：**+1.30**
- 科学者への信頼と企業への信頼のギャップ：**+1.50**
- 自然さ懸念と受容度の相関：**r=-0.31**（日本の食文化に特有の「自然」志向）

## 4. 考察と今後の展望

### 4.1 統合的考察

本研究の6つのコンポーネントから得られた知見を総合すると、以下の構造が浮かび上がる：

1. **技術間の受容度階層**: AI > 核融合 > 遺伝子編集の順に受容度が高い。これはメタ解析（0.568 > 0.513 > 0.398）と感情分析の両方で一貫している。

2. **信頼-リスク-便益の三角構造**: SEMモデルは、制度的信頼がリスク・便益認知を介して受容度に影響する「信頼ヒューリスティック」（Siegrist & Cvetkovich, 2000）を実証的に支持した。便益認知の直接効果（β=+0.378）はリスク認知（β=-0.325）よりも大きく、ポジティブフレーミングの有効性を示唆する。

3. **フレーミングの非対称効果**: リスクフレームの負の効果（d≈-0.40）は便益フレームの正の効果（d≈+0.35）をわずかに上回り、「ネガティビティバイアス」（Kahneman & Tversky, 1979）と整合する。

4. **日本固有の要因**: ゲノム編集食品の日本での受容率は17%と極めて低く、「自然さ懸念」が独自の負の予測因子として機能している。これは日本の食文化における「自然食品」志向と関連すると考えられる。

### 4.2 方法論的貢献

- **BERT/感情辞書ハイブリッド**: 言語モデルの文脈理解と辞書の透明性を組み合わせ、多言語（日英）対応可能な感情分析フレームワークを構築した。
- **NLP-SEM統合**: 感情分析から得られるマクロレベルの世論指標と、個人レベルのSEMモデルを接続する設計を提示した。

### 4.3 限界

1. **合成データ**: 本研究はシミュレーションデータに基づく設計検証であり、実データでの検証が必要
2. **文化的妥当性**: 心理測定尺度の文化的等価性（measurement invariance）の検証が必要
3. **時間的動態**: 現行モデルは静的であり、パネルデータや時系列モデルの統合が課題
4. **因果推論**: SEMは相関構造に基づくものであり、真の因果関係の確立には実験デザインが必要

### 4.4 今後の展望

1. **実データへの適用**: 内閣府「科学技術に関する世論調査」、Eurobarometer等の実データでの検証
2. **動的モデルの構築**: ベイジアンネットワークや時変パラメータSEMによる受容度変動の予測
3. **リアルタイム監視**: ソーシャルメディアストリーミングデータを用いた受容度ダッシュボードの構築
4. **介入効果推定**: ランダム化比較試験によるフレーミング介入の因果効果推定
5. **国際比較**: 多母集団SEMによる文化間の因果構造の比較
