## 1. 実験目的と背景

### 1.1 背景

mRNAワクチンは、COVID-19パンデミックを契機に実用化が加速した次世代ワクチンプラットフォームである。mRNAワクチンの設計には、以下の多層的な最適化が必要となる：

- **コドン最適化**：ヒト細胞における翻訳効率最大化
- **UTR設計**：mRNA安定性・リボソーム結合効率の制御
- **修飾ヌクレオチド**：自然免疫回避と翻訳増強のバランス
- **エピトープ選定**：広範な集団免疫獲得のための抗原設計
- **LNP製剤最適化**：細胞内mRNA送達効率の最大化
- **マルチバレント戦略**：変異株への対応力

本研究では、これら6つの要素をカバーする統合型 in silico 設計プラットフォームを構築し、SARS-CoV-2スパイクタンパク質RBDドメインを例題抗原として各種最適化を実施した。

### 1.2 目的

1. コドン最適化アルゴリズムによる翻訳効率・安定性の定量評価
2. 5'/3'UTR配列バリアントのリボソーム負荷効率・半減期予測
3. N1-メチルプソイドウリジン等の修飾ヌクレオチドが及ぼす免疫原性・翻訳への影響モデリング
4. MHC-I/II拘束性エピトープおよびB細胞エピトープの同定と集団カバレッジ推定
5. 脂質ナノ粒子（LNP）組成パラメータのグリッドサーチによる最適製剤の決定
6. 既存・新興変異株を対象としたマルチバレントワクチン戦略の比較評価

## 2. 使用した手法・アルゴリズムの概要

### 2.1 コドン最適化（Module 1）

**アルゴリズム**: Codon Adaptation Index (CAI) 最大化

- **ヒトコドン使用頻度表**: Kazusaデータベース由来（Homo sapiens）
- **3戦略の比較**:
  - *Native*: 使用頻度に比例したランダム割り当て
  - *Optimized*: CAI偏重ランダムサンプリング（bias=1.5）
  - *Highly Optimized*: 各アミノ酸に対し最頻コドンを強制割り当て
- **評価指標**: CAI、GC含量（%）、CpGジヌクレオチド比率、mRNA安定性スコア（GC密度・AU連続配列ペナルティの複合指標）

### 2.2 UTR設計（Module 2）

**5'UTR評価モデル**:
- Kozakコンセンサス配列スコア（GCCACCATGG前後の文脈一致度）
- 開始コドン周辺ヘアピン自由エネルギー（ΔG近似値）
- リボソーム負荷効率スコア = Kozak×0.6 + (1/(1+|ΔG|))×0.4

**3'UTR評価モデル**:
- AU-richエレメント（ARE）含量（mRNA不安定化因子）
- Poly-A鎖長最適化（目標: 120–160nt）
- TENT4/StAble安定化エレメント効果の予測半減期モデル

比較したUTRテンプレート: ヒトβ-グロビン、CMVエンハンサー、EMCV IRES、TOP配列最適型、合成StAbleエレメント

### 2.3 修飾ヌクレオチド効果予測（Module 3）

**モデル化した修飾体**:
1. 非修飾（Unmodified）— ベースライン
2. プソイドウリジン（Ψ）
3. 5-メチルシチジン（m5C）
4. N1-メチルプソイドウリジン（m1Ψ） — 現行BNT162b2/mRNA-1273採用
5. 2'-O-メチル（Nm）
6. m1Ψ + m5C コンビネーション

**評価軸**: TLR7/8活性化レベル、RIG-I活性化レベル、翻訳効率乗数（multiplier）、mRNA半減期、総合ワクチンポテンシースコア

**用量応答モデル**: ヒルの式（Hill equation, hill coefficient=1.5）によるEC50ベース予測

### 2.4 抗原エピトープ解析（Module 4）

**MHC-I結合予測**:
- 9-merスライディングウィンドウ
- HLA-A\*02:01、HLA-A\*24:02、HLA-B\*07:02対象
- アンカー残基スコアによる疑似IC50推定

**MHC-II結合予測**:
- 15-merスライディングウィンドウ
- HLA-DR\*01:01、HLA-DR\*03:01、HLA-DR\*07:01対象

**B細胞エピトープ予測**:
- Parker親水性スケール（7-merウィンドウ平均）
- 線形エピトープの表面露出度スコアリング

**集団カバレッジ**: HLA頻度重み付き和によるグローバル集団カバレッジ推定（Sette & Sidney, 1999準拠）

### 2.5 LNP最適化シミュレーション（Module 5）

**パラメータ空間**:
- イオン化脂質モル比: 30–60%
- コレステロール比: 25–45%
- PEG化脂質比: 1.5–2.5%
- ヘルパー脂質（DSPC）: 残余
- N:P比: 4–6

**物理モデル**:
- 粒子径 (nm): イオン化脂質・コレステロール偏差ペナルティ付きガウス型モデル
- PDI: コンポーネント偏差線形モデル
- 封入効率 (%): N:P比・イオン化脂質比の線形関数
- ゼータ電位 (mV): pKa=6.5を仮定した生理的pH下の電荷計算
- トランスフェクション効率: 粒子径・PDI・封入率・ゼータ電位の積スコア

グリッドサーチによる全組み合わせ探索（約270ポイント）を実施。

### 2.6 マルチバレントワクチン設計（Module 6）

**対象変異株**:
- Ancestral（Wuhan参照株）、Alpha (B.1.1.7)、Beta (B.1.351)、Delta (B.1.617.2)、Omicron BA.1、Omicron XBB.1.5

**比較戦略**:
1. モノバレント（祖先株）
2. バイバレント（祖先株 + Omicron BA.1）
3. トリバレント（祖先株 + Delta + Omicron BA.1）
4. モザイク（全変異株コンセンサス配列アプローチ）
5. AIポリバレント（計算最適化多価設計）

**評価指標**: 中和幅（Breadth Score）、最新変異株に対する効力、製造性、安全性プロファイル、コスト効率

## 4. 考察と今後の展望

### 4.1 統合設計の有効性

本プラットフォームにより、6つの設計要素を並行して最適化する in silico ワークフローを確立した。特に以下の知見が得られた：

1. **コドン最適化**においては、CAI=1.0の達成よりもGC含量≈50%、CpG比率<0.65を保つCAI偏重最適化の方が、免疫原性低減と翻訳効率のバランスが優れている。

2. **UTR設計**では、3'UTR ARE含量ゼロ（ARE=0）のSynthetic StAbleエレメントが半減期22.4時間を実現し、現行のヒトβ-グロビン3'UTR（8.5h）比で2.6倍の安定化効果を示した。

3. **修飾ヌクレオチド**のm1Ψ+m5Cコンビネーションは、TLR7活性を95%抑制しながら翻訳効率を1.75倍に向上させる最も優れたプロファイルを示した。ただし製造コストと規制承認の観点から、単独m1Ψ（現行承認済み）との費用対効果比較が必要である。

4. **エピトープ解析**では、9-mer MHC-I + 15-mer MHC-II組み合わせにより集団カバレッジ93.7%を達成。HLA-A\*24:02（アジア人頻度高）を含む設計はアジア圏への適応性を示す。

5. **LNP最適化**では、PEG脂質を2.5%→1.5%に削減し、コレステロール比35%でのエンドソーム脱出効率向上を予測した。ただしゼータ電位が-16.6mVと低めであり、in vitro 検証が必要である。

6. **マルチバレント設計**では、モザイク/AIポリバレント戦略が幅スコア0.94を達成し、モノバレント比2.6倍の中和幅を実現。一方で製造性スコアが0.68–0.76と低く、スケールアップ困難性の課題が残る。

### 4.2 限界と留意点

- 本シミュレーションは簡略化物理モデルおよび疑似アフィニティスコアを用いており、実験的検証なしに絶対的な予測精度を保証するものではない。
- MHC結合予測には IEDB の NetMHCpan/NetMHCIIpan 等の高精度ツールとの統合が推奨される。
- LNP モデルは生体内動態（in vivo 分布、肝臓集積等）を考慮していない。
- 変異株のエスケープ率は文献値に基づく推定であり、新興変異株（JN.1, KP.2等）への対応には逐次更新が必要。

### 4.3 今後の展望

1. **深層学習統合**: OptimRNA、CodonBERT等の言語モデルによるコドン最適化精度向上
2. **MD シミュレーション**: LNP-mRNA 相互作用の分子動力学シミュレーション（GROMACS/AMBER）
3. **免疫シミュレーター統合**: IMMSIM / VaxDesign との接続による抗体応答予測
4. **リアルタイム変異株追跡**: GISAID API との連携による自動更新パイプライン
5. **臨床翻訳ガイドライン**: FDA/EMA 規制要件に準拠した設計制約の組み込み
