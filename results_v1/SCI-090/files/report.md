## 1. 実験目的と背景

### 1.1 目的

BIM（Building Information Modeling）データを起点として、建築物の環境性能を統合的に評価するシミュレーションシステムを設計・実装し、ZEB（ネットゼロエネルギービル）設計への適用可能性を検証する。

### 1.2 背景

2050年カーボンニュートラル達成に向け、建築部門のエネルギー消費削減は喫緊の課題である。日本のZEB定義（経済産業省）では、省エネ（50%以上削減）と創エネの組み合わせにより、年間一次エネルギー消費量のネットゼロを目指す。本研究では、IFCデータからの自動変換パイプラインを構築し、熱・光・風の3つの環境要素を統合的に評価するフレームワークを提案する。

### 1.3 対象建物概要

| 項目 | 値 |
|------|-----|
| 建物用途 | 事務所ビル |
| 延床面積 | 5,000 m² |
| 階数 | 地上5階 |
| 基準階面積 | 1,000 m² |
| 階高 | 3.5 m |
| 所在地 | 東京（35.68°N, 139.77°E） |

## 2. 使用した手法・アルゴリズムの概要

### 2.1 システムアーキテクチャ

```
IFC Model (BIM)
    │
    ├──→ [IFC Parser] ──→ BuildingModel（中間表現）
    │         │
    │         ├──→ EnergyPlus Exporter (.idf)
    │         ├──→ Radiance Exporter (.rad)
    │         └──→ CFD Mesh Exporter (.json)
    │
    ├──→ [Thermal Load Simulator]
    │         └──→ 月別冷暖房負荷、ピーク負荷、年間一次エネルギー
    │
    ├──→ [Natural Ventilation CFD]
    │         └──→ 風向×風速パラメトリック解析、ACH、換気効率
    │
    ├──→ [Daylight Simulator]
    │         └──→ sDA、ASE、昼光率、LEED判定
    │
    ├──→ [ZEB Evaluator]
    │         └──→ 基準/ZEB Ready/Nearly ZEB/ZEB 比較
    │
    └──→ [Integrated Dashboard]
              └──→ 6種の統合可視化チャート
```

### 2.2 IFCデータ変換（Phase 1）

- **入力**: IFC 2x3/4 ファイル（Industry Foundation Classes）
- **中間表現**: `BuildingModel` データクラス（ゾーン、サーフェス、材料層）
- **出力形式**:
  - EnergyPlus IDF（熱負荷計算用）
  - Radiance RAD（昼光解析用）
  - CFD Config JSON（自然換気解析用）
- **自動抽出項目**: 壁体U値、窓面積比（WWR）、ゾーン体積、開口部位置

### 2.3 熱負荷シミュレーション（Phase 2）

月別定常計算による簡易熱負荷モデルを採用し、EnergyPlusの代理モデルとして機能する。

**計算手法**:
- **外皮負荷**: `Q_env = Σ(A_i × U_i × ΔT)` （壁・窓の面積×U値×温度差）
- **日射取得**: `Q_sol = A_win × I_sol × SHGC` （窓面積×日射量×日射熱取得係数）
- **内部発熱**: 人体（120W/人）、照明、OA機器の総和
- **換気負荷**: オリフィス方程式 + 全熱交換器回収率考慮
- **HVAC効率**: VRF + DOAS（COP 冷房5.5 / 暖房4.2）

### 2.4 自然換気CFD解析（Phase 3）

**手法**: オリフィス方程式ベースの風力換気モデル

- **風圧係数**: 矩形建物の方位別Cp値（風洞実験データベース準拠）
- **べき乗則**: 高さ方向の風速プロファイル `V(z) = V_ref × (z/z_ref)^α`
- **等価開口面積**: 直列抵抗モデル `A_eq = (A_w × A_l) / √(A_w² + A_l²)`
- **換気量**: `Q = A_eq × √(2ΔP/ρ)`
- **パラメトリック条件**: 風速5段階（1–5 m/s）× 風向8方位 = 40ケース

### 2.5 昼光シミュレーション（Phase 4）

**手法**: BRS（Building Research Station）昼光率計算法の拡張

- **Sky Component (SC)**: 窓の立体角因子に基づく天空成分
- **Internally Reflected Component (IRC)**: 室内平均反射率に基づく間接成分
- **指標**:
  - sDA300/50%: 年間の50%以上の稼働時間で300lux以上を達成する面積割合
  - ASE1000/250h: 年間250時間以上で1000lux超過する面積割合
  - LEED v4 Daylight Credit: sDA ≥ 55% かつ ASE ≤ 10%

### 2.6 ZEB評価（Phase 5）

日本のZEB定義（経済産業省エネルギー消費性能計算法）に準拠した4段階評価:

| ZEB区分 | 省エネ率 | 創エネ含む条件 |
|---------|---------|-------------|
| ZEB | ≥50% | Net ≤ 0 |
| Nearly ZEB | ≥50% | 再エネカバー率 ≥75% |
| ZEB Ready | ≥50% | — |
| ZEB Oriented | ≥40% | — |

## 4. 考察と今後の展望

### 4.1 考察

#### システム設計の有効性
IFCからの自動変換パイプラインにより、BIMモデルから熱・光・風の3つのシミュレーションモデルを一貫して生成できることを実証した。中間表現（BuildingModel）の導入により、各専門シミュレーションへの変換の柔軟性と拡張性を確保した。

#### ZEB達成の課題
5階建事務所ビル（5,000 m²）では、屋上面積（≒1,000 m²）に対する延床面積比が大きいため、屋上PVのみではZEB達成が困難である。最高性能ケース（消費57.0, 発電48.2 kWh/m²/yr）でもNet 8.8 kWh/m²/yrが残存し、「Nearly ZEB」に留まった。ZEB達成には壁面PV、BIPV（建材一体型太陽電池）、蓄電池の導入が必要と考えられる。

#### 昼光とグレアのトレードオフ
高いsDA（100%）を達成した一方、ASE（22.3%）がLEED基準を超過した。これはWWR 40%の大面積窓が直射日光を導入しすぎることに起因する。方位別の遮光戦略（南面庇 + 東西面自動ブラインド）によるASE制御が必要であり、昼光利用と視覚的快適性のバランス最適化が課題である。

#### 自然換気の季節活用
平均ACH 20.08は十分な換気性能を示すが、快適域割合39%はジェット効果による局所的な高風速を示唆する。開口部配置の最適化（ウィンドキャッチャー、腰窓+高窓の組合せ）により、より均一な気流分布が期待できる。

### 4.2 今後の展望

1. **EnergyPlus/Radiance直接連携**: 現在の代理モデルをEnergyPlusエンジン及びRadianceレイトレーシングに置換し、時刻別シミュレーション精度を向上
2. **CFDソルバー統合**: OpenFOAM等のCFDソルバーとの連携により、室内気流分布の詳細解析を実現
3. **BIPV・蓄電池モデル**: 壁面太陽電池、建材一体型PV、リチウムイオン蓄電池の統合評価
4. **LCA（ライフサイクルアセスメント）**: 建材のエンボディドカーボンを含む全ライフサイクルCO₂評価
5. **最適化エンジン**: 遺伝的アルゴリズムによる外皮・設備・再エネのパラメトリック最適化
6. **BIMリアルタイム連携**: Revit/ArchiCADプラグインによる設計変更時の自動再計算
7. **機械学習サロゲートモデル**: EnergyPlus学習済みモデルによる高速パラメトリック評価
