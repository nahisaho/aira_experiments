## 1. 実験目的と背景

### 1.1 目的

汎用人工知能（AGI）の安全性を数学的に保証するための統合的理論フレームワークを設計・検証する。形式手法（型理論・モデル検査）とMLセーフティを統合し、以下の6つの安全性特性について形式的定義、数学的定理、および数値的検証を行う。

### 1.2 背景

AGIの安全性は、個別の問題（報酬ハッキング、内部アライメント等）として研究されてきたが、統一的な数学的フレームワークは存在しない。本研究では、これらの問題を統合し、型理論に基づく合成可能な安全性保証を提案する。

### 1.3 対象とする安全性特性

| # | 特性 | 形式的問題 |
|---|------|-----------|
| 1 | 報酬ハッキング | プロキシ報酬と真の報酬の乖離による最適化の暴走 |

## 2. 使用した手法・アルゴリズムの概要

### 2.1 報酬ハッキング（Reward Hacking）

**形式的定義（Definition 1）:**

真の報酬 R\* : S × A → ℝ とプロキシ報酬 R̂ : S × A → ℝ に対し、報酬ハッキングとは以下を満たす方策 π の存在をいう：

```
∃ π : E_{R̂}[π] ≥ E_{R̂}[π*_{R̂}] - ε  AND  E_{R*}[π] < E_{R*}[π*_{R*}] - δ
```

**定理1（防止条件）:**

∀s,a: |R̂(s,a) - R\*(s,a)| ≤ η かつ MDPの直径が D のとき、R̂ の下で ε-最適な方策 π に対して：

```
E_{R*}[π] ≥ E_{R*}[π*_{R*}] - 2ηD/(1-γ) - ε
```

**手法:** 20状態×5行動のMDPで、プロキシノイズレベル η を 0.01〜5.0 まで変化させ、ハッキングギャップと理論上界を比較。各条件50試行の平均。

### 2.2 Mesa-Optimization（内部アライメント）

**形式的定義（Definition 2）:**

学習モデル M が mesa-optimizer であるとは、内部目的関数 U_M が存在し：

```
M(s) = argmax_a E[U_M(s') | s, a]
```

**定理2（内部アライメント上界）:**

正則化 λ、訓練分布のカバレッジ c、訓練データサイズ n に対して：

```
P(Δ_inner > ε) ≤ exp(-λ·c·n·ε²/2)
```

**手法:** 30状態、100モデルの模擬実験。訓練データ量 n ∈ {100, 1000, 10000}、カバレッジ c ∈ {0.3, 0.5, 0.8}、正則化 λ ∈ {0.01, 0.1, 1.0} の組合せで内部ギャップと欺瞞的アライメントを測定。

### 2.3 遮断可能性（Corrigibility）

**形式的定義（Definition 3）:**

エージェント π が ε-corrigible であるとは、任意のシャットダウン信号 σ と状態 s に対して：

```
V^π(s | σ) - V^{π_off}(s | σ) ≤ ε
```

**定理3（効用無差別条件）:**

エージェントが corrigible であるための必要十分条件：

```
U(outcome | shutdown) = U(outcome | ¬shutdown) = U_0（定数）
```

**手法:** 15状態×4行動のMDP上で、4種類の方策（貪欲・シャットダウン準拠・ランダム・混合）の遮断可能性ギャップを測定。

### 2.4 影響度制限（Impact Measures）

**形式的定義（Definition 4 — Attainable Utility Preservation）:**

```
Impact(s, a) = Σ_R |AU_R(s') - AU_R(s_null)|
```

**定理4（近似保証）:**

k 個の補助報酬関数に対して：

```
|Impact_k(s,a) - Impact_∞(s,a)| ≤ O(1/√k) · V_max/(1-γ)
```

**手法:** 10状態×3行動、20個の補助報酬関数でAUPとRelative Reachability（RR）の両指標を計算。k の増加に伴う推定値の収束を検証。

### 2.5 協力的IRL（CIRL）

**形式的定義（Definition 5）:**

CIRLゲーム (H, R) において、人間 H は θ ∈ Θ に基づく報酬を持ち、ロボット R はベイズ推定で θ を学習。

**定理5（収束保証）:**

ボルツマン合理的な人間（温度パラメータ β）による T 回のデモンストレーションの後：

```
|V^{CIRL}(θ*) - V*(θ*)| ≤ O(1/√T) + ε_H/(1-γ)
```

**手法:** 10状態×4行動、3次元報酬パラメータ。デモンストレーション数 T ∈ {5, 10, 20, 50, 100, 200, 500} でコサイン類似度と価値ギャップの収束を追跡。

### 2.6 Debate プロトコル

**形式的定義（Definition 6）:**

正直エージェント A₁ と不正直エージェント A₂ が主張 c について議論し、審判 J が判定。

**定理6:** A₁ が議論に勝つ必勝戦略を持つ ⟺ c が真

**手法:** 5ラウンドの議論を20件の主張に対して実施。5つの設定（バランス型、正直有利、不正直強化、弱い審判、強い正直）で審判精度を測定。

### 2.7 型理論による安全性合成

CTL（Computation Tree Logic）による安全性仕様と、依存型に基づく安全性の合成規則を定義：

```
SafeAgent = RewardAligned ∧ Corrigible ∧ ImpactBounded ∧ ValueLearner
```

## 4. 考察と今後の展望

### 4.1 主要な発見

1. **理論上界の保守性:** 報酬ハッキングの防止上界 2ηD/(1-γ) は非常に保守的であり、実際のギャップは上界の数桁下に位置する。より tight な上界の導出が今後の課題。

2. **遮断可能性と最適性のトレードオフ:** 完全な遮断可能性は効用無差別条件の明示的導入なしには達成不可能であり、これは報酬最大化の原理と本質的に相反する。

3. **CIRLの高効率:** ベイズ的報酬学習は少数のデモンストレーションで高いアライメントを達成可能であり、理論上界よりも実際の収束が速い。

4. **影響度指標の一貫性:** AUPとRRの高相関は、異なる理論的動機から導出された指標が実質的に同等の安全性概念を捉えていることを示唆。

5. **Debate の脆弱性:** 不正直エージェントの能力が正直エージェントに接近する状況では、Debate プロトコルの信頼性が急速に低下する。

### 4.2 限界

- **有限状態モデル:** 本実験は小規模な離散MDPに限定。連続空間・深層学習への拡張は未検証。
- **確率的シミュレーション:** 欺瞞的アライメントの検出は現実のニューラルネットワークにおけるmesa-optimizerの検出とは異なる。
- **計算複雑性:** 影響度指標の正確な計算は一般にNP困難であり、本フレームワークの近似の質は問題構造に依存。

### 4.3 今後の展望

1. **深層学習との統合:** ニューラルネットワークの内部表現に対する mesa-optimization 検出器の開発。
2. **形式検証ツールチェーン:** Lean4/Coq による安全性定理の機械的証明。
3. **マルチエージェント拡張:** 複数のAGIシステム間の安全性合成規則の精緻化。
4. **スケーラブルな影響度測定:** 高次元状態空間での効率的なAUP近似アルゴリズム。
5. **実世界ベンチマーク:** Procgen/SafetyGym等のリッチな環境でのフレームワーク検証。

## 付録A: 定理の証明スケッチ

### 定理1の証明（報酬ハッキング防止）

π が R̂ の下で ε-最適とする。すなわち E_{R̂}[π] ≥ E_{R̂}[π\*] - ε。
∀s,a: |R̂(s,a) - R\*(s,a)| ≤ η より：

```
|E_{R̂}[π] - E_{R*}[π]| ≤ η · Σ_{t=0}^∞ γ^t = η/(1-γ)
```

同様に π\* についても成立。よって：

```
E_{R*}[π] ≥ E_{R̂}[π] - η/(1-γ)
           ≥ E_{R̂}[π*] - ε - η/(1-γ)
           ≥ E_{R*}[π*] - 2η/(1-γ) - ε
```

MDPの直径 D を考慮すると、上界は 2ηD/(1-γ) + ε に改善される。 □

### 定理5の証明スケッチ（CIRL収束）

T 回の観測 {(s_t, a_t)}_{t=1}^T に対するベイズ事後分布の集中不等式を適用。人間の ε_H-最適性による誤差項と、有限サンプルによる推定誤差 O(1/√T) の合計が総誤差上界を与える。 □
