## 1. 実験目的と背景

### 1.1 目的

射出成形プロセスの全工程（充填→保圧→冷却→離型）を包括するデジタルツインシステムを構築し、以下を実現する：

1. 樹脂流動のリアルタイムシミュレーション
2. 冷却・結晶化過程のモデリングによる固化挙動予測
3. 残留応力・そり変形の定量予測
4. プロセスパラメータと品質の因果関係の体系的理解
5. センサーデータによるモデルオンライン校正
6. 自動車部品製造への適用実証

### 1.2 背景

射出成形は自動車・電子機器・医療機器等の量産において最も広く使われるプラスチック成形技術である。しかし、そり変形・ヒケ・残留応力などの品質問題はプロセスパラメータの複雑な相互作用に起因し、経験則だけでは最適条件の探索が困難である。

デジタルツインは物理モデル（Moldflow/OpenFOAM）とデータ駆動モデル（ガウス過程回帰）を統合し、リアルタイムセンサーデータによるモデル校正（アンサンブルカルマンフィルタ）を行うことで、予測精度と生産効率の両立を図る。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 モジュール1: 樹脂流動シミュレーション

| 手法 | 詳細 |
|------|------|
| **Hele-Shaw近似** | 薄肉キャビティの2.5D流動解析。流動度積分 S = ∫z²/η dz をGauss-Seidel法で解く |
| **3D流動解析** | 有限差分法によるNavier-Stokes方程式の簡易解法。移流＋拡散項を陽的に時間積分 |
| **粘度モデル** | Cross-WLF モデル: η(γ̇,T) = η₀(T)/(1+(η₀γ̇/τ*)^(1-n))。η₀はWLF式で温度依存 |

**主要パラメータ**: PA66-GF30、パワーロー指数 n=0.3、τ*=150 kPa

### 2.2 モジュール2: 冷却・結晶化動力学

| 手法 | 詳細 |
|------|------|
| **1D厚さ方向熱伝導** | FDM法、壁面第3種境界条件（冷却水側HTC考慮） |
| **Nakamura結晶化速度式** | dX/dt = n·K(T)·(1-X)·[-ln(1-X)]^((n-1)/n) |
| **Lauritzen-Hoffman核生成** | K(T) = K₀·exp(-U*/(R(T-T∞)))·exp(-Kg/(T·ΔT)) |
| **結晶度依存物性** | 熱伝導率・比熱を結晶度の線形混合則で計算 |

### 2.3 モジュール3: 残留応力・そり変形

| 手法 | 詳細 |
|------|------|
| **層状固化応力モデル** | σ(z) = E(z)/(1-ν²)·[ε_free(z) - ε_avg - κ·z] |
| **そり曲率計算** | 曲げモーメントM = ∫E·(ε_free-ε_avg)·z dz から κ = M/I |
| **変形場** | δ = κ·L²/8（単純支持平板近似） |

### 2.4 モジュール4: プロセス-品質代替モデル

| 手法 | 詳細 |
|------|------|
| **実験計画** | Latin Hypercube Sampling (LHS)、6パラメータ×80サンプル |
| **代替モデル** | Gaussian Process Regression (Matérn ν=2.5カーネル) |
| **感度解析** | Sobol一次感度指標（Saltelli法） |
| **最適化** | 差分進化法 (Differential Evolution) による多目的最適化 |

### 2.5 モジュール5: データ同化

| 手法 | 詳細 |
|------|------|
| **アンサンブルカルマンフィルタ (EnKF)** | アンサンブルサイズ=50、状態ベクトル8次元 |
| **観測モデル** | 圧力センサ3点＋温度センサ4点 = 7次元観測 |
| **校正対象** | 圧力/温度バイアス＋粘度/HTC/収縮/応力の補正係数 |

### 2.6 モジュール6: 自動車部品ケーススタディ

| 項目 | 詳細 |
|------|------|
| **4シナリオ比較** | nominal / high_speed / low_stress / optimized |
| **モンテカルロ分析** | 500サンプル、全パラメータ±5%変動 |
| **品質基準** | そり<0.5mm、ヒケ<0.02mm、重量44.5-45.5g、収縮率<1% |

## 5. 考察と今後の展望

### 5.1 考察

1. **流動シミュレーション**: Hele-Shaw近似は薄肉部品に対して計算コストと精度のバランスが良い。3D解析は厚肉部やリブ・ボス周辺の詳細解析に適する。

2. **冷却・結晶化**: Nakamura モデルにより結晶化度の厚さ方向分布を予測可能。冷却時間21.4sで離型温度に到達し、結晶化度は約35%で飽和した。

3. **残留応力**: 冷却後の温度場が比較的均一なため、そり変形は微小（<0.04mm）であった。実機では型拘束や射出圧力の非対称性によりそりが増大する可能性がある。

4. **代替モデル**: GP回帰のR²は0.21〜0.76と品質指標により精度に差がある。warpage予測の精度が低いのは、物理モデルのノイズ項の影響が大きいためである。訓練データの増加や物理情報付きカーネルの導入が改善に有効。

5. **データ同化**: EnKFは観測可能なパラメータ（圧力・温度補正）については良好に収束した（誤差<0.2）。間接的なパラメータ（粘度・HTC補正）は観測情報が不足するため推定精度に限界がある。

6. **ケーススタディ**: 全4シナリオが品質基準を満足。high_speedシナリオはサイクルタイム28.7sと最も効率的だが、そりが最大（0.043mm）。optimizedシナリオはバランスの良い条件を提供。

### 5.2 今後の展望

- **3D-FEAとの完全連成**: 充填→冷却→構造解析の一貫シミュレーション
- **Physics-Informed Neural Network (PINN)** による高速代替モデルの構築
- **強化学習** によるリアルタイムプロセス制御の実現
- **マルチスケールモデリング**: 繊維配向→結晶化→力学特性の階層的予測
- **Edge Computing** による工場現場でのリアルタイム推論
