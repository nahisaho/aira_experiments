## 1. 実験目的と背景

### 1.1 目的

次世代の暗黒物質(DM)直接検出実験の戦略設計を支援するため、包括的なモンテカルロシミュレーションフレームワークを開発した。本フレームワークは以下の6つの課題を統合的に評価する：

1. **非WIMP暗黒物質候補の検出可能性**: アクシオン、暗黒光子、プリモーディアルブラックホール(PBH)
2. **方向感度検出器の感度計算**: CYGNUS/MIMAC型ガスTPC
3. **ニュートリノフロア到達予測**: コヒーレント弾性ニュートリノ-原子核散乱(CEνNS)
4. **バックグラウンド低減戦略の体系的評価**: 放射性・宇宙線起源・ニュートリノ起源
5. **多ターゲット戦略の相補性**: Xe/Ar/Ge/NaI検出器の比較
6. **年周変動シグナルの統計的検出力**: 季節変動の検出有意度

### 1.2 背景

暗黒物質は宇宙のエネルギー密度の約27%を占めるが、その粒子的性質は未解明である。現在のXENON-nT、LZ、PandaX-4T等の第2世代実験がWIMPパラメータ空間を急速に制約する一方、次世代実験(DARWIN/XLZD、DarkSide-20k、CYGNUS)の設計最適化が急務となっている。

本フレームワークは、Standard Halo Model (SHM)に基づく暗黒物質ハロー速度分布、Helm核形状因子、Lewin & Smith (1996)の微分散乱率公式を基盤とし、多様な信号・バックグラウンドモデルを統合する。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 フレームワーク設計思想

GEANT4のレイヤードアーキテクチャとROOTのデータ解析パイプラインに着想を得て、以下のモジュール構成を採用：

```
src/
├── core/constants.py       # 物理定数・核ターゲット・形状因子
├── signals/dm_signals.py   # 信号モデル (WIMP/Axion/DarkPhoton/PBH)
├── detectors/detector_models.py  # 検出器モデル
├── backgrounds/background_models.py  # バックグラウンドモデル
└── analysis/statistics.py  # 統計解析・感度計算
```

### 2.2 WIMP信号計算

微分散乱率は Lewin & Smith の標準公式に基づく：

$$
\frac{dR}{dE_R} = N_T \cdot \frac{\rho_\chi}{m_\chi} \cdot \frac{m_N \sigma_N c^2}{2\mu_N^2} \cdot F^2(E_R) \cdot \eta(v_{\min})
$$

- **Standard Halo Model**: ρ₀ = 0.3 GeV/cm³, v₀ = 220 km/s, v_esc = 544 km/s
- **Helm形状因子**: F²(q) による核の有限サイズ効果
- **速度積分**: η(v_min) = ∫_{v>v_min} f(v)/v d³v（解析的計算）

### 2.3 非WIMP信号モデル

| モデル | メカニズム | 主要パラメータ |
|--------|-----------|---------------|
| アクシオン | 太陽アクシオンの軸電子効果吸収 | m_a, g_ae |
| 暗黒光子 | 動的混合による吸収 | m_A', κ |
| PBH | ホーキング放射ニュートリノ → CEνNS | M_PBH, f_DM |

### 2.4 方向感度検出器

CYGNUS/MIMAC型ガスTPC（CF₄ガス）の3次元トラック再構成をモデル化：
- **角度分布**: DM風方向（Cygnus座）からの散乱分布 ∝ exp(-v_e² sin²θ / 2σ_v²)
- **Head/Tail認識**: 前方-後方非対称性による双極子テスト
- **Head/Tail無し**: 四重極テスト（cos²θ偏差）

### 2.5 ニュートリノフロア

11種のニュートリノ源（pp, pep, hep, ⁷Be, ⁸B, ¹³N, ¹⁵O, ¹⁷F, 大気, DSNB）からのCEνNS反跳スペクトルを計算。フロア断面積を S/√B = z_CL 基準で評価。

### 2.6 統計手法

- **排除限界**: 90% CL Poisson上限（Feldman-Cousins近似）
- **発見感度**: 3σ有意度に必要な信号数
- **年周変動**: 変調振幅 A_m × √(N/2) による有意度評価
- **方向性検出**: Rayleigh検定（双極子）/ 四重極検定

### 3.2 非WIMP候補の検出可能性

#### アクシオン（太陽）
- g_ae = 10⁻¹¹: ~10¹⁰イベント（既に排除済み領域）
- g_ae = 10⁻¹²: ~10⁶イベント（検出可能）
- **g_ae = 10⁻¹³: ~104イベント（DARWIN規模で発見可能境界）**

#### 暗黒光子
- κ = 10⁻¹⁵での吸収率: m_A' = 0.5 keV で 2.7 × 10⁻¹⁹ events/kg/day
- **現行パラメータでは検出困難 → κ > 10⁻¹² が必要**

#### プリモーディアルBH
- M_PBH = 10¹⁵ g (T_H = 10.6 MeV): ホーキングニュートリノ経由で大量の反跳事象
- M_PBH = 10¹⁷ g (T_H = 0.1 MeV): ニュートリノエネルギー不足で検出困難
- **小惑星質量PBH (10¹⁵-10¹⁶ g) がCEνNS検出器で原理的に検出可能**

## 4. 考察と今後の展望

### 4.1 主要な知見

1. **次世代Xe検出器（DARWIN）はニュートリノフォグ近傍まで到達可能** だが、フォグ突破には方向感度検出器との併用が必須。

2. **非WIMP候補のうちアクシオン（g_ae ~ 10⁻¹³）は次世代検出器で探索可能域** に入る。暗黒光子は現行混合パラメータではチャレンジングであり、専用低閾値検出器が必要。

3. **方向性検出はHead/Tail認識が決定的** — H/Tありの場合200事象で方向性確認可能だが、H/Tなしでは数千～数万事象が必要。CYGNUSのR&Dにおいてトラック方向再構成精度の改善が最優先課題。

4. **多ターゲット戦略はSI/SD分離に不可欠** — Xe (高A²) + F/NaI (SD敏感) + Ge (低閾値) の三本柱が理想的。

5. **バックグラウンド低減は検出器ごとに最適戦略が異なる** — Geは宇宙線活性化冷却が支配的、Xeは総合対策、Arは内在的³⁹Arの同位体分離が鍵。

### 4.2 フレームワークの制限事項

- 核形状因子はHelm近似のみ（実験データに基づく数値形状因子は未実装）
- ニュートリノスペクトルは簡易パラメトリックモデル（SSMの詳細スペクトルではない）
- 検出器応答はエネルギー分解能のガウス畳み込みのみ（S1/S2の詳細シミュレーション未実装）
- 実際のGEANT4ジオメトリ・粒子輸送シミュレーションは含まず、解析的/半解析的計算

### 4.3 今後の展望

1. **GEANT4連携**: 本フレームワークのイベントジェネレータをGEANT4 Primary Generator Actionとして組み込み、検出器シミュレーションと接続
2. **ROOT I/O**: TTree/TH1形式での結果出力によりROOT解析パイプラインとの統合
3. **速度分布の一般化**: SHMを超えるハローモデル（Streams, Sausage構造）の実装
4. **機械学習によるS/B分離**: ニューラルネットワークベースの事象分類器
5. **ベイズ統計フレームワーク**: プロファイル尤度比と Bayesian evidence の比較
