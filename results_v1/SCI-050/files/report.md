## 1. 実験目的と背景

### 1.1 目的

観察データから因果効果を推定する主要6手法を、同一のシミュレーションデータ上で体系的に比較し、各手法の **推定精度・バイアス・適用条件・限界** を定量的に評価する。

### 1.2 背景

医薬品疫学（pharmacoepidemiology）では、ランダム化比較試験（RCT）が実施困難な場合にリアルワールドデータ（RWD）を用いた因果推論が求められる。しかし観察データには **交絡バイアス**、**選択バイアス**、**未測定交絡** が内在し、推定手法の選択が結論に大きく影響する。本フレームワークは、DoWhy/EconML を基盤とした再現可能なワークフローを構築し、手法間の体系的な比較を可能にする。

### 1.3 シミュレーション設計

新規降圧薬の心血管イベントリスク低減効果を推定する薬剤疫学シナリオを構築した。

| パラメータ | 値 |
|---|---|
| サンプルサイズ | n = 3,000 |
| 処置群比率 | 31.8% |
| 真のATE（平均処置効果） | **−5.0 mmHg**（収縮期血圧低下） |
| 交絡変数 | 年齢、性別、BMI、併存疾患スコア、ベースラインBP |
| 操作変数 | 医師の処方傾向（physician preference） |
| 異質的処置効果 | ITE = −5.0 − 0.1×(age−60) − 0.5×comorbidity |

処置割り付けは交絡変数と操作変数に依存するロジスティックモデルで決定し、真の因果効果が既知の環境でベンチマークを行った。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 傾向スコアマッチング（PSM）と代替手法

| 手法 | 原理 | 実装 |
|---|---|---|
| **PSM** | 傾向スコアに基づく1:1最近傍マッチング | scikit-learn LogisticRegression + NearestNeighbors |
| **IPW** | 逆確率重み付け | 重み = T/e(X) + (1−T)/(1−e(X)) |
| **IPW（トリミング）** | 極端な傾向スコア（<0.05, >0.95）を除外 | 同上 + トリミング |
| **AIPW（二重頑健推定）** | IPW + 結果モデルの組み合わせ | GBR + IPW |

**PSMの限界**:
- マッチングによるサンプル損失（955名のみマッチ）
- 高次元共変量での「次元の呪い」
- カリパーやマッチング比率の恣意的選択

### 2.2 操作変数法（IV）

- **操作変数**: 医師の処方傾向（physician preference）
- **推定法**: 二段階最小二乗法（2SLS）
- **弱操作変数診断**: 第一段階F統計量 + Stock-Yogo基準
- **頑健推定**: Anderson-Rubin信頼集合

### 2.3 差分の差分法（DID）

- **パネルデータ**: 500単位 × 8期間、処置開始は第5期
- **推定法**: 処置×事後の交互作用項を含む回帰（クラスターロバスト標準誤差）
- **平行トレンド検証**: イベントスタディプロット + 事前期間ダミーの同時F検定 + プラセボ検定

### 2.4 Double/Debiased Machine Learning（DML）

- **LinearDML**: 線形CATE関数 + GBR/GBCによるナイサンスパラメータ推定
- **CausalForestDML**: 因果フォレストによる柔軟なCATEモデリング
- **クロスフィッティング**: 5-fold CV
- **離散処置**: `discrete_treatment=True`

### 2.5 因果フォレスト（Causal Forest）

- **実装**: EconML `grf.CausalForest`（500本のツリー）
- **最小リーフサイズ**: 20
- **異質的処置効果（HTE）分析**: CATE五分位分析、年齢別・併存疾患別効果推定
- **信頼区間**: ブートストラップ法（200回）

### 2.6 DoWhy因果推論ワークフロー

- **因果グラフ（DAG）**: ドメイン知識に基づくグラフ定義
- **識別**: バックドア基準 + IV基準の自動識別
- **推定**: 線形回帰、PSM、IV の3手法
- **反駁テスト**: ランダム共通原因、プラセボ処置、データサブセット

## 3. 主要な結果と数値

### 3.1 手法別ATE推定値

| 手法 | ATE推定値 (mmHg) | SE | 95% CI | |Bias| |
|---|---|---|---|---|
| **PSM** | −6.089 | 0.482 | [−7.035, −5.144] | 1.089 |
| **IPW** | −7.149 | — | — | 2.149 |
| **IPW（トリミング）** | −7.149 | — | — | 2.149 |
| **AIPW（二重頑健）** | −5.914 | 0.186 | [−5.279, −5.549] | 0.914 |
| **2SLS-IV** | −5.774 | 0.689 | [−7.125, −4.423] | 0.774 |
| **DID** | −4.981 | 0.205 | [−5.383, −4.579] | **0.019** |
| **LinearDML** | −5.756 | — | [−6.163, −5.350] | 0.756 |
| **CausalForestDML** | −5.888 | — | [−8.059, −3.717] | 0.888 |
| **Causal Forest** | −5.761 | — | [−5.798, −5.712] | 0.761 |
| **DoWhy LR** | −6.086 | — | — | 1.086 |
| **DoWhy PSM** | −5.490 | — | — | 0.490 |
| **DoWhy IV** | −4.299 | — | — | 0.701 |

**最小バイアス**: DID (|Bias| = 0.019)　—　設計上平行トレンドを満たすデータで最も正確。

### 3.2 傾向スコア分析

- **PS推定モデルAUC**: 0.649（中程度の弁別能）
- **マッチング後SMD**: 全共変量で0.05未満（バランス良好）
- **IPWのバイアス**: 極端な傾向スコアによる重み不安定性でバイアスが最大（2.149）

### 3.3 操作変数分析

- **第一段階F統計量**: 94.46（> 10、弱操作変数ではない ✓）
- **Anderson-Rubin信頼集合**: [−6.960, −4.648]（真のATEを含む ✓）
- **感度分析**: 操作変数の強度γが低下するとバイアスが急増し、F < 10で推定が不安定化

### 3.4 DID分析

- **ATE推定値**: −4.981（真値に最も近い）
- **イベントスタディ**: 事前期間の係数は概ね0付近
- **事前トレンド同時F検定**: p = 0.000（統計的に平行トレンド棄却）
  - ※ ただしこれは大サンプルによる検出力過剰の可能性あり
- **プラセボ検定**: 推定ATEはプラセボ分布の外側に位置

### 3.5 異質的処置効果（HTE）

因果フォレストによるCATE分析から以下の傾向が確認された：

| CATE五分位 | 平均CATE (mmHg) | 平均年齢 | 平均併存疾患 |
|---|---|---|---|
| Q1（最大効果） | −7.545 | 67.0 | 3.18 |
| Q2 | −6.398 | 65.0 | 2.02 |
| Q3 | −5.623 | 62.3 | 1.55 |
| Q4 | −4.953 | 55.7 | 1.70 |
| Q5（最小効果） | −4.284 | 51.6 | 1.78 |

- **高齢かつ併存疾患が多い患者**ほど降圧効果が大きい（−7.5 mmHg）
- **若年低リスク患者**では効果が限定的（−4.3 mmHg）
- 推定CATEと真のITEの相関: r = 0.669（中程度の回復）

### 3.6 DoWhy反駁テスト

| テスト | 効果 | p値 | 解釈 |
|---|---|---|---|
| ランダム共通原因 | −6.086 | 1.000 | ✓ 推定は頑健 |
| データサブセット (80%) | −6.098 | 0.920 | ✓ 推定は安定 |

## 4. 考察

### 4.1 手法間比較の知見

1. **DIDが最小バイアス**（0.019）を達成したが、これはデータ生成過程が平行トレンドを満たす設計であったため。実データでは平行トレンドの検証が不可欠。

2. **AIPWは二重頑健性**により、結果モデルまたは傾向スコアモデルのいずれかが正しければ一致推定量となり、PSM単体（Bias=1.089）より優れた推定（Bias=0.914）を実現。

3. **IV法はLATEを推定**するため、ATEとの乖離が生じうる。本シミュレーションでは操作変数が十分強く（F=94.46）、Anderson-Rubin信頼集合が真値を含んだ。

4. **DML/因果フォレスト**は柔軟なナイサンスモデルにより中程度のバイアス（0.76〜0.89）を達成。CATEの不均一性も捕捉可能。

5. **IPW**は極端な傾向スコアに対して最も脆弱で、トリミングしても改善しなかった。実務では安定化重みやHájek推定量の使用を推奨。

### 4.2 医薬品疫学への示唆

- **手法の単一使用は避けるべき**: 複数手法による感度分析（triangulation）が信頼性を高める
- **HTEの臨床的意義**: 高齢・高併存疾患患者では降圧効果が約1.8倍大きく、リスク層別化に基づく個別化医療の根拠となる
- **DoWhyワークフロー**: DAGの明示 → 識別 → 推定 → 反駁という体系的手順が再現可能な因果推論を支援

### 4.3 限界

- シミュレーションデータであり、未測定交絡の影響は設計上制御されている
- DIDの事前トレンドF検定が有意となったのは大サンプルによる検出力過剰の可能性
- CATEとITEの相関は0.669にとどまり、個人レベルの効果推定の精度には限界がある
- IPW推定量の不安定性は重みの正規化やHájek推定量で改善の余地あり

### 4.4 今後の展望

1. **未測定交絡への対処**: 感度分析（E-value, Rosenbaum bounds）の統合
2. **時間変動処置**: Marginal Structural Models（MSM）の追加
3. **実データへの適用**: MIMIC-III、UK Biobank等のRWDへの適用検証
4. **メタラーナー比較**: S-Learner, T-Learner, X-Learnerの追加比較
5. **因果発見**: PC/GESアルゴリズムによるDAGの自動推定

## 付録: DoWhy/EconML因果推論ワークフロー

```
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 因果グラフ（DAG）の定義                              │
│  → ドメイン知識に基づく変数間の因果関係の明示                   │
├─────────────────────────────────────────────────────────────┤
│  Step 2: 因果効果の識別（Identification）                     │
│  → DoWhy: バックドア基準 / フロントドア基準 / IV基準            │
│  → 識別可能性の自動判定                                       │
├─────────────────────────────────────────────────────────────┤
│  Step 3: 推定（Estimation）                                  │
│  → PSM / IPW / AIPW / IV-2SLS / DML / Causal Forest         │
│  → EconML: LinearDML, CausalForestDML, grf.CausalForest     │
├─────────────────────────────────────────────────────────────┤
│  Step 4: 反駁テスト（Refutation）                             │
│  → ランダム共通原因 / プラセボ処置 / データサブセット            │
│  → 推定の頑健性を多角的に検証                                 │
├─────────────────────────────────────────────────────────────┤
│  Step 5: 感度分析 & HTE分析                                  │
│  → CATE五分位分析、操作変数強度感度分析                        │
│  → サブグループ別の処置効果の異質性評価                        │
└─────────────────────────────────────────────────────────────┘
```
