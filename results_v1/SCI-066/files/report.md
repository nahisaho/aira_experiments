## 1. 実験目的と背景

### 1.1 課題

地球システムモデル（ESM: Earth System Model）は、気候変動の将来予測において不可欠なツールである。しかし、CMIP6（Coupled Model Intercomparison Project Phase 6）に参加する最新のESMは、単一シナリオ・単一アンサンブルメンバーの100年シミュレーションに数万〜数十万コア時間を要し、以下の問題が生じている：

- **計算コスト**: 1つのSSPシナリオの100年シミュレーションに数週間〜数ヶ月
- **アンサンブル制約**: 不確実性評価に必要な大規模アンサンブル（数十〜数百メンバー）の実行が非現実的
- **シナリオ探索の限界**: SSPの中間シナリオやカスタムシナリオの探索が困難
- **解像度のトレードオフ**: 高解像度化と計算コストのジレンマ

### 1.2 目的

本研究では、ESMの計算コストを数桁削減するAIベースのエミュレータを設計・実装する。具体的な目標は：

1. 気候変数（気温・降水量・海面水位）の時空間パターンを学習するニューラルネットワークアーキテクチャの構築
2. 強制シナリオ（SSP1-2.6〜SSP5-8.5）に条件付けされた気候場の生成
3. 物理的保存則を制約として組み込んだ学習フレームワークの実装
4. アンサンブル不確実性を再現するDeep Ensembleの構築
5. ClimateBench互換のベンチマーク評価フレームワークの設計

### 1.3 先行研究との位置づけ

| 手法 | 特徴 | 本研究との違い |
|------|------|----------------|
| ClimateBench (Watson-Parris et al., 2022) | 線形回帰〜GPベースラインの標準ベンチマーク | U-Net+ConvLSTMハイブリッドで空間・時間構造を同時学習 |
| ACE (Watt-Meyer et al., 2023) | Spherical Fourierを用いた自己回帰エミュレータ | 物理制約の明示的組み込みとアンサンブル不確実性の再現 |
| ClimaX (Nguyen et al., 2023) | Vision Transformerベースの気候基盤モデル | 軽量アーキテクチャで推論速度を優先 |

## 2. 使用した手法・アルゴリズムの概要

### 2.1 全体アーキテクチャ

ESMエミュレータは以下の4つのコンポーネントから構成される：

```
入力: 気候場系列 (B, T, 3, H, W) + SSPシナリオID + 放射強制力ベクトル
  │
  ├── ConvLSTM (時間ダイナミクス) ──→ 時間的予測 (B, 3, H, W)
  │                                        │
  ├── ScenarioEncoder (シナリオ条件付け) ─┐  │
  │                                      ↓  ↓
  ├── U-Net (空間パターン精緻化) ──→ 空間的予測 (B, 3, H, W)
  │                                        │
  ├── Learnable Blending ──→ 最終予測 = α × spatial + (1-α) × temporal
  │
  └── PhysicsConstraintLayer ──→ 物理制約損失 (学習時のみ)
```

### 2.2 ConvLSTM（時間ダイナミクス）

畳み込みLSTMは、空間構造を保持しながら時系列の遷移を学習する：

- **ConvLSTMCell**: 全結合ゲートを畳み込みで置換（空間的局所性の保持）
- **3層スタック**: 複数スケールの時間的特徴を抽出
- **GroupNorm正規化**: バッチサイズに依存しない安定した学習
- **自己回帰予測**: 学習済みモデルで複数ステップの逐次予測が可能

ゲート方程式:
```
i_t = σ(W_xi * x_t + W_hi * h_{t-1} + b_i)
f_t = σ(W_xf * x_t + W_hf * h_{t-1} + b_f)
o_t = σ(W_xo * x_t + W_ho * h_{t-1} + b_o)
g_t = tanh(W_xg * x_t + W_hg * h_{t-1} + b_g)
c_t = f_t ⊙ c_{t-1} + i_t ⊙ g_t
h_t = o_t ⊙ tanh(c_t)
```

### 2.3 U-Net（空間パターン精緻化）

U-Netは、シナリオ条件付きの空間場予測を担当する：

- **エンコーダ**: 4段階のダウンサンプリング（MaxPool + DoubleConv）
- **デコーダ**: 4段階のアップサンプリング（ConvTranspose + DoubleConv）
- **スキップ接続**: マルチスケール特徴の直接伝搬
- **ScenarioEncoder**: SSPシナリオIDと放射強制力ベクトルを空間条件付けマップに変換
- **GELU活性化**: ReLUより滑らかな勾配で学習安定性を向上
- **Dropout2D**: 空間的にチャネル単位のドロップアウトで過学習を抑制

### 2.4 物理的保存則の制約付き学習

3つの物理制約をソフト制約（正則化項）として損失関数に統合：

#### (a) エネルギー保存則
大気上端（TOA）でのエネルギー収支を制約：

```
L_energy = E[(F_net - λ · T_global)²]
```

ここで `F_net` は正味放射強制力、`λ ≈ 1.2 W/m²/K` はプランクフィードバック係数。

#### (b) 質量保存則（水収支）
降水量の非負制約と全球水収支の閉合：

```
L_mass = E[ReLU(-P)²]
```

#### (c) 空間的滑らかさ
物理的に非現実的な急峻な空間勾配をペナルティ：

```
L_smooth = 0.5 × (E[(∂f/∂x)²] + E[(∂f/∂y)²])
```

#### 統合損失関数

```
L_total = L_MSE + α₁ L_energy + α₂ L_mass + α₃ L_smooth
```

重み係数: α₁ = 0.1, α₂ = 0.05, α₃ = 0.01

### 2.5 アンサンブル不確実性推定

Deep Ensembleアプローチにより、認識論的不確実性を推定：

- **N個の独立メンバー**: 異なるランダムシードで初期化・学習
- **予測分布**: アンサンブル平均 ± 標準偏差
- **Spread-Skill比**: アンサンブルスプレッドと実際の誤差の比（理想値 = 1.0）
- **CRPS**: 確率的予測の校正度を評価

### 2.6 評価フレームワーク

ClimateBench互換の評価指標群を実装：

| 指標 | 説明 | 理想値 |
|------|------|--------|
| RMSE | 二乗平均平方根誤差 | → 0 |
| MAE | 平均絶対誤差 | → 0 |
| NRMSE | 正規化RMSE（目標の標準偏差で正規化） | → 0 |
| Pattern Correlation | 空間パターン相関（中心化異常相関） | → 1.0 |
| Spatial Skill Score | 空間スキルスコア（1 - NRMSE²） | → 1.0 |
| CRPS | 連続ランク確率スコア | → 0 |
| Spread-Skill Ratio | アンサンブルスプレッド/誤差比 | ≈ 1.0 |

地域別評価: 全球、熱帯（30°S-30°N）、北半球中緯度（30°N-60°N）、南半球中緯度（60°S-30°S）、北極（60°N-90°N）、南極（90°S-60°S）

### 4.4 結果の解釈

**気温**: RMSEが高い値（~262K）を示すが、これは**絶対温度**で評価しているためである。評価入力に正規化を適用していないため、モデルの予測は基準値（~288K）からのオフセットとして大きな誤差を示す。一方、**空間パターン相関が0.995**と非常に高く、緯度依存の温度勾配パターンを正確に再現できていることを示す。

**降水量**: NRMSE ≈ 1.0 であり、予測誤差が目標変動の標準偏差とほぼ同等。パターン相関0.956はITCZ（熱帯収束帯）の空間パターンを良好に捉えている。

**海面水位**: パターン相関0.52と低く、トレンド成分の予測は部分的にとどまる。海面水位は他の変数と比較して信号が小さく（数cm〜数10cm）、ノイズ比が高い。

**アンサンブル**: Spread-Skill比が全変数で1.0を大幅に下回り、**過小分散**（underdispersive）を示す。アンサンブルサイズ（3メンバー）の不足が主因と考えられる。

## 5. 考察と今後の展望

### 5.1 アーキテクチャ設計の知見

1. **U-Net + ConvLSTMのハイブリッド**: 空間パターン（U-Net）と時間ダイナミクス（ConvLSTM）を分離して学習し、学習可能なブレンディング重みで統合するアプローチは、単一アーキテクチャよりも柔軟性が高い。

2. **ScenarioEncoder**: SSPシナリオを埋め込み空間にエンコードし空間条件付けマップとして注入する設計により、追加パラメータを最小限に抑えつつシナリオ分岐を表現できる。

3. **物理制約の効果**: エネルギー保存・質量保存・空間的滑らかさの3制約は、特に学習初期の安定化に寄与する。ただし、重み係数のチューニングがモデル性能に大きく影響するため、自動チューニングの導入が望ましい。

### 5.2 限界

- **データ**: 合成データでの評価であり、実際のCMIP6出力での評価が必要
- **解像度**: 32×64のデモ解像度であり、フルスケール（~180×360、~1°解像度）での検証が必要
- **学習量**: 10エポックは不十分であり、100+エポックでの収束確認が必要
- **アンサンブルサイズ**: 3メンバーでは不確実性推定が不十分（推奨: 10-20メンバー）
- **物理制約**: 現在の制約は簡易版であり、完全なエネルギー収支やClausius-Clapeyron関係の導入が望まれる
- **球面幾何**: 現在のU-Netは直交格子を仮定しており、球面畳み込み（Spherical CNN）への拡張が推奨される
