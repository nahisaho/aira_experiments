---

## 1. 実験目的と背景

AIシステムの社会実装が加速する中、倫理的側面の**定量的評価**が喫緊の課題となっている。本研究では、以下の5次元を統合的に評価するフレームワークを設計・実装し、医療AI診断システムへの適用を通じてその有効性を検証した。

| # | 評価次元 | 対象リスク |
|---|---------|----------|
| 1 | 公平性 (Fairness) | 属性間の予測格差、較正バイアス |
| 2 | 説明可能性 (Explainability) | SHAP値の安定性・一貫性 |
| 3 | プライバシー (Privacy) | メンバーシップ推論攻撃への耐性 |
| 4 | ロバスト性 (Robustness) | 敵対的摂動・分布シフトへの頑健性 |
| 5 | 環境負荷 (Environment) | 学習時のCO₂排出量 |

**動機**: 既存のAI倫理評価は定性的チェックリストに依存しがちであり、各次元を横断的・定量的に比較するフレームワークが不足している。本研究はFairlearn/AIF360の概念を踏まえつつ、5次元を0–1スコアに正規化し、重み付き統合スコアで総合評価を行うパイプラインを提案する。

## 2. 使用した手法・アルゴリズムの概要

### 2.1 データセット

- **合成医療診断データ**: 3,000例、20特徴量、二値分類（診断陽性/陰性）
- **保護属性**: 年齢群（Young <50 / Old ≥50）、性別
- **意図的バイアス注入**: Old群の陰性例の15%を陽性に反転（現実のバイアスをシミュレーション）
- **分割**: 学習70% / テスト30%（層化抽出）

### 2.2 モデル

- **Gradient Boosting Classifier** (scikit-learn)
  - `n_estimators=150`, `max_depth=5`, `random_state=42`
  - テスト精度: **0.8656**, AUC: **0.9052**

### 2.3 公平性評価

| 指標 | 定義 | 計算方法 |
|------|------|---------|
| Statistical Parity Difference (SPD) | P(ŷ=1\|G=a) − P(ŷ=1\|G=b) | グループ別陽性率の差 |
| Equalized Odds Difference (EOD) | TPR/FPRのグループ間最大差 | 真ラベル条件付き予測率の差 |
| Calibration Gap | グループ間較正誤差の差 | 10-bin較正曲線の平均偏差差 |
| 統合公平性スコア | 重み付き統合 | 1 − (0.4×SPD + 0.35×EOD + 0.25×CalGap) |

### 2.4 説明可能性評価

- **SHAP一貫性**: 5回のブートストラップサンプリングで特徴量重要度ランキングのSpearman順位相関を測定
- **説明安定性**: 微小ノイズ（σ=0.01）摂動下でのSHAP値のコサイン類似度
- **統合スコア**: 0.5×一貫性 + 0.5×安定性

### 2.5 プライバシーリスク評価

- **メンバーシップ推論攻撃 (MIA)**: 学習データ（メンバー）とテストデータ（非メンバー）の予測確信度分布の分離可能性を評価
- **閾値ベース攻撃**: 最適閾値でのAttack Accuracy・AUCを計算
- **プライバシースコア**: 1 − 2×(Attack AUC − 0.5) でAUC 0.5→1.0, AUC 1.0→0.0に変換
- **過学習ギャップ**: Train/Test精度差を補助指標として使用

### 2.6 ロバスト性評価

- **敵対的摂動**: ε ∈ {0.01, 0.05, 0.1, 0.2, 0.5} のランダム方向摂動下での精度低下を測定
- **分布シフト**: 全特徴量に均一シフト {0.0, 0.5, 1.0, 2.0, 3.0} を加えた場合の精度低下を測定
- **統合スコア**: 中程度摂動（上位3条件）での平均精度保持率

### 2.7 環境負荷評価

- **CO₂排出量推定**: 消費電力(W) × 学習時間(s) / 3.6×10⁶ × 炭素強度(gCO₂/kWh)
- **デフォルト条件**: CPU 65W、炭素強度 400 gCO₂/kWh（日本平均相当）
- **環境スコア**: exp(−CO₂g / 200)

### 2.8 統合評価

| 次元 | 重み |
|------|------|
| Fairness | 0.25 |
| Explainability | 0.20 |
| Privacy | 0.20 |
| Robustness | 0.20 |
| Environment | 0.15 |

**Overall Ethics Score** = Σ(重み × 次元スコア)

## 3. 主要な結果と数値

### 3.1 各次元のスコア

| 次元 | スコア | グレード | 主要指標 |
|------|--------|---------|---------|
| **Fairness** | **0.906** | A | SPD=0.033, EOD=0.193, CalGap=0.052 |
| **Explainability** | **0.602** | D | SHAP一貫性=0.207, 安定性=0.997 |
| **Privacy** | **0.721** | C | MIA AUC=0.639, 過学習Gap=0.132 |
| **Robustness** | **0.991** | A | ε=0.5でも精度低下 <2% |
| **Environment** | **1.000** | A | CO₂=0.021g, エネルギー=0.053mWh |
| **OVERALL** | **0.840** | **B** | — |

### 3.2 公平性の詳細

- **Statistical Parity**: Young群 0.448 vs Old群 0.481 → 差 0.033（良好）
- **Equalized Odds**: 真ラベル=1の場合のTPR差が0.193（要改善）
- **Calibration**: 両群とも較正誤差 <0.10（許容範囲）

### 3.3 説明可能性の詳細

- **SHAP一貫性** (0.207): ブートストラップ間でのランキング相関が低く、特徴量重要度の順序が不安定。これはサンプル依存性が高いことを示す。
- **説明安定性** (0.997): 微小摂動に対するSHAP値の変動は極めて小さく、局所的な説明の安定性は優秀。
- **課題**: グローバルな一貫性が低いため、どの特徴量が「最も重要」かの解釈に注意が必要。

### 3.4 プライバシーの詳細

- **MIA Attack AUC**: 0.639 → 攻撃者がランダムより有意にメンバーを識別可能
- **過学習ギャップ**: 0.132 → モデルが学習データを過度に記憶している兆候
- **リスクレベル**: LOW（閾値0.7をわずかに超過）

### 3.5 ロバスト性の詳細

- 木ベースモデルの特性上、連続値ノイズに対して高い頑健性を示す
- ε=0.5でも精度低下は1.6%に留まる
- 分布シフト magnitude=3.0では精度が大幅低下（0.50付近）→ 大きなドメインシフトには脆弱

### 3.6 環境負荷の詳細

- 小規模モデル（GBM 150本、深さ5）のため、CO₂排出量は微量（0.021g）
- 大規模モデル（LLM等）では数桁上がるため、スケーリング時の再評価が必須

## 4. 医療AI診断システム 倫理監査ケーススタディ

### 4.1 シナリオ

ある医療機関が、患者の臨床データから疾患の早期診断を行うAIシステムを導入検討中。規制要件として、年齢・性別による予測格差の排除、説明可能な判断根拠の提示、患者データのプライバシー保護が求められる。

### 4.2 監査結果サマリ

| 監査項目 | 判定 | 根拠 |
|---------|------|------|
| 公平性基準 (SPD < 0.1) | ✅ 合格 | SPD=0.033 |
| 公平性基準 (EOD < 0.1) | ❌ 不合格 | EOD=0.193 |
| 説明可能性（SHAP安定性 > 0.9） | ✅ 合格 | 安定性=0.997 |
| 説明可能性（SHAP一貫性 > 0.5） | ❌ 不合格 | 一貫性=0.207 |
| プライバシー（MIA AUC < 0.6） | ❌ 不合格 | MIA AUC=0.639 |
| ロバスト性（ε=0.1で精度低下 < 5%） | ✅ 合格 | 低下=−0.1% |
| 環境負荷（CO₂ < 100g/回） | ✅ 合格 | 0.021g |

### 4.3 是正勧告

1. **Equalized Odds改善**: 後処理による閾値調整（Hardt et al., 2016）またはFairlearn の`ThresholdOptimizer`を適用
2. **SHAP一貫性向上**: 特徴量選択の安定性を高めるため、Stability Selection + SHAP の組合せを検討
3. **プライバシー強化**: 差分プライバシー（DP-SGD）の導入、正則化強化による過学習抑制
4. **継続モニタリング**: 本フレームワークを定期実行し、スコアの経時変化を追跡

## 5. 考察と今後の展望

### 5.1 フレームワークの有効性

- 5次元を0–1スコアに正規化し統合することで、**異なる倫理的側面の横断比較**が可能になった
- レーダーチャート・ヒートマップによる可視化は、ステークホルダーへの説明に有効
- 統合スコア（Grade B = 0.840）は、説明可能性とプライバシーに改善余地があることを明確に示した

### 5.2 限界

| 限界 | 影響 | 対策案 |
|------|------|-------|
| 合成データでの検証 | 実データのバイアス構造を完全に再現できない | 実臨床データでの追試 |
| 閾値ベースMIAのみ | 高度な攻撃モデルへの耐性は未評価 | Shadow Model攻撃の実装 |
| 環境負荷の推定精度 | 実測ではなく推定値 | CodeCarbonによる実測 |
| 単一モデルでの評価 | モデルアーキテクチャ依存性が不明 | 複数モデルの比較評価 |
| 重み付けの恣意性 | 重みによって結論が変わりうる | 感度分析の実施 |

### 5.3 今後の展望

1. **Fairlearn ThresholdOptimizer**・**AIF360 Reweighing** の統合による公平性改善パイプライン
2. **差分プライバシー対応学習**（Opacus/TensorFlow Privacy）の組込み
3. **LIME・Anchors等の複数説明手法**の比較評価
4. **実臨床データ**（MIMIC-IV等）での検証
5. **規制対応**（EU AI Act、厚生労働省ガイドライン）との要件マッピング
6. **CI/CDパイプライン統合**: モデル更新時の自動倫理監査
