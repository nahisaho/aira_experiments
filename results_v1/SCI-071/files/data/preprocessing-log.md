# Preprocessing Log

- Input source: synthetic cloth-folding trajectories generated by `run_experiment.py`.
- State construction: regular cloth grid flattened to `(num_points * 3)` coordinates.
- Randomization: pose rotation, translation, height noise, and observation noise applied per episode.
- Split strategy: random train/validation split with a fixed seed.
- Normalization: action inputs bounded to `[-1, 1]`; state targets left in metric coordinates.
