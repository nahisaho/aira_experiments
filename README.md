# AIRA 科学実験 100本ベンチマーク

**AI Research Assistant (AIRA)** に100本の科学実験を自動実行させ、その結果を記録したベンチマークリポジトリです。

## 公開の目的

このリポジトリは、以下の目的で実験結果を公開しています：

1. **AIによる科学研究支援の現在地を示す** — LLMベースのAIエージェントが、先行研究調査から実験コード実装・論文執筆まで一貫して遂行できることを、100本の実験で実証します。
2. **再現性と透明性の確保** — 入力プロンプト・AI応答全文・生成コード・論文をすべて公開することで、AIの出力品質を誰でも検証可能にします。
3. **プロンプト設計のベストプラクティス共有** — 先行研究調査→実験計画→実験実施の3段階プロンプト設計により、AIの出力品質がどう変化するかの知見を共有します（[比較レポート](comparison-report.md)参照）。
4. **AI for Science コミュニティへの貢献** — 生命科学・計算化学・物理学など多分野にわたるAI生成論文・コードのデータセットとして、AI支援研究の評価基準策定に活用できます。

## 概要

AIRAのCo-Scientistスキルに対して、生命科学・計算科学・物理学など多分野にわたる100の研究テーマを与え、各テーマについて以下を自動生成させました：

- **実験コード** (Python): データ前処理、モデル実装、学習・評価パイプライン
- **可視化** (PNG): アーキテクチャ図、学習曲線、ベンチマーク比較等
- **実験レポート** (`report.md`): 実験目的・手法・結果・考察の詳細レポート
- **学術論文** (`paper.md`): Abstract〜Referencesを備えた学術論文形式の文書

### プロンプト設計

各実験プロンプトは3段階構成です：

1. **先行研究調査** — ToolUniverse MCP（Semantic Scholar / PubMed / Crossref）を使った文献調査
2. **実験計画** — 先行研究の知見に基づく実験設計
3. **実験実施** — コード実装・可視化・レポート/論文生成

## ディレクトリ構成

```
aira_experiments/
├── README.md                 # このファイル
├── comparison-report.md      # バージョン間比較レポート (v1.0〜v4.0)
├── results/                  # 実験結果 (100実験)
│   ├── summary.json          # 全実験のメタデータ集約
│   ├── SCI-001/              # 各実験ディレクトリ
│   │   ├── input_prompt.txt  # 入力プロンプト
│   │   ├── output_response.md # AIの応答全文
│   │   ├── metadata.json     # 実行メタデータ (所要時間、ファイル数等)
│   │   ├── file_list.json    # 生成ファイル一覧
│   │   └── files/            # 生成された成果物
│   │       ├── paper.md      # 学術論文
│   │       ├── report.md     # 実験レポート
│   │       ├── src/          # 実験コード (Python)
│   │       ├── figures/      # 生成された図表 (PNG)
│   │       └── results/      # 実験結果データ (JSON等)
│   ├── SCI-002/
│   │   └── ...
│   └── SCI-100/
│       └── ...
├── scripts/
│   └── run-experiments.js    # 実験自動実行スクリプト (Playwright)
└── package.json
```

## 技術スタック

- **AIRA**: AI Research Assistant (ローカル実行)
- **Co-Scientist スキル**: 科学実験の自動実行を担当するAIスキル
- **ToolUniverse MCP**: 学術論文検索 (Semantic Scholar, PubMed, Crossref)
- **Playwright**: ブラウザ自動化による実験実行
