# AIRA 研究成果物生成ベンチマーク（100本）

**AI Research Assistant (AIRA)** に100件の科学研究テーマを与え、文献調査・コード実装・図表作成・論文執筆を自動実行させた結果を記録したベンチマークリポジトリです。

> [!IMPORTANT]
> **本ベンチマークの限界**: 本実験で生成されたデータ・図表・数値結果はすべてAIによるシミュレーションまたはモックデータであり、実験室での実測データは一切使用していません。生成コードの実行検証、引用の正確性検証、専門家による科学的妥当性の評価も未実施です。そのため、個々の生成物を科学的成果として扱うことはできません。
>
> しかし、100件を実際に実行し体系的に分析することで、**AI for Scienceにおける現時点でのAIの能力と限界の境界線**が見えてきました。AIは課題が明確に定義されれば、既存手法を組み合わせることで新しい研究アプローチを高速に生成できます。100件の生成物はいずれも複数の既存技術を統合した「組み合わせ的新規性」を持っており、これはAIならではの強みです。一方で、**「何を問うか」を決めるのは、依然として研究者自身でなければならない**——これが100件のベンチマークから得られた示唆です。
>
> ただし、本実験ではAIに研究テーマ自体を設定させる実験は行っていないため、この結論は観察に基づく示唆であり、実験的に証明されたものではありません。

## 公開の目的

このリポジトリは、以下の目的で実験結果を公開しています。

1. **AIによる研究成果物生成の現在地を示す** — LLMベースのAIエージェントが、先行研究調査から実験コード実装・論文形式の文書作成までの成果物生成ワークフローを完了しうることを、100件のベンチマークで記録します。
2. **再現性と透明性の確保** — 入力プロンプト・AI応答全文・生成コード・論文を公開することで、第三者がAI出力を事後検証・批判的検討できる材料を提供します。
3. **プロンプト設計の知見共有** — 先行研究調査→実験計画→実験実施の3段階プロンプト設計により、AIの出力がどう変化するかの観察結果を共有します（[比較レポート](docs/comparison-report.md)参照）。
4. **AI for Science コミュニティへの貢献** — AI生成の研究成果物を批判的に検討するためのデータセットとして公開します。

## 概要

AIRAのCo-Scientistスキルに対して、生命科学・計算科学・物理学など多分野にわたる100の研究テーマを与え、各テーマについて以下を自動生成させました。実験手法の詳細は [methodology.md](docs/methodology.md) を参照してください。

- **実験コード** (Python): データ前処理、モデル実装、学習・評価パイプライン
- **可視化** (PNG): アーキテクチャ図、学習曲線、ベンチマーク比較等
- **実験レポート** (`report.md`): 実験目的・手法・結果・考察の詳細レポート
- **学術論文** (`paper.md`): Abstract〜Referencesを備えた学術論文形式の文書

### プロンプト設計

各実験プロンプトは3段階構成です。

1. **先行研究調査** — ToolUniverse MCP（Semantic Scholar / PubMed / Crossref）を使った文献調査
2. **実験計画** — 先行研究の知見に基づく実験設計
3. **実験実施** — コード実装・可視化・レポート/論文生成

## 新規性マーカー分析

100本の生成論文（paper.md）に含まれる「新規性を主張する表層的特徴」（手法命名、先駆性表現、貢献リスト等）を自動抽出し、スコアリングしました。詳細は [新規性マーカー分析レポート](docs/novelty-report.md) を参照してください。

> **注**: このスコアは**科学的新規性そのものを測定するものではありません**。論文が「新規性を主張するための修辞的要素」をどの程度含むかという形式的指標です。実際の科学的貢献度の評価には、専門家によるレビューが必要です。

| マーカーレベル | 件数 | 含まれる特徴 |
|--------------|------|------------|
| 🟢 多（5点以上） | 39件 | 独自手法名、先駆性表現、複数技術統合、ベースライン比較 |
| 🟡 中（3-4点） | 31件 | 部分的な手法命名、DOI付き引用、貢献リスト |
| 🔴 少（0-2点） | 30件 | 汎用的なフレームワーク記述 |

**主な観察結果**:
- 100件中100件が複数の既存技術を統合した「組み合わせ的新規性」を持つ — AIは既存手法を新たに組み合わせることで、個々の技術にはない研究アプローチを生成した。ただし、既存のパラダイムを覆すような根本的に新しいアルゴリズムと判断できる事例は、本分析の範囲では確認していない（専門家評価は未実施）
- 97%がDOI形式の参考文献を含む（DOIの実在性および引用内容の正確性は未検証）
- 100件のテーマはすべて人間が設計したプロンプトに基づいており、AIが自発的に研究課題を設定した事例はない。この観察から、**AIは組み合わせ的新規性の生成に長けるが、「何を問うか」を決める研究者の役割は依然として重要**と考えられる。ただし、AIに問い設定を行わせる対照実験は未実施であるため、今後の検証課題として残る

詳細な実践ガイドは [ベストプラクティス](docs/best-practices.md) を参照してください。

## ディレクトリ構成

```
aira_experiments/
├── README.md                 # このファイル
├── docs/                     # ドキュメント
│   ├── methodology.md        # 実験方法論（実行条件・制約・評価手法）
│   ├── comparison-report.md  # バージョン間比較レポート (v1.0〜v4.0)
│   ├── novelty-report.md     # 新規性マーカー分析レポート
│   └── best-practices.md     # AI for Science 実践ガイド
├── results/                  # 実験結果 (100実験)
│   ├── summary.json          # 全実験のメタデータ集約
│   ├── SCI-001/              # 各実験ディレクトリ
│   │   ├── input_prompt.txt  # 入力プロンプト
│   │   ├── output_response.md # AIの応答全文
│   │   ├── metadata.json     # 実行メタデータ (所要時間、ファイル数等)
│   │   ├── file_list.json    # 生成ファイル一覧
│   │   └── files/            # 生成された成果物
│   │       ├── paper.md      # 学術論文
│   │       ├── report.md     # 実験レポート
│   │       ├── src/          # 実験コード (Python)
│   │       ├── figures/      # 生成された図表 (PNG)
│   │       └── results/      # 実験結果データ (JSON等)
│   ├── SCI-002/
│   │   └── ...
│   └── SCI-100/
│       └── ...
├── scripts/
│   └── run-experiments.js    # 実験自動実行スクリプト (Playwright)
└── package.json
```

## 技術スタック
