# はじめに

AIRA（AI Research Assistant）の3バージョン — v3.4.3（Round 11）、v3.4.4（Round 12）、v3.4.5（Round 13）— で**同一の30実験ベンチマーク**を実行し、研究成果物の品質推移を定量的・定性的に分析した。

本記事では、3ラウンドを横断的に比較することで、各バージョンの改善効果と残存課題を明らかにする。

# 定性分析

## メトリクス別の評価

### Value Mismatches（VM）— ⚠️ 悪化傾向

3ラウンドの最大の懸念事項。VM avg が 26.5→42.0→54.8 と一貫して増加している。

**仮説1: バリデーション精度の向上**
v3.4.4 で導入された Last-output bias 排除・Format normalisation により、以前は見逃されていた不一致が検出されるようになった。つまり「真の不一致率は同じだが、検出率が上がった」可能性。

**仮説2: エージェントの出力フォーマットの多様化**
v3.4.5 の Format Normalisation が逆効果となり、エージェントがより多様なフォーマットで値を出力するようになった可能性。バリデーターの正規化がこの多様性に追いつけていない。

**仮説3: LLM の非決定性**
VM の「不安定」パターン（8/26 = 31%）が示すように、同一条件でも VM が大幅に変動する。3ラウンドの傾向は、統計的ノイズによる見かけの傾向である可能性。

### Uncited Claims — ✅ 改善

3ラウンドで最も明確な改善を示した指標。

- uncited=0 の割合: 67%→63%→**81%**
- uncited 4+ の件数: 4→5→**2**
- avg: 1.1→1.2→**0.6**

R13 での改善は、v3.4.5 の Citation Handling 改善の効果と考えられる。

### Figure Orphans（FigOrp）— ➡️ 横ばい

- FigOrp=0 の割合: 63%→67%→62% — 3ラウンドで安定
- 「0 か 4+」の二極化が一貫 — 中間値がない
- FigOrp > 0 の場合は常に 4+ — 図の管理は「できるか全くできないか」の構造的問題

この二極化は、エージェントの図参照処理にバイナリな障害パターンがあることを示唆する。

### Gates — ⬇️ R13 で API アノマリー発生

R11/R12 では全件 Gates 4/4 だったが、R13 で 4件が Gates 0/4。このパターンは v3.4.5 固有の問題で、バリデーション API の応答異常と考えられる。

# 考察

## 3ラウンド横断で見える構造的課題

### 1. VM は「バリデーションの検出感度」に支配されている

VM avg の増加トレンド（26.5→42.0→54.8）は、バリデーションロジックの変更と強い相関がある。v3.4.4 で Last-output bias を排除し、v3.4.5 で Format Normalisation を導入した結果、以前は「一致」と判定されていた値が「不一致」と判定されるようになった。

これは「品質の悪化」ではなく「計測精度の向上」と解釈すべきである。ただし、エージェント側の値出力の安定性向上も並行して取り組む必要がある。

### 2. Uncited は改善可能な指標

uncited の改善トレンド（1.1→1.2→0.6）は、バリデーションと無関係にエージェントの引用行動が改善できることを示す。R13 では uncited=0 が 81% に達しており、プロンプト最適化でさらなる改善が期待できる。

### 3. FigOrp の二極化は構造的問題

FigOrp の「0 か 4+」パターンは3ラウンドで変わらない。これはプロンプトやバージョンでは解決できず、エージェントのツール呼び出しパターンまたは図参照のアーキテクチャレベルの変更が必要。

### 4. ベンチマークの安定性は確認済み

論文構造（語数、セクション数、テーブル行数）が3ラウンドで安定していることから、ベンチマークの一貫性は高い。メトリクスの変動は、バージョン変更とLLM非決定性に帰属できる。

## 改善施策の効果予測

| 施策 | 対象メトリクス | 期待効果 |
|------|--------------|---------|
| Citation Ledger（results-summary セル） | VM | セルに全数値を集約→引用一貫性向上 |
| Figure Manifest（figure-manifest セル） | FigOrp | 明示的な図存在チェック→二極化の解消 |
| Golden Rules（プロンプト冒頭3ルール） | VM, Uncited | 最重要指示を最初に提示→遵守率向上 |
| NatureLM/GALACTICA 直接呼び出し | 全体 | ToolUniverse 経由の不安定性を排除 |

これらの施策は Round 14（v3.4.8）で導入済み。結果の比較は Round 14 完了後に実施予定。

# まとめ

3ラウンドの比較から、以下の結論が得られた：

1. **VM の増加は計測精度の向上による見かけの悪化**であり、エージェントの出力品質自体は必ずしも低下していない
2. **Uncited は3ラウンドで最も明確な改善**を示し、プロンプトレベルでの改善が有効であることを示す
3. **FigOrp の二極化は構造的課題**であり、アーキテクチャレベルの変更が必要
4. **ベンチマーク手法は安定**しており、バージョン間比較に適している
5. **LLM の非決定性**が VM の31%を「不安定」にしており、単一ラウンドの結果解釈には注意が必要

Round 14 では、上記分析に基づくプロンプト最適化（Golden Rules、Citation Ledger、Figure Manifest）の効果を検証する予定である。
